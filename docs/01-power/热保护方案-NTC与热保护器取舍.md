# 热保护方案 · 3 路 NTC 和 3 只 NC thermostat 要不要砍

- **日期**：2026-09-14
- **起因**：用户「我觉得可以不加 NTC 和 NC thermostat」
- **结论**：**NTC 可以砍；热保护器不建议全砍，但应该换个装法 —— 让绕线厂埋进变压器绕组里。**

---

## 0. 一句话

**NTC 是"显示和预警"，砍掉只是难看一点；热保护器是"最后一道闸"，砍掉之后
风扇堵转或 1.4 倍持续过载就没有任何东西会拦。**

而且有个两全的做法：**变压器本来就要环氧真空灌封，顺手让绕线厂在绕组里埋一只
NC 温度开关引两根线出来** —— 比外面贴 3 只还强，还顺带解决了灌封体上没地方装 NTC 的问题。

---

## 1. 先算清楚：砍掉之后，还剩什么在保护温度

| 保护 | 在不在 | 管什么 |
|---|---|---|
| **硬件 OC**（AMC23C12，10.3 Arms） | ✅ 在 | **短路**。跳闸点是额定的 **1.46×** |
| **硬件 OV**（AMC23C12，288 Vrms） | ✅ 在 | 开路 / 高阻 |
| **TPA3255 芯片自带过温关断** | ✅ 在（芯片内部） | 功放芯片**自己** |
| **功放模块的 `CLIP_OTW` 告警** | ❌ ADR-017 砍了 | —（MCU 不知道功放热了） |
| **风扇 TACH 转速反馈** | ❌ ADR-016 砍了 | —（风扇停了没人知道） |
| **变压器温度** | ❌ **什么都没有** | — |

🔴 **变压器是整机唯一一个"过热了完全没人管"的大功率件，而且它是环氧真空灌封的 ——
烧了是整块报废，灌封体过热还会开裂冒烟。**

---

## 2. 两个真实的失效场景（不是假想的）

### 场景 A：风扇堵转 —— 这个概率最高

滚珠风扇寿命有限，卡灰、轴承干涸都很常见。ADR-016 砍掉 TACH 之后，
**风扇停转是一个完全静默的故障**。

箱内发热量估算：

```
36V 母线总功耗          71 W
其中变成输出功率的       50 W（送到被测电缆上，不留在箱内）
→ 留在箱内的热量      ≈ 21 W（功放损耗 + 变压器损耗 + 12V 负载 + DRS 自身损耗）
```

21 W 关在一个没有强制风冷的机箱里，温升典型在 **+30~50 °C**。
40 °C 环境 → 箱内 70~90 °C，**变压器自身的温升还要叠加在这个上面。**

**没有热保护器 = 这个故障一直烧到出事为止。**

### 场景 B：1.0~1.45 倍持续过载 —— OC 保护**够不着**

```
额定    7.07 Arms
OC 跳闸 10.3 Arms = 1.46×
```

**也就是说 1.45 倍的持续过载永远不会跳闸。**
50 VA 的变压器长期跑 **72 VA**，铜损按 I² 算是额定的 **2.1 倍** —— 一定会烧。

> 🔴 **硬件 OC 保护的是短路，不是过热。** 这两件事不能互相替代。
> 想靠收紧 OC 门限来覆盖过热是行不通的 —— 门限压到 1.1× 会在感性负载和扫频瞬态上误跳。

正常情况下软件的 CC / VA 环会把输出限在 50 VA，**但这条路依赖 MCU 活着**。
硬件 OC/OV 之所以存在，就是因为「软件卡死了还得有保护」——
过热这件事同样需要一条不依赖 MCU 的路。

### 场景 C（合规）

IEC 61010-1 §10 要求**单一故障（风扇堵转就是典型的单一故障）不得导致危险温度**。
将来要做认证的话，这是硬条款，不是建议。

## 3. 🟢 推荐方案：把热保护器**埋进变压器里**，外置的全砍

变压器本来就是**环氧真空灌封**件，灌封的时候埋一只 NC 温度开关是顺手的事。

```
绕线厂在绕组热点处埋一只 NC 温度开关（或温度保险丝），引两根线出来
        ↓
串进 RLY-01 的 12 V 继电器线圈回路（和门行程开关串在一起，待决 #5）
        ↓
超温 → 线圈断电 → 所有抽头继电器释放 → 输出断开   （完全不经过 MCU）
        ↓
同一条回路的通断状态由已有的 COIL_LOOP → U19 光耦 → PB15 监视，MCU 能看到但管不着
```

| 比外面贴 3 只好在哪 | 说明 |
|---|---|
| **测的是真正的热点** | 外面贴的测的是灌封体表面，滞后几分钟、低十几度 |
| **解决了「灌封体上没地方装」** | 待决 #53 的 T-2（预埋 M4 铜螺母）可以直接取消 |
| **不依赖 MCU** | 硬串在线圈回路里，和 AMC23C12 的硬件 OC/OV 是同一个哲学 |
| **成本几块钱** | 灌封之前放进去，不增加工序 |
| **省掉 3 只 NTC + 3 只 thermostat 的线束和装配** | 机箱件从 6 件减到 1~2 件 |

### 具体要求（加进变压器采购规格书，和 T-1 一起提）

| # | 要求 |
|---|---|
| **T-3** | **在绕组热点处预埋一只常闭（NC）温度开关**，动作温度按绝缘等级定<br>（B 级 130 °C → 取 **110~115 °C**；F 级 155 °C → 取 **130~140 °C**）<br>自动复位型，触点额定 ≥1 A / 250 VAC，引 **两根线到灌封体外**（长度 ≥300 mm） |
| **T-3′** | *（可选）* 同时埋一只 **10 kΩ@25 °C / B3950 NTC**，另引两根线 ——<br>这样面板上还能显示变压器温度、软件还能做降额，而不只是"到点断电" |
| — | 🔴 **T-2（预埋 M4 铜螺母）在采用 T-3 之后可以取消** |

## 4. 那 MAIN-01 上已经画好的部分怎么办

### 4.1 3 路 NTC（`R48`~`R53` / `C69`~`C71` / `CN6`/`CN7`/`CN8`）

审图 #19 已经逐条验过**全对**。三个处理方式：

| 方案 | 做法 | 评价 |
|---|---|---|
| **A（推荐）** | **原理图一个字不改，BOM 里把这 12 个件标 DNP（不贴）** | 零风险、零返工。将来想加（比如采纳 T-3′）只要贴上元件 ✅ |
| B | 从原理图里删掉 | 省下约 15×20 mm 板面和 3 只座子的位置，但要重画、重审 |
| C | 保留并装 1 路（变压器），另 2 路 DNP | 面板上能显示变压器温度，软件能做降额 |

> 🟢 **我建议 A 或 C。** 这 12 个件的物料成本可以忽略，板面也很小，
> 而**已经验证正确的原理图不动，是最省事也最不容易出新错的做法**。

### 4.2 `PB15` / `U19` / `R20` / `R21` / `C53` / `C44`（`COIL_LOOP` 监视）

🔴 **一个都不能省，和热保护器砍不砍无关** ——
这条链监视的是**整个 12 V 继电器线圈回路**的通断，里面串着**门行程开关**（待决 #5）。
即使 3 只 thermostat 全砍，门互锁还在，这条监视链照样要有。

**所以：砍掉热保护器在 MAIN-01 上一分钱、一个引脚都省不下来。**

### 4.3 引脚账

| 情况 | 占用 |
|---|---|
| 现状（3 NTC + COIL_LOOP） | `PC3`/`PA0`/`PA1` + `PB15` = 4 脚 |
| 全砍 NTC，保留 COIL_LOOP | `PB15` = 1 脚，**空闲脚 8 → 11** |
| 方案 C（1 路 NTC） | 2 脚，空闲脚 8 → 10 |

## 5. 如果最后决定**全砍**（外置 NTC + 外置 thermostat + 不埋 T-3）

那必须有东西补上，否则变压器就是裸奔。可行的补偿手段只有一个：

🟡 **用已有的 V/I 测量做软件热模型。**
这台机器本来就在连续测输出 V 和 I（最高 1.25 MSPS），**随时知道真实输出 VA** ——
可以做一个 I²t 积分器：

```
积分时间常数按变压器热时间常数取（灌封件典型 5~15 min，向绕线厂要）
输出 VA > 额定 → 开始积分；积满 → 降额或停机
```

**但要认清它的局限：**
- 🔴 **它依赖 MCU 活着** —— 软件卡死就没有了，而硬件 OC 的存在本身就说明我们不信任这一点
- 🔴 **它管不了风扇堵转**（场景 A）—— 输出 VA 完全正常，箱内照样在升温
- 🔴 **它不满足 IEC 61010-1 §10 的单一故障要求**

→ **软件热模型是补充，不是替代。**

> ✅ **2026-09-18 用户拍板：「可以先把这几个 NTC 加回来」**
> ① **MAIN-01 上 3 路 NTC 全部恢复**（12 件全装，不 DNP）→ `绘图-rev22改动…` §一
> ② 外置 3 只 NC thermostat 仍不采购（本来就是机箱件，MAIN-01 上一个引脚不动）
> ③ 🔴 **T-3（绕组内埋 NC 温度开关）保留为变压器采购条款，优先级反而上升** ——
> 同日 ADR-018 删掉了与门 `U29`，**T-3 成了整机唯一一条不经过 MCU 的保护**，
> 管的正是本文 §2 场景 A（风扇堵转）和场景 B（1.0~1.45× 持续过载）这两段。
> 🟡 NTC 补的是**信息**（显示/报警/降功率），不是**执行**；执行仍然靠 MCU 或 T-3。

### 以下为拍板前的原文分析


| 件 | 建议 | 理由 |
|---|---|---|
| **3 路外置 NTC** | 🟢 **砍**（原理图不动，BOM 标 DNP） | 只是显示和预警；零返工保留将来加回的可能 |
| **3 只外置 NC thermostat** | 🟢 **砍** | 贴在外面测表面温度，滞后大、装配麻烦 |
| **变压器内埋 NC 温度开关（T-3）** | 🔴 **强烈建议加** | 测热点、不依赖 MCU、灌封时顺手、几块钱；<br>它替代的是上面两项的**全部保护价值**，而且更强 |
| 变压器内埋 NTC（T-3′） | 🟡 可选 | 想在面板上显示变压器温度、软件做降额就加 |
| 功放散热器的温度检测 | 🟢 **砍** | **TPA3255 芯片自带过温关断，会自己保护自己** |
| `PB15` / `U19` / `COIL_LOOP` 监视链 | 🔴 **必须保留** | 它管的是门互锁，和热保护无关，砍了也省不下引脚 |

> 🔴 **要是 T-3 也不做**（比如绕线厂不配合），请回到 §5 认清代价：
> 变压器将没有任何独立于 MCU 的过热保护，风扇堵转这个单一故障没有任何拦阻。
> 那样的话至少要做软件热模型 + 在说明书里写明"必须保证通风口不被遮挡"。
