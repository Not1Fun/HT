# 12 V 风扇选型 —— 噪声、EMI、以及一条比 EMI 重要得多的事

> 2026-09-25 · 起因：用户「12V 风扇选型，希望噪音和电磁干扰小一点」
> 前提：**ADR-016 —— 风扇不调速、常开满速。** 这本身就是 EMI 最好的选择（PWM 斩波源不存在）。
> 结论先写：**EMI 不是选型的约束条件，声学噪声和轴承寿命才是；而真正值钱的一条是"做进风不做排风"。**

## 1. 到底需要多少风量 —— 算出来比想象的小得多

### 热量

`热保护方案-NTC与热保护器取舍.md` §2 的账：36 V 母线吃 71 W，其中 50 W 送到被测电缆上
→ **留在箱内 ≈ 21 W**（功放损耗 + 变压器损耗 + 12 V 负载 + 串联电阻损耗）。

🔴 **但那是「不充电」的工况。** DRS 满功率充电时输出 240 W，自身损耗要叠上去：
🟡 **DRS-240-36 的效率规格书里没给（待核实）**，按 AC/DC 模块常见的 90% 估算，
240 W 输出时自身损耗 ≈ **27 W** → **箱内总热量可能到 45~50 W**。

→ **按 50 W 定风量，不是保守过头。**

### 风量公式

```
ΔT = P / (ρ·c_p·Q)        45 °C 空气：ρ·c_p = 1.11 × 1005 = 1116 J/(m³·K)
1 CFM = 4.7195e-4 m³/s
```

| 热量 | ΔT 10 K | ΔT 15 K |
|---|---|---|
| 21 W（不充电） | 3.99 CFM | 2.66 CFM |
| **50 W（充电+满载）** | 9.49 CFM | **6.33 CFM** |

**理论上只要 6.3 CFM。** 再按实际打两次折：

```
机箱内部混合不良（气流短路、死角）              ×2
滤网 + 防护网压损把工作点压到自由风量的 50~70%   ÷0.6
→ 自由风量需求 = 6.33 × 2 / 0.6 ≈ 21 CFM
```

→ 🟢 **选型下限：自由风量 ≥ 25 CFM。** 这是个很轻松的指标，**所以完全没必要用吵的风扇。**

## 2. 噪声：同风量下"大而慢"永远赢

### 风机相似定律（教科书，不是估算）

```
风量 Q ∝ N            静压 Δp ∝ N²          轴功率 ∝ N³
声功率级 L_w ≈ L_w0 + 50·log₁₀(N/N₀)  dB
```

→ **转速减半：风量减半，噪声降 15 dB(A)。**
所以「换大一号的风扇、把转速降下来」是唯一免费的降噪手段。

### 达到 ≈25 CFM 自由风量各尺寸要多快（🟡 典型值，按实际型号规格书核对）

| 尺寸 | 所需转速 | 典型噪声 | 判定 |
|---|---|---|---|
| 60×60×25 | 3500~4000 RPM | **30~34 dB(A)** | 🔴 明显能听见，别选 |
| **80×80×25** | 1800~2200 | **21~25 dB(A)** | ✅ 够用 |
| **92×92×25** | 1400~1600 | **18~21 dB(A)** | ✅✅ 推荐 |
| 120×120×25 | 900~1100 | **15~18 dB(A)** | ✅✅✅ 面板放得下就选它 |

🟢 **建议：面板允许就上 92 mm 或 120 mm 的低速款。** 同样 25 CFM，比 60 mm 安静 **12~16 dB(A)**，
差价几块钱。

### 两条零成本的机械降噪

- 🔴 **用金属丝防护网，不要冲压网板** —— 冲压孔板的湍流噪声比丝网高 2~4 dB(A)
- 🔴 **橡胶减振钉/减振垫代替金属螺钉** —— 否则风扇的振动直接灌进机箱钣金当音箱用
- 🟡 别让风扇顶着高阻力工作：滤棉选粗一点的（换气型），太密的滤网把工作点推到风扇曲线的失速区，
  风量掉、噪声反而涨

## 3. 轴承：连续运行 + 箱内高温，这条比噪声更容易翻车

| 类型 | 寿命 | 噪声 | 判定 |
|---|---|---|---|
| 含油 / 套筒 | 30k h @40 °C，**70 °C 只剩 ~10k h** | 中，老化后明显变大 | 🔴 **不选** —— 连续运行 10k h = **1.1 年** |
| **液压 / 流体动压（FDB/HDB）** | **50k~60k h @40 °C** | **最低** | ✅ **首选** |
| 双滚珠 | **70k h @70 °C** | +2~4 dB，高频啸叫 | 🟡 只有必须做排风（轴承泡在热风里）时才选 |

🟢 **配合 §4 的"做进风"，风扇轴承看到的是环境温度而不是箱内温度** → **FDB 是对的选择**：
最安静，而且 50k h 连续运行 = **5.7 年**。

## 4. 🔴🔴 最值钱的一条：做**进风**（正压 + 滤网），不要做排风

这条和风扇本身的参数无关，但它保护的是**整机爬电间隙判据的立脚点**。

SNS-01 的 1.699 mm、RLY-01 L4 的四对 1.2~2.4 mm，**全部是按「污染度 2」判的**
（只有非导电性灰尘，偶尔凝露）。而：

```
风扇做排风  → 箱内负压 → 从每一条缝隙吸入未过滤的灰尘
            → 几年之后向「污染度 3」漂移
            → 爬电判据要求大幅上升，而 SNS-01 现在本来就还差 0.8 mm（待决 #86）

风扇做进风  → 箱内正压 → 灰尘只能从滤网进来
            → 污染度 2 的假设被主动维持住
```

→ ✅ **风扇装进风位 + 前面加可清洗滤棉，出风口只开百叶不装风扇。**
**零成本，同时拿到三样好处**：轴承在环境温度（寿命 ×5）· 污染度 2 保住 · 灰尘可维护。

🔴 **配套两条必须写进说明书/装配文件**：
① **滤棉的清洗周期** —— 滤网堵了，正压没了、风量掉了、噪声还涨；
② 🟡 **面板开孔要满足 IP2X**（箱内有 223.6 Vrms，手指不可触及带电件）——
标准的风扇防护网 + 滤棉框就够，但要在图纸上写明。

## 5. EMI：算完之后发现它不是约束条件

### 风扇在 2~10 kHz 到底有多少能量

以 92 mm / 1500 RPM / 4 极无刷为例：

```
电气换向基频 = (1500/60) × 2 极对 = 50 Hz
叶片通过频率 = 25 rev/s × 7 叶   = 175 Hz
→ 要落进 2 kHz，需要 40 次谐波
```

梯形波换向电流的谐波大致按 **1/n²** 衰减 → 40 次 ≈ 基波的 **1/1600**。
电流纹波估 30~50% × 0.2 A = 60~100 mA → **40 次谐波约 40~60 µA。**

再叠两层天然抑制：

1. 🟢 **这股电流不流经 `AGND`。** 它在 `GND` 平面里回自己的 DC/DC；
   `AGND` 是星点的**末端支路**，只走自己那 96 mA（这是审图 #26 就地更正过的一条）
   → 风扇纹波不在 `AGND` 铜上产生压降，也就不进差分 ADC 的共模窗口。
2. 🟢 **相干单频点 DFT 的 bin 宽只有 `f_s/L` = 170 kHz / 8500 = 20 Hz**（2 kHz 档）
   → 只有落在测量频点 ±几个 bin 内的东西才进得了读数。

🔴 **唯一的理论弱点**：矩形窗的旁瓣只按约 **6 dB/oct** 衰减（第一旁瓣 −13 dB），
所以"离测量频点几个 bin 的**强**非相干单音"抑制得不好。
**但风扇在这一带只有 µA 级，压根没有这种单音。**

### → 所以 EMI 只要做三件免费的事

1. 🔴 **补上端子电容：`100 µF / ≥25 V` + `100 nF`，就近贴 `U11`。**
   这是本轮唯一一条真正的电气必改（rev23 实测端子上一只电容都没有）。
2. 🔴 **风扇两根线绞起来，贴机箱壁走**；
   **绝不和 `CN4` 那束 SNS-01 模拟线平行长走**，必须交叉时走 90°。
   （那束是唯一真正怕磁耦合的东西 —— 绞线 + 总屏蔽本来就是 ADR-015 要的。）
3. 🟡 **磁珠可选不必需**：`12V辅助电源` 旧版建议的 `FB1`(600 Ω@100 MHz / ≥500 mA)
   是为了压 25 kHz 的 PWM 纹波，ADR-016 取消调速之后那个源没了。想加就加在风扇 +12 V 线上，几毛钱。

### 🔴 决定性的一步是实测，不是看规格书

首板到手后 5 分钟就能做完，比任何 datasheet 都准：

```
接一只固定的无感功率电阻 → DDS 分别跑 2 / 5 / 8 / 10 kHz
每个频点读 V / I / |Z| / 相位，风扇【关】和【开】各记一组
判据：读数变化 < 0.01%（1000 Ω 档最敏感）→ 风扇无影响，收工
若有影响 → 先查是不是线束平行走了，再考虑加磁珠
```

## 6. 选型规格（可直接抄进采购单）

| 项 | 要求 | 理由 |
|---|---|---|
| 电压 | **DC 12 V** | `U11`（`12V` 经 `F5`） |
| 尺寸 | **92×92×25 mm**（面板放得下就 120×120×25） | §2，同风量比 60 mm 安静 12~16 dB(A) |
| 自由风量 | **≥ 25 CFM** | §1，理论只要 6.3 CFM，已含 3.3× 余量 |
| 转速 | **≤1600 RPM**（92 mm）/ ≤1100 RPM（120 mm） | 相似定律：转速减半噪声 −15 dB(A) |
| 噪声 | **≤ 21 dB(A)** | 目标 |
| **轴承** | 🔴 **液压 / 流体动压（FDB / HDB）** | §3，含油套筒 70 °C 只有 1.1 年寿命 |
| 引线 | **2 线（红+黑）即可** | ADR-016 不调速；买到 3/4 线也只接红黑，其余悬空 |
| 电流 | 0.10 ~ 0.25 A（≤0.4 A） | `F5` 1.1 A PPTC，余量 3~7×；12V_AUX 预算 610 mA |
| 工作温度 | **≥ 70 °C** | 箱内 40 °C 环境 + 温升 |
| 安装 | 🔴 **进风位** + 可清洗滤棉 + **丝网防护罩** + **橡胶减振钉** | §4 / §2 |

**余量复核（`F5` = BSMD1206C-1100T）**

```
保持电流 1.1 A @23 °C，🟡 高温降额曲线待核实，按 60 °C 约 0.7× 估 → 0.77 A
风扇稳态 0.10~0.25 A          → 余量 3.1 ~ 7.7×   ✅
启动浪涌 2~3× = 0.3~0.75 A    → PPTC 在 2× I_hold 下动作时间是秒级 → 不会误跳 ✅
PPTC 串联电阻 🟡 待核实（1.1 A/1206 典型 0.1~0.25 Ω）→ 0.2 A 时压降 20~50 mV，可忽略
```
