## 2. X1 三合一模块的画法

**不要自建一个整体的 5 脚符号。** 用立创库现成的插座 / 保险丝 / 开关符号拼出来，外面套虚线框标注
「X1 IEC320 C14 三合一模块（机箱件）」。

理由：
- 保险丝在哪一路、开关断几路，一眼看清，审图和装配不会搞错
- 保险丝规格可直接标在符号旁
- 不用自己建库

BOM 里三个位号（X1 / F_AC / S1）都保留，备注「由 X1 模块集成，不单独采购」。

## 4. RV1（TMOV）的位置 —— 有讲究

**接在开关之后**，与 EMI 滤波器输入并联（跨在 `AC_L` ↔ `AC_N`）。

1. **必须在保险丝之后。** MOV 老化失效模式是短路，只有在熔断器下游，失效时才能被熔断器切掉。
   接在保险丝上游 = 直接短路市电。
2. **放在开关之后更好。** 关机时 MOV 完全断电，不持续承受市电应力、老化慢；
   而关机时下游本来就没东西需要保护。

> ⚠️ **常见错误画法**：把 MOV 接在 `C14.L` 和 `C14.N` 之间（保险丝上游）。不要这样画。

## 5. 开关极数验证（模块到手后必做）

图纸最终画法取决于单刀还是双刀。**不插电**，万用表蜂鸣档：

| 步骤 | 操作 | 结论 |
|---|---|---|
| 1 | 开关 ON，测 `C14.L` 对各出线端子 | 找到 L 的出线端子 |
| 2 | 开关 ON，测 `C14.N` 对各出线端子 | 找到 N 的出线端子 |
| 3 | **开关 OFF**，重测 1、2 | 只有 L 断 = **单刀**；L 和 N 都断 = **双刀** |
| 4 | 开关 ON，**抽掉保险丝**，重测 1、2 | 哪条断了保险丝就在哪一路（**必须在 L**） |
| 5 | 测 `C14.E` 对 PE 端子 | 应直通 0Ω |

**判定：**
- 第 4 步若测出**保险丝在 N 上** → **此模块不可用，退货**。熔断器必须在火线。
- 第 3 步若测出是**单刀** → 可接受，但必须同时满足：
  ① 开关断的是 L 线　② 保险丝在 L 线上　③ 机箱贴警示「检修前必须拔电源线，不能只关开关」
  （国内插座 L/N 反接常见，单刀关机后机内 EMI 与 DRS 输入端可能仍带电）

## 6. 两个容易漏的

### 6.1 X 电容泄放电阻

GB4943 要求拔掉插头后 **1 秒内插头两端降到 37V 以下**。

EMI 模块内部通常自带泄放电阻，但**必须确认**。没有的话外加 **1 MΩ / 0.5 W** 跨接 `AC_L` ↔ `AC_N`。

校验：τ = 1 MΩ × 0.22 µF ≈ **0.22 s** ✅（降到 37% 需 0.22s，降到 37V/311V=12% 需 0.47s）

### 6.2 PE 是螺栓，不是压接

原理图上画个接地符号很简单，但**装配文件里必须写清楚**：

- PE 用 **M4 螺栓 + 齿形垫圈 + 冷压端子**直接压到机箱金属本体
- 螺栓处要**刮掉喷漆/氧化层**露出金属
- **不能靠端子排转接**
- 汇到这个螺柱的：X1/C14.E、FL1 接地端、DRS 的 FG、面板、两个变压器磁芯

这是安规检查必看项。
