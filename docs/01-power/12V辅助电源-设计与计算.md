# 12V 辅助电源（+12V_AUX）· 设计与计算

> 来源：DDR-30L-12（36V → 12V / 2.5A，**DIN 导轨件，不上 PCB**）
> PWR-01 的职责：**接收 → 保护储能 → 分四路出去**。继电器与其驱动不在本板（见 §2）。

## 2. 板级划分：ULN2803 与继电器不放 PWR-01

**结论：驱动器与 8 个小继电器都放继电器板（RLY-01），紧挨变压器。**

| 理由 | 说明 |
|---|---|
| 续流回路要短 | 关断继电器时线圈反峰靠驱动器内部 COM 二极管钳位。驱动在 PWR-01、线圈在另一头的话，几十厘米线束成了天线，di/dt 打出的 EMI 会串进 AMC3301/AMC3330 采样链 |
| 线束少一半 | 驱动在继电器板：8 根 3.3V 信号 + 2 根 12V 电源；驱动在 PWR-01：8 根信号进 + 8 根功率线出 |
| 大电流不跨板 | 12V 侧的 316 mA（G7L）不用在板间来回跑 |

**PWR-01 只给继电器板供 12V（J11，2 根线 + 一个熔断器）。**

## 3. PWR-01 上的 12V 电路

```
J7 (2P 5.08mm) ← DDR-30L-12 输出
   │
+12V_AUX ─┬─ D3  TVS SMBJ15A ─┐
          ├─ C20 470µF/25V    │
          ├─ C21 10µF/25V     ├─ GND_AUX
          ├─ C22 100nF        ─┘
          │
          ├──────────────→ 板内 4× PC817C 一次侧（各串 3.3kΩ，R20–R23）
          ├─ PTC1 0.5A ──→ J9  风扇 4P
          ├─ PTC2 0.1A ──→ J10 蜂鸣器 2P
          └─ F4 T1A ─────→ J11 继电器板 2P
```

**星点接地**：`GND_AUX ──[ R101 0Ω 2512 ]── DGND`（按 ADR-004，单点星接）

### 3.1 D3 选 SMBJ15A，不是 SMBJ13A

DDR-30L-12 输出电位器可调 ±10% → 最高 **13.2 V**。

| 型号 | Vrwm | Vc | 判定 |
|---|---|---|---|
| SMBJ13A | 13 V | 21.5 V | ❌ 13.2 V 已超 Vrwm，会持续漏电发热 |
| **SMBJ15A** | **15 V** | 24.4 V | ✅ 余量足够；钳位 24.4 V，12V 器件短时（µs 级）能扛 |

> 若确认 DDR 输出固定在 12.0 V 不做调整，可改 SMBJ13A 获得更低钳位电压。

### 3.2 C20 = 470 µF 的依据

最坏动态负载 = 两只 G7L 同时吸合，316 mA 阶跃。

```
DDR 环路响应按 200 µs，允许母线跌落 ΔV = 0.5 V
C ≥ I·t / ΔV = 0.316 A × 200 µs / 0.5 V = 126 µF
```

取 **470 µF / 25 V 低 ESR 电解**，余量 3.7× ✅
配 C21 10 µF/25V X7R 1210 + C22 100 nF/50V X7R 0805 做高频去耦。

### 3.3 ⚠️ 继电器板那路必须用熔断器，不能用 PTC

**PTC 跳闸后不是断开**，而是进入高阻但仍有几伏残压的状态。
继电器会卡在**半吸合 / 抖动**，触点持续拉弧 —— 对 KSAFE 安全切断继电器来说，
这比彻底断开危险得多。

- **J11（继电器板）→ F4 = T1A 熔断器**（377 mA 工作电流，2.65× 余量）
- J9（风扇）、J10（蜂鸣器）不是安全相关，用 PTC 自恢复没问题

PTC 内阻校核：0.5 A 保持的 PTC 内阻约 0.5–1 Ω，200 mA 时压降 0.1–0.2 V，
风扇不敏感 ✅

## 4. 风扇 4 线接口（J9）—— 最容易画错的一块

```
J9.1  GND_AUX
J9.2  +12V_AUX  (经 PTC1，再串磁珠 600Ω@100MHz + 就近 100nF 到 GND_AUX)
J9.3  TACH  ──┬─ R30 10 kΩ 上拉到 3V3_D
              └─ R31 100Ω + C23 1nF ─→ J3 (FAN_TACH)
J9.4  PWM   ──── Q10 (2N7002) 漏极
                 源极 → GND_AUX
                 栅极 ← R32 100Ω ← J3 (FAN_PWM)
                 R33 100 kΩ 栅源下拉
```

### 4.1 PWM 必须开漏驱动，不能 3.3V 推挽直驱

4-wire 风扇的 PWM 引脚**内部上拉到风扇自己的 5V**。MCU 用推挽输出 3.3 V 高电平顶上去，
会有电流从风扇的 5V 经上拉倒灌进 MCU 引脚，长期损坏 IO。
Intel 4-wire 规范要求外部用**开漏**拉低。

### 4.2 逻辑是反的

Q10 导通 → PWM 脚被拉低 → 风扇减速。
**MCU 侧输出需反相**，软件处理，写进接口文档。

### 4.3 R33 是失效安全设计

MCU 复位或掉电 → Q10 关断 → PWM 脚被风扇内部上拉拉高 → **风扇全速**。

这个默认状态是对的：**MCU 死了风扇全速，比停转安全**。

### 4.4 PWM 频率必须 25 kHz

Intel 4-wire 规范 21–28 kHz，取 **25 kHz**。

> ⚠️ **这台设备是 2–10 kHz 音频源，风扇 PWM 绝不能落在测量带宽内。**
> 25 kHz 在带宽之上，安全。但 25 kHz 的电流纹波会耦合到 12 V 与 36 V 母线，
> 所以风扇电源线串磁珠 + 就近 100 nF。
> 若实测仍有干扰，软件可在测量窗口内把风扇切到固定转速或短时停转。

### 4.5 TACH

风扇 TACH 是**开漏输出**，上拉到 3V3_D 即可（不会输出 5V，无电平冲突）。

```
2 脉冲/转，2000 rpm → 66.7 Hz
RC 滤波 100Ω + 1nF → 截止 1.6 MHz，完全不影响
```

> 注：TACH 在 GND_AUX 域、上拉在 DGND 域，靠 ADR-004 的星点共地才成立。
> 若将来要把 12V 域真正隔离，此处需改为光耦。

## 5. 蜂鸣器（J10）

```
+12V_AUX (经 PTC2) → J10.1 ─ 蜂鸣器 ─ J10.2 → Q11 (2N7002) 漏极
                     D5 (1N4148) 并联续流，阴极接 12V 侧
                     Q11 源极 → GND_AUX
                     Q11 栅极 ← R34 100Ω ← J3 (BUZZER_EN)
                     R35 100 kΩ 栅源下拉
```

- 2N7002：60 V / 115 mA。Vgs = 3.3 V 时 Rds(on) ≈ 7 Ω → 20 mA 下压降 **0.14 V** ✅
- R35 下拉：MCU 复位时蜂鸣器不叫（失效安全）
- D5 续流：有源蜂鸣器内含线圈，关断有反峰

## 6. 继电器驱动器：ULN2803ADWR → 建议换 TBD62083A

**位置在继电器板，但型号现在定。**

| | ULN2803ADWR | **TBD62083A** |
|---|---|---|
| 输出类型 | 达林顿（双极） | DMOS |
| 3.3V 逻辑 | datasheet 全按 Vin=5V 标定 | **输入 2.5 V (min) 即导通，明确兼容 3.3V** |
| Ic = 200 mA 时压降 | Vce(sat) **1.0 – 1.3 V** | Ron 2.0–3.25 Ω → **0.4 – 0.65 V** |
| 引脚 | — | **引脚兼容，可直接替换** |

### 3.3V 驱动 ULN2803A 的核算

```
Ib = (3.3 V − 1.4 V) / 2.7 kΩ = 0.70 mA
达林顿 hFE > 1000 → Ic 能力 ≈ 700 mA >> 需要的 44 mA (G2RL-2)
```

**电流上是够的**，不会不导通。问题在于 datasheet 的 VOL / IC 特性曲线全部按 Vin = 5 V 标注，
3.3 V 下没有保证值。TBD62083A 价格相近、引脚兼容，换掉是零成本改进。

### ⚠️ 审图必查：pin 10 (COM) 必须接 +12V_AUX

不接的话内部续流二极管不起作用，关断继电器时线圈反峰（可达上百伏）直接打在输出管上。
**这是这颗片子最经典的死法。**

### 建议补充：输入端加 10 kΩ 下拉

TCA9535 上电默认是高阻输入态。虽然 ULN2803/TBD62083 内部有 B-E 下拉能保证不误导通，
但外部加 10 kΩ 下拉更稳妥（配合 ADR / 评审 P0-5 的 TCA9539 RESET 方案做冗余）。
