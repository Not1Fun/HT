# SNS-01（采样/保护板）· 三个地怎么铺铜

> 2026-09-16 · 用户问「`DGND`/`AGND`/`HV_GND` 哪些能铺大面积地铜」
> 依据：`Netlist_SNS-01_20260914_rev5.tel`（审图 #25 已收口）+ `PCB阶段检查清单.md` §二.5

---

# 〇、一句话结论

**三块全都要铺，而且都应该铺满各自的区。**

这块板上真正的功夫**不在"铺不铺"，而在"缝"和"禁布区"** ——
铺铜本身只会让三个地更干净，会出事的是**两块铜在某个角落连上了**，
或者**自动铺铜流进了隔离槽**。

| 地 | 铺？ | 载流 | 一句话 |
|---|---|---|---|
| **`HV_GND`** | 🟢 **铺满整个高压区** | ≈ **15 mA**（全是直流） | 38 个引脚、四颗 IC 的高压参考、20 只去耦电容的地 —— **必须整块铜** |
| **`AGND`** | 🟢 **铺满模拟子区** | ≈ **96 mA** | ADR-015 禁的是**第二个接地点**，不是铺铜。铺铜反而好 |
| **`DGND`** | 🟢 **铺满数字子区** | ≈ **64 mA 开关电流** | `UCC12050` 一次侧的开关电流全在这块铜上 —— **这块反而是最"脏"的** |

# 一、板子的物理分区（可以直接照这个摆）

网表把布局基本定死了，没有自由度：

```
┌──────────────────────────────┬──╳──┬──────────────────┬──────────────────┐
│        高压区 HV_GND          │ 隔  │   模拟子区 AGND   │  数字子区 DGND    │
│                              │ 离  │                  │                  │
│  U30(输入2P) RS1(shunt) U6   │ 槽  │   U4/U5 的       │   U1/U2/U3 的     │
│  (输出2P)                    │ ≥8.5│   低压侧         │   低压侧          │
│  两条分压链 R2~R7 / R12~R19   │ mm  │   C17 C21 C22    │   C4 C5 C9 C10    │
│  20 只高压侧去耦              │     │   C29 C30 C31    │   C11 C13         │
│  5V_ISO 岛 (U3 二次侧)        │     │   CN4 (9P)       │   CN9 (8P)        │
└──────────────────────────────┴──╳──┴──────────────────┴──────────────────┘
        ↑ 一块连续的铜             ↑           ↑ 两块互不相连的铜 ↑
                                四颗 IC 全骑在这条线上
                                      ↑ AGND/DGND 的分缝垂直于隔离栅，一直延伸到槽边
```

## 1.1 🔴🔴 四颗 IC 的朝向：**`U3` 和另外三颗是反的**

从 rev5 网表逐脚验证出来的（这条极容易画错）：

| IC | 高压侧引脚 | 低压侧引脚 | 朝向 |
|---|---|---|---|
| `U1` `U2` AMC23C12 (SOIC-8) | **1~4** (`5V_ISO`/`IN`/`REF`/`GND1`) | 5~8 (`DGND`/`OUT`/`LATCH`/`3V3_SNS`) | 低脚号朝高压 |
| `U4` AMC3301 (SOIC-16 DWE) | **1~8** | 9~16 | 低脚号朝高压 |
| `U5` AMC3330 (SOIC-16 DWE) | **1~8** | 9~16 | 低脚号朝高压 |
| 🔴 **`U3` UCC12050 (SOIC-16)** | **9~16**（`GNDS`/`VISO`） | **1~8**（`VINP`/`GNDP`） | 🔴 **低脚号朝低压 —— 正好相反** |

→ 🔴 **四颗都骑在同一条直线上时，`U3` 要相对 `U4`/`U5` 旋转 180°。**
**判据**：摆完之后，`U3.9`~`U3.16` 和 `U4.1`~`U4.8` 必须在槽的**同一侧**。

## 1.2 谁挨着谁

- `U4`/`U5`（两片 AMC 测量）的低压侧 → **`AGND` 子区**，正对 `CN4`
- `U1`/`U2`（OC/OV）+ `U3`（UCC12050）的低压侧 → **`DGND` 子区**，正对 `CN9`
- 🔴 沿隔离栅从一头排过去建议：**`U4` `U5` | `U1` `U2` `U3`**
  —— 让 AGND/DGND 的分缝正好落在 `U5` 和 `U1` 之间，垂直切到槽边

# 二、`HV_GND` —— 🟢 必须铺，而且铺满

## 2.1 它是什么

**38 个引脚**，全板最大的网：

```
RS1.3（开尔文取样·窄脚）  ← 唯一的"零点"
四颗 IC 的高压参考   U1.4 U2.4 · U3.9~.12/.15/.16 · U4.2/.8 · U5.2/.7/.8
两条分压链下臂       R6.1（OV 链）· R19.1（测量链）
两只 REF 电阻下臂     R10.2 · R11.2
AMC3301 的 INN 滤波   R9.1
20 只高压侧去耦电容的地脚
```

## 2.2 🔴 为什么**必须**是整块铜，不能用细线

`HV_GND` 上大约有 **15 mA**（`UCC12050` 输出 8.6 mA + 两条分压链 0.77 mA +
两片 AMC 高压侧自耗 ~6 mA 🟡**待核实**）。这股电流流过芯片 `HGND` 脚到 `RS1.3`
之间的铜，**直接叠在被测的 shunt 电压上**：

| 连接方式（10 mm 距离，2 oz） | 电阻 | 误差电压 | 1 Ω 档占比 | 1000 Ω 档占比 |
|---|---|---|---|---|
| **10 mm 宽铺铜 = 1 □** | **0.240 mΩ** | **3.7 µV** | 25 ppm | 790 ppm |
| 0.25 mm 细线 | 9.60 mΩ | 148 µV | 983 ppm | **31600 ppm = 3.2%** 🔴 |

→ **铺铜比细线好 40 倍**，这就是答案。

> 🟢 **而且这 15 mA 基本是直流** → 落在 DC bin，**不进相干 DFT 的 f bin**，
> 对交流读数没有影响。真正要防的是 `UCC12050` 的**开关纹波**（MHz 级，🟡 频率待核实）——
> 它被 AMC 输入端的 `10Ω+10Ω+10nF`（TI 图 8-2）就地滤掉 ✅

## 2.3 🔴 三条硬约束

| # | 约束 | 为什么 |
|---|---|---|
| **H-1** | 🔴🔴 **`HV_GND` 铺铜绝不能碰到 `TR_COM` / `SHUNT +`(OUT-) / `HV+` 三块功率铜** | 那三条走 **7.07 A**。`HV_GND` 只从 `RS1.3`（窄脚）取，`TR_COM` 只从 `RS1.4`（宽脚）取 —— **两者只在电阻片内部相连**（审图 #23 定稿）。铜碰上 = 开尔文作废 + 7 A 从参考铜上流过 |
| **H-2** | 🔴 **四颗 IC 尽量靠近 `RS1`**，让铺铜上任意两点 ≤1 □ | 见 2.2 的表；距离翻倍误差翻倍 |
| **H-3** | 🔴 **`RS1.3` 接进铺铜的那一点就是"开尔文点"**，S-8 要求的「`HGND` 单独走线」在整块铜上自动满足 —— **前提是 H-2** | TI §8.3 |

> 🟡 **`R9`（AMC3301 的 `INN` 滤波）的位置**：它也在 `HV_GND` 上。
> 🔴 **把 `R9` 的地脚放在离 `RS1.3` 最近的地方**，别放到铺铜的远端，
> 否则 `INN` 和 `HGND` 之间会多出一段铜阻 —— 这正是 TI §8.3 在防的事。

# 三、`AGND` —— 🟢 可以铺，而且应该铺

## 3.1 🔴 先澄清一个最容易误读的地方

ADR-015 写的是：

> **「AMC 低压侧的 `GND2` 只经线束接主板 `AGND`，采样板上不得就地接地。」**

🔴 **「不得就地接地」= 不许有第二个接地点**（机壳 / PE / 金属柱 / `DGND`），
**不是「不许铺铜」。** 这两件事完全不同。

SNS-01 上的 `AGND` 是**一块只经 `CN4.2/.5/.8` 三根线回主板的孤岛铜** ——
铺大铺小都改变不了它的电位，**铺大反而给两片 AMC 的输出级一个干净的就地参考**。

## 3.2 它载多少

`3V3_AVDD` 给两片 AMC 的低压侧供电 ≈ **96 mA**（就是 MAIN-01 上 `U6` 线性稳压器
原样传过去的那 96 mA），全部经 `CN4` 的三根 `AGND` 回线流走。

- 1 oz 铺铜 1 □ = 0.48 mΩ → 96 mA 产生 **46 µV**
- 对比差分 ADC 的共模窗口 **±170 mV** → 余量 **3700 万倍** ✅ 完全不是问题

🔴 **但那 96 mA 里含两片 AMC 内部 DC/DC 的开关分量** →
`C21`/`C22`（`U4` 的 3V3_AVDD）· `C30`/`C31`（`U5` 的）· `C17`/`C29`（两片的 `DCDC_IN`）
**必须贴着各自的芯片放**，让开关电流就地闭环，**铺铜上和线束里只剩直流**。
（这与 MAIN-01 那头 `C54` 10µF + `C55` 100nF 贴 `CN4.9` 是同一件事的两头。）

## 3.3 🔴 三条硬约束

| # | 约束 |
|---|---|
| **A-1** | 🔴🔴 **绝对不能有第二个接地点**：不接机壳、不接 PE、**不碰任何金属安装柱**、不和 `DGND` 相连 |
| **A-2** | 🔴 **所有安装孔周围画禁布环**（建议 NPTH 非金属化孔）—— 一颗金属柱就把 ADR-015 破了，而且**排查起来极难** |
| **A-3** | 🔴 铺铜要**包住 `U4`/`U5` 的输出脚到 `CN4.3/.4/.6/.7` 那两对差分线**，并保证 `CN4.2/.5/.8` 三个回线脚到两片 AMC 的 `GND`(9)/`DCDC_GND`(15) 之间是最短的铜 |

# 四、`DGND` —— 🟢 可以铺，**而且这块最需要铺**

## 4.1 它是全板最"脏"的一块

16 个引脚：`CN9.1/.2/.5` + `U1.5`/`U2.5`（AMC23C12 的 `GND2`）+
`U3.2/.4/.6/.7/.8`（UCC12050 一次侧 `GNDP` + NC）+ 6 只去耦。

🔴 **`UCC12050` 一次侧的 64 mA 全在这块铜上**，而且它内部是个高频 DC/DC ——
**这是 SNS-01 上唯一的开关电流源。**

## 4.2 🔴 三条硬约束

| # | 约束 | 为什么 |
|---|---|---|
| **D-1** | 🔴 **`C11`/`C13`（`5V_SNS` 去耦）贴 `U3.1`/`U3.3` 放** | 让 64 mA 的高频分量在 `U3` 脚下就地闭环，铺铜上和 `CN9` 线束里只剩直流 |
| **D-2** | 🔴 **`U3` 的地脚 → `CN9.1/.2/.5` 走最短最宽的铜** | 那 64 mA 的直流回路 |
| **D-3** | 🟡 **`DGND` 铺铜和 `AGND` 铺铜之间留明确的缝，缝里不塞走线** | 两块铜大面积并排 = 容性耦合。<br>🟢 量级上不致命（主板差分 ADC 抑制共模），<br>🔴 但**主板的抗混叠只有单极点 75.8 kHz** → 1 MHz 处只衰减 **−22 dB**、2 MHz 处 **−28 dB**，MHz 噪声折叠进来的抑制并不宽裕。规则免费，照做 |

# 五、层数建议：🟢 **两层板（外层 2 oz）就够，而且比四层更安全**

| 理由 | 说明 |
|---|---|
| **2 oz 外层是硬需求** | S-2 要求三条 7.07 A 铜各 ≥5 mm @2 oz。两层板做 2 oz 是常规、便宜 |
| **没有快信号** | 全板最快的是 AMC 的输出（275 kHz 带宽）和 `OC_FAULT#`/`OV_FAULT#` 的沿。不需要紧邻参考面 |
| 🔴 **四层反而更容易出事** | 内层也要跟着开槽、跟着分三块；隔离栅下多两层铜 = 多两次画错的机会。**5 kV 栅上不值得为"少走两根线"冒这个险** |

🔴 **两层板的铺铜规则**：
- **顶层和底层都铺**，同一块区**在两层上形状一样**
- 🔴 **底层的隔离槽、AGND/DGND 分缝，和顶层严格对齐** —— 和 MAIN-01「L4 照抄 L2 分区」是同一条
- 同区的顶/底铜用**过孔缝合**（沿 `RS1` → 四颗 IC 的开尔文路径上多缝几个）
- 🔴 **缝合过孔同样不许进禁布区**

# 六、🔴🔴 禁布区清单（自动铺铜最容易流进去的 5 处）

**立创的自动铺铜会钻进每一个角落，光靠 DRC 间距规则不够，要画"禁止铺铜区"。**

| # | 位置 | 要求 |
|---|---|---|
| **K-1** | 🔴🔴 **隔离槽** | 画成一条贯穿板子的**矩形禁布区**，宽度 🔧 **取 ≥8.5 mm**（不是 8 mm）—— 按四颗 IC 里要求最高的 `AMC23C12`（CLR/CPG ≥8.5 mm）取，**别让 PCB 成为短板**。槽本身（铣槽）在禁布区正中 |
| **K-2** | 🔴 **`RS1` 的两颗 M3 螺丝孔** | 🔴🔴 **它们在带电侧**（shunt 铝壳就在 7.07 A 主回路上）—— **绝不能用金属柱连到机箱**。周围留禁布环 + 按 223.6 Vrms 算爬电 |
| **K-3** | 🔴 **所有低压侧安装孔** | 禁布环 + 建议 NPTH，防止 `AGND` 或 `DGND` 经金属柱落到机箱（破 A-1） |
| **K-4** | 🔴 **`AGND` / `DGND` 之间的分缝** | 画成禁布区，别只靠"两块铜各自的 net"—— 自动铺铜在窄处会把两块连起来 |
| **K-5** | 🔴 **`HV_GND` 铺铜 vs 三条功率铜（`HV+`/`TR_COM`/`SHUNT +`）** | 见 H-1。在 `RS1` 周围画禁布区，把取样铜和电流铜隔开 |

# 七、出板前自检（铺完铜逐条过）

1. 🔴🔴 **把三块铜分别高亮**：`HV_GND` / `AGND` / `DGND` **必须是三块完全分开的铜**
   （SNS-01 上它们永远不相连，星点在 MAIN-01 的 `R13`/`R16`）
2. 🔴🔴 **顶层和底层各看一遍**，底层最容易漏
3. 🔴 **沿隔离槽走一圈**，确认**没有任何铜、过孔、丝印油墨进入 8.5 mm 禁布区**
4. 🔴 `U3.9`~`U3.16` 和 `U4.1`~`U4.8` **在槽的同一侧**（§1.1 的朝向判据）
5. 🔴 `HV_GND` 铺铜**没有碰到** `HV+` / `TR_COM` / `SHUNT +` 任何一块功率铜
6. 🔴 `RS1.2`/`RS1.3` 两根开尔文线**紧贴并行当差分对走**，没有被铺铜"顺手"短路（S-3）
7. 🔴 每个安装孔周围都有禁布环；**`RS1` 的两颗 M3 不接机箱**
8. 🔴 `C11`/`C13` 贴 `U3.1/.3`；`C21`/`C22`/`C30`/`C31`/`C17`/`C29` 贴各自芯片
9. 🔴 四颗 IC 到 `RS1` 的铺铜路径 ≤1~2 □
