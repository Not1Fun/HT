## 二.5、🔴 SNS-01（高压板）专属布局条款

| # | 要求 |
|---|---|
| S-1 | 🔴 **整个高压区在隔离栅的同一侧**：`HV+` 走线 + `HV_GND` 铜 + `RS1` + 两条分压链 + 四颗 IC 的高压侧。<br>隔离栅是一条**直线**、下面**开槽**、**≥8 mm**（`AMC23C12` CLR/CPG ≥8.5 mm、`UCC12050` >8 mm），四颗 IC 全部骑在栅上 |
| S-2 | 🔴 **两条 7.07 A 走线**（`J4.1→HV+→J3.1` 和 `J3.2→RS1→J4.2`）各 ≥5 mm @2 oz（PCB 阶段按 IPC-2152 定准确值） |
| S-3 | 🔴 **`RS1` 的两根开尔文取样走线紧贴并行（当差分对走），远离主电流回路，环路面积最小**<br>—— 这部分互感是**标定不掉**的相位误差（随布局和电流方向变） |
| S-4 | 🔴 `RS1` 是 **22.5×17.5×8 mm 通孔四脚 + M3 螺丝（0.9 N·m）**：板面提前留位、留 M3 孔、下方铺铜散热（0.750 W） |
| S-5 | 🔴 `HV+` ↔ `HV_GND` 是**功能绝缘**（都是危险带电）；它们**对 `AGND`/`DGND`** 才是**加强绝缘**。两类间距分开算 |
| S-6 | 🔴 板上**三个地互不相连**：`HV_GND` / `AGND`（只从 `CN4` 来）/ `DGND`（只从 `CN9` 来） |
| S-7 | 🔴 `UCC12050` 的 `VISO` 旁路电容（`C12`/`C14`）地脚接 **15 脚**（手册指定），不是 9/16 脚 |
| S-8 | 🔴 AMC3301/AMC3330 的 `HGND`(8) 用**单独一根走线**到 `RS1` 的取样脚，不在芯片脚下和 `INN` 短接（TI §8.3 精度条款） |
| **S-9** 🆕 | 🔴 **三块地铺铜与禁布区** → **`docs/05-pcb/SNS-01-PCB铺铜与分区.md`**（2026-09-16）<br>结论：**`HV_GND`/`AGND`/`DGND` 三块全都要铺满各自的区**（铺铜比细线好 40 倍）；<br>真正会出事的是**两块铜在角落连上**或**自动铺铜流进隔离槽** → 5 处禁布区要**画出来**，别只靠 DRC |
| **S-10** 🆕 | 🔴🔴 **`U3`(UCC12050) 的朝向和另外三颗相反**：`U3` 一次侧是 **1~8**，而 `U1`/`U2`/`U4`/`U5` 的**高压侧**是低脚号<br>→ **`U3` 要相对 `U4`/`U5` 旋转 180°**。判据：`U3.9`~`U3.16` 和 `U4.1`~`U4.8` 在槽的**同一侧** |
