# KSAFE 互锁链 · `COIL_LOOP` 是什么 · 什么情况下输出会被切断

> 2026-09-19 建立。起因：用户「不是由 MCU 控制，我想问在什么情况下继电器会被关断，`COIL_LOOP` 是什么」。
> **这份文档同时结掉挂了很久的待决 #5（门互锁是否硬串线圈回路）和 #22（具体接法）** ——
> 因为 RLY-01 PCB v4 画出来的就是那个接法，这里把它定稿。

## 1. `COIL_LOOP` 是什么

**它是「安全链走完之后、KSAFE 线圈之前」的那个节点**，网名字面意思就是"线圈回路"。
RLY-01 上只有三样东西挂在它上面：

```
'COIL_LOOP' ; D1.1  P1.2  U7.1
```

| 成员 | 是什么 |
|---|---|
| `P1.2` | 从机箱那条安全链**回来**的那根线（3P 端子的中间脚） |
| `D1.1` | 续流二极管的**阴极** |
| `U7.1` | 送去 MAIN-01 `CN2.3` 的**监视线** |

### 完整接线（RLY-01 ↔ 机箱 ↔ MAIN-01）

```
RLY-01                                    机箱内
─────────────────────────────────────────────────────────────────────
P1.1 = 12V  ───────────────→  门互锁开关 (NC) ──→ T-3 温度开关 (NC) ──┐
                                                                      │ 节点 A
P1.2 = COIL_LOOP  ←───────────────────────────────────────────────────┤
  ├── D1 阴极（阳极接 DGND）                                          │
  └── U7.1 ──→ MAIN-01 CN2.3                                          ├→ KSAFE_A 线圈
                 └─[2.2 kΩ]→ U19 PC817C → PB15（MCU 只能读）          └→ KSAFE_B 线圈
                                                                            │
P1.3 = DGND ←───────────────────── 两只线圈的另一端 ────────────────────────┘
```

> 🔴 **装配文件必须写死**：机箱那三根线的去向就是上面这张图。
> `P1.1` 出去、经过链、**从 `P1.2` 回来**，两只线圈接在「`P1.2` 回来的那个节点」和 `P1.3` 之间。
> 画错成「`P1.1` → 链 → 线圈 → `P1.3`，`P1.2` 另外接在链的上游」的话，
> **`D1` 就跑到互锁触点外面去了，续流失效。**

### 一句话
**`COIL_LOOP` 上有没有 12 V ＝ 那条安全链通不通。**
MCU 通过 `PB15` 只能**读**这一位（链通 = LED 亮 = `PB15` 低，和四路 DRS 干接点同一套极性），
**读到了也管不着** —— 它没有任何手段去开或关这条链。

## 2. 🔴 什么情况下 KSAFE 会被切断（= 输出被物理断开）

### 会断的 —— 只有四条，全是「失电即释放」

| # | 条件 | 谁断的 | 断开延时 |
|---|---|---|---|
| **1** | **机箱门被打开** | 门互锁开关（NC，门关合、门开断） | 机械释放 ≤30 ms<br>+ 续流衰减 9.4 ms<br>≈ **39 ms** |
| **2** | **变压器绕组过热** | **T-3**（绕组热点内埋 NC 温度开关） | 同上 |
| **3** | **12 V 没了** —— 整机断电 / MAIN-01 的 `F5`(T1A) 熔断 / `U11`↔`U12` 线束脱落 | — | 同上 |
| **4** | **`P1` 线束脱落，或链上任何一个接点开路** | — | 同上 |

✅ **失效安全方向全对**：任何东西坏掉、断掉、掉电，结果都是「线圈失电 → KSAFE 释放 → 输出两极断开」。

（延时的来源见审图 #33 §4：G7L 手册机械释放 **≤30 ms**；`D1` 让线圈电流从 158 mA
按 τ = L/R = 0.37 H / 75 Ω = **4.93 ms** 衰减到必释放的 24 mA，要 **9.36 ms**。
门从开缝到手能伸进去是几百 ms 量级 → 39 ms 完全够。）

### 🔴 不会断的 —— 这是最容易想当然的一块

| 事件 | KSAFE | 那谁在管？ |
|---|---|---|
| **硬件 OC 跳闸**（AMC23C12，10.3 A = 额定 1.46×） | ❌ **不动** | `OC_FAULT#` → MCU `PD2` EXTI → 停 DAC/DMA → 静音（**<1 µs**） |
| **硬件 OV 跳闸**（288 Vrms = 1.29×） | ❌ **不动** | `OV_FAULT#` → MCU `PB3` EXTI → 同上 |
| **MCU 复位 / 跑飞 / 死机** | ❌ **不动**（它根本不接 MCU） | `C65` 2.2 µF 隔直 → 输出归零；MCU 跑飞则只剩 IWDG |
| **软件想关输出** | ❌ **没有这条路径** | 只能靠静音功放 |
| **拔掉采样板**（`SNS_PRESENT#`） | ❌ **不动** | 只通知 MCU，软件禁止输出 |
| **面板 `SYSTEM ENABLE` 按键** | ❌ **不动** | 它只是 TCA9539 的 `P16` 一路**输入**，软件读 |
| **抽头对抽头短路** | ❌ **不动** | 🔴 **没人管**（待决 #71 结案后只剩软件互斥） |

> ### 🔴 一句话记住
> **KSAFE 管的是「人」和「变压器过热」，不管过流过压。**
> 过流过压的执行机构是 **MCU 的中断服务程序**（ADR-018 定的），不是继电器。

## 3. 🟡 由此暴露的一个缺口（ADR-018 自己记过，这里把补法算清楚）

ADR-018 删掉与门之后，那张表里留了一行：

> 🔴 **MCU 跑飞但 DMA 还在输出** —— **唯一没人管的**，只有 IWDG（`t_tout` min 0.9 s / max 2.5 s）→ 最坏 **2.5 s**

**KSAFE 本来是补这个缺口的最佳人选** —— 它是全机唯一一个能**物理断开 223.6 Vrms** 的东西，
而且完全不依赖 MCU。但按现在的接法，它和 OC/OV 毫不相干。

### 要补的话：把 OC/OV 串进 `COIL_LOOP` → `DGND` 那一段

```
COIL_LOOP ──→ [机箱：两只 KSAFE 线圈] ──→ P1.3 ──→ [Q1 低边 N-MOS] ──→ DGND
                                                        G ← HARD_OK（经 CN3 从 MAIN-01 来）
                                                        G ← 10 kΩ 下拉到 DGND
D1 阳极跟着挪到 P1.3（MOSFET 在续流回路外）
```

| 项 | 内容 |
|---|---|
| **逻辑** | MOSFET 和互锁链**串联 = 与**：门开 **或** 过流 **或** 过压，任一条都断 ✅ 原来那道一点没被削弱 |
| **速度** | **39 ms**（vs MCU 静音 <1 µs）→ 它是**后备**，不是主力 |
| 🔴 **要先把两根故障线做"与"** | 待决 #54 把 `OC_FAULT#`/`OV_FAULT#` **拆成了两根**（为了分辨是哪一种）。<br>不能直接并（并了就丢诊断）→ 在 MAIN-01 上用**两只二极管做线与**（阴极各接一根故障线、阳极并起来 + 一只上拉）还原出一个 `HARD_OK` 节点 |
| **硬件代价** | MAIN-01：2 只二极管 + 1 只上拉；RLY-01：1 只 N-MOS（320 mA → `AO3400` 一类，🔴 `BSS138` 200 mA 不行）+ 1 只 10 kΩ 下拉；`CN3` **10P → 12P** |
| 🟢 **顺带的好处** | AMC23C12 是**锁存**的 → 跳了就一直断到软件清 `PROT_LATCH` 为止，**故障后不自恢复**，这正是想要的 |
| 🔴 **顺带的代价** | 开机时 `PROT_LATCH` 没清之前 KSAFE 起不来 → 上电顺序要加一步「先清锁存再合 KSAFE」 |

**用不用由你定** —— 记成待决 #80。不做也不是错，只是那条「MCU 跑飞 2.5 s」的窗口继续留着。

## 4. ✅ 待决 #5 / #22 结案

- **#5「门互锁是否改成硬串继电器线圈回路」→ 是，已经这么画了。** 门互锁开关**不只是**给 TCA9539 `P17` 看的，
  它的 NC 触点**硬串在 KSAFE 的 12 V 线圈回路里**。
- **#22「具体接法」→ 见本文 §1 那张图。** 三根线：`P1.1`=12V 出、`P1.2`=链回来（= `COIL_LOOP`）、`P1.3`=地。

🔴 **机箱侧两条采购/装配要求**：
1. **门互锁开关**：NC 触点，按 **12 V DC / 0.4 A 感性负载**选（不是信号级微动开关）。
   🟢 `D1` 已经在板上钳位了，触点只承受 12 V + 二极管压降。
2. **T-3 温度开关**：NC、自动复位、绕组热点内埋，动作温度**比软件停机阈值高 10~15 °C**，
   串在门互锁之后。**写进变压器采购规格书。**
