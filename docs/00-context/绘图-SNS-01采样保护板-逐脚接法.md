# 〇、先把"地"理清楚 —— 这块板上有 **3 个互不相连的地**

| 网络 | 是什么 | 从哪来 | 🔴 硬性约束 |
|---|---|---|---|
| **`HV_GND`** | 高压侧参考 = **shunt 的变压器那一端** | 板上的 `J3.1` | 🔴 **两片 AMC23C12 的 `GND1`、`UCC12050` 的 `GNDS`、`AMC3301`/`AMC3330` 的 `HGND`、两条分压链的下臂 —— 全部接这里，只有这一块高压铜** |
| **`AGND`** | 模拟低压侧 | **只**从 `J1.2/5/8` 来 | 🔴 **板上不得就地接地**（ADR-015）。STM32 差分 ADC 的共模窗口只有 ±170 mV |
| **`DGND`** | 数字低压侧 | **只**从 `J2` 来 | `AMC23C12` 的 `GND2`、`UCC12050` 的 `GNDP` |

🔴 **`AGND` 和 `DGND` 在这块板上也绝对不能碰**（它们在 MAIN-01 上经 `R13` 0 Ω 单点相连）。

```
                    ┌──────── 隔离栅（开槽，≥8 mm）────────┐
   高压区            │        低压区                        │
 ┌──────────┐       │    ┌───────────┐    ┌────────────┐   │
 │ HV_GND   │  5kV  │    │   AGND    │    │   DGND     │   │
 │（一块铜）│ ←───→ │    │ (AMC3301/ │    │ (AMC23C12  │   │
 └──────────┘       │    │  3330低侧)│    │  UCC12050) │   │
                    │    └───────────┘    └────────────┘   │
                    └──────────────────────────────────────┘
                           ↑ 这两块也互不相连
```

## 🔴 为什么参考端必须是**变压器侧**，不是输出端子侧

```
负载电流：HV+ → 负载 → 输出− → shunt → 变压器com          【要被测到】
分压电流：HV+ → 两条分压链 → 参考端 → 变压器com

参考端 = 变压器侧 ✅ 分压电流直接回 com，不过 shunt
参考端 = 端子侧   ❌ 分压电流被 shunt 当成负载电流测进去
```

```
两条分压链并联 = 1609 kΩ ∥ 357.8 kΩ = 292 kΩ  →  223.6 V / 292 kΩ = 0.766 mA
1 Ω 档（7.07 A）    ：0.011%  可忽略
1000 Ω 档（0.2236 A）：【0.34%】而且与电压同相 → 把负载读得偏阻性
```

**高阻档正是这台仪器最需要准的地方**；浪涌时变压器侧也更安静。两个理由同一个答案。

# 一、高压功率通路与端子

> 🔧 **2026-09-14 改定（用户提议，采纳）**：原方案是「`J3` 功率 2P + `J4` 取样 1P」，
> 现改为 **`J4` 输入 2P + `J3` 输出 2P，`HV+` 在板上从走线直接取样**。
> **理由：取样线断掉 = 电压测量和硬件 OV 保护同时静默失效**；改成功率通路后这个失效模式不存在了
> （那根线断了就没有输出）。代价只是板上多一条 7 A 走线（约 0.1 W）。

```
                  ┌──────────────── SNS-01（高压区）────────────────┐
变压器抽头 ───→ J4.1 ──────── HV+ 走线（7.07 A）──────── J3.1 ───→ 输出 + 端子
                  │             │            │                     │
                  │        [OV 分压链]   [测量分压链]               │
                  │        4×402k:1k     7×51k:806Ω                 │
                  │             └──────┬─────┘  下臂都回 HV_GND     │
变压器 com  ───→ J4.2 ──┬─[ RS1 shunt 15 mΩ 四端 ]─┬── J3.2 ───→ 输出 − 端子
                  │   取样脚                     取样脚             │
                  │  = HV_GND                  = SHUNT_L            │
                  └─────────────────────────────────────────────────┘
```

| 位号 | 器件 | 要点 |
|---|---|---|
| `J4` | **2P 螺钉端子** ≥10 A / ≥300 V | 变压器进线（抽头 + com）。🔴 **不能用牛角、不能用 XH** |
| `J3` | **2P 螺钉端子** ≥10 A / ≥300 V | 去输出端子（+ / −） |
| `RS1` | **PCS-10W 15 mΩ 四端** | 见 §一.2 |

🔴 **板上有两条 7.07 A 走线**，2 oz 下各 ≥5 mm 宽（PCB 阶段按 IPC-2152 算准确值）。
```
40 mm 长 × 5 mm 宽 × 2 oz ≈ 2 mΩ → 0.1 W，压降 14 mV = 223.6 V 的 0.006%，不影响测量 ✅
```
🔴 **整个高压区（`HV+` 走线 + `HV_GND` 铜 + `RS1` + 两条分压链 + 四颗 IC 的高压侧）
必须在隔离栅的同一侧**，栅下开槽、≥8 mm；四颗 IC 全部骑在栅上。
🟡 `HV+` ↔ `HV_GND` 之间是**功能绝缘**（两者都是危险带电）；
它们**对 `AGND`/`DGND`** 才是**加强绝缘** —— 两类间距不一样，分开算。

🟡 **差模 GDT 仍然放输出端子/机箱侧**，不搬上板 —— GDT 动作时是几百安培，不该在 PCB 铜箔上跑。
SNS-01 这边靠分压链本身限流（上臂 1206 额定 200 V，GDT 600 V 时每只 150 V ✅）。

## 一.2 🔴 `RS1` = PCS-10W —— **四端开尔文，四个脚必须分开接**

✅ 手册已入库：`reference/PCS-10W-分流器-DataSheet.pdf`（驰宇 PCS-10W）
**「技术特点」第 4 条写的就是「四端连接」**；尺寸图上
**外侧两脚宽 1.5 mm / 间距 17.78 mm = 电流端；内侧两脚宽 1.1 mm / 间距 7.62 mm = 取样端**。

```
J4.2（变压器侧）──── 电流端（宽脚）
                      取样端（窄脚）──┬── HV_GND ── 四颗 IC 的高压侧参考
                                       ├── R9 → AMC3301.7 (INN)
                                       ├── R10 / R11 的 REF 回地
                                       └── 两条分压链的下臂

J3.2（输出−侧）──── 电流端（宽脚）
                     取样端（窄脚）──┬── R8 → AMC3301.6 (INP)
                                      └── R1 → AMC23C12(OC).2 (IN)
```

🔴 **绝对不能把 1+2、3+4 短接**（rev1/rev2 都是这么画的）—— 那等于把四端件当两端用：

```
7 A 通路上的 PCB 铜箔 + 焊点 + 镀镍铜脚很容易凑出 1~3 mΩ
→ 电流读数偏大 【7~20%】，而且随温度漂（铜 +0.39%/°C）
```

🔴 **立创封装 `PCS-10W` 的 1/2/3/4 谁是电流端要去封装库核一眼**（判据：**宽脚 = 电流端**）。

> 🟢 分压链那 0.766 mA 流经取样脚会不会破坏开尔文？镀镍铜脚约 0.2 mΩ →
> `0.766 mA × 0.2 mΩ = 0.15 µV`，相对 150 mV 信号是 **0.0001%** ✅ 完全可以忽略。

### 🔴 还要向厂家问一个手册没给的数：**残余电感 `L_s`**

手册只写「无感设计」没给数值。它直接变成电流通道的相位误差
`arctan(2π·f·L_s / 15 mΩ)`：

| `L_s` | 2 kHz | **10 kHz** |
|---|---|---|
| 0.5 nH | 0.024° | **0.120°** |
| 1 nH | 0.048° | **0.240°** |
| 2 nH | 0.096° | **0.480°** |
| 5 nH | 0.240° | **1.200°** |

```
要 ≤0.10° @10 kHz → L_s ≤ 0.42 nH
要 ≤0.25° @10 kHz → L_s ≤ 1.04 nH
```

🟢 **和频率成正比、系统性、可重复** → 和 AMC 带宽差一样，**被那张 4 点相位标定表一起吃掉**。
所以不必把 `L_s` 卡到 0.42 nH，**关键是稳定**（合金箔 + 低 TCR 就是为这个）。

🔴 **但有一部分标定不掉：PCB 上开尔文取样走线的环路面积**（和主电流回路互感耦合，
随布局和电流方向变）。→ **两根取样走线紧贴并行当差分对走，远离主电流回路，环路面积最小。**

### 🔴 `C32` 为什么是 **220 pF** 而不是 1 nF —— 相位

```
分压链戴维南阻抗 = 357 kΩ ∥ 806 Ω = 804 Ω

C32 = 220 pF → f_c = 900 kHz → 10 kHz 处相移 0.637°
（对比：电流通道 20 Ω × 10 nF → f_c 796 kHz → 0.720°）
两通道失配只有 0.08° ✅

若照抄 1 nF：f_c = 198 kHz → 相移 2.89° → 【和电流通道差 2.2°】❌
```

🔴 **必须 C0G/NP0**（0603 的 220 pF C0G 很好买）。

> 🟢 **两条通道的相位差最终靠软件标定清零**：`AMC3301` 带宽 typ 334 kHz、`AMC3330` typ 375 kHz，
> 10 kHz 处天生差约 **0.19°**，这是**系统性、可重复**的。
> 而频率预设只有 **2 / 5 / 8 / 10 kHz 四个** → **一张 4 项的相位偏移表就能标定干净**。
> 硬件这边要做的不是"完全匹配"，而是**保证稳定**：C0G 电容、±0.1% 电阻，标定值才不会漂。

# 四、硬件保护链 —— 两片 `AMC23C12` 的补完

## 4.1 🔴🔴 `REF`(3 脚) 现在悬空 = **保护等于没有**

`REF` 内部是 100 µA 恒流源，悬空会一直冲到轨：
门限跑飞到 2.7 V（OC 换算 **180 A 才跳**），而且 `V_REF > V_MSEL`(500 mV) 会让芯片进
**正比较器模式、`Cmp1` 被禁用 → 交流负半周完全不保护**（手册 §7.1）。

```
U1.3 (OC) ──┬──[ R10 2.15 kΩ ±1% ]── HV_GND
            └──[ C33 100 nF ]─────── HV_GND      手册 §8.4 图 8-6 的 C5，贴脚放

U2.3 (OV) ──┬──[ R11 2.49 kΩ ±1% ]── HV_GND
            └──[ C34 100 nF ]─────── HV_GND
```

| | `R_REF` | `V_REF` | 跳闸点 | 换算 | 余量 |
|---|---|---|---|---|---|
| **OC** | **2.15 kΩ** | 215 mV | ±219 mV 峰 | 14.6 A 峰 = **10.3 Arms** | **1.46×** ✅ |
| **OV** | **2.49 kΩ** | 249 mV | ±253 mV 峰 | ×1609 = 407 V 峰 = **288 Vrms** | **1.29×** ✅ |

两者 `V_REF` 都 < `V_MSEL` 最小值 500 mV → **窗口比较器模式**（±双门限），交流正负半周都保护 ✅

## 4.2 🔴 OC 的输入要挪到 shunt 的**被测端**

```
【改前】 HGND ──[R1 10Ω]── U1.2        ← 和 GND1 不在两端，且 GND1 悬空
【改后】 SHUNT_L ──[R1 10Ω]──┬── U1.2 (IN)
                              └──[C3 1nF]── HV_GND      ✅ C3 位置不用动
```

`AMC23C12` 是**单端**输入，`IN` 和 `GND1` 必须在 shunt 的**两端** —— 这是强制的。

🟡 `R1` 10 Ω + `C3` 1 nF = **10 ns**，看着"几乎不滤波"，但这是对的：
比较器自己就有 280~410 ns 延迟，RC 再大就拖慢跳闸；
而功放那 400 kHz 开关噪声已经被模块的 LC 输出滤波 + 变压器挡掉了。**保持不变。**

## 4.3 🔴 OV 分压链的上臂要接到 `HV+`

```
【改前】 R2.1 ∈ HGND   → 量到的是 150mV/1609 = 93 µV，【永远不会跳闸】
【改后】 R2.1 ∈ HV+
```
其余（`R3`/`R4`/`R5` 402 kΩ、`R6` 1 kΩ、`C6` **100 pF**、`R7` 10 Ω）**全部保持不动，值都是对的** ✅

每只 402 kΩ 在 223.6 Vrms 下：**55.9 Vrms = 79.0 V 峰 / 7.8 mW** ✅（1206 额定 200 V）

## 4.4 🔴 `V_IN` 的负向范围只有 −400 mV —— 锁存模式不能改

手册 §6.9：`V_IN` 工作范围 **−400 mV ~ +4 V**（绝对最大 −6 V ~ +5.5 V）。
负向余量：**OC 1.83× / OV 1.58×**。GDT 放电、硬短路时会短暂超出推荐范围，
但远在绝对最大值内、`R_IN` = 1 GΩ 几乎不流电流 ✅
→ 🔴 **`PROT_LATCH` 在 MAIN-01 上那只 10 kΩ 上拉（默认锁存）绝不能省**：
透明模式下超范围期间 TI 不保证比较器行为，`OUT` 可能正好在最需要时被释放。

## 4.5 🔴 两片的 `OUT` 要分成两个网名

```
【改前】 'OC_FAULT#' ; U1.6 U2.6        ← 并成一根，MCU 分不清是过流还是过压
【改后】 'OC_FAULT#' ; U1.6             → J2  （过流）
        'OV_FAULT#' ; U2.6             → J2  （过压）
```
🔴 **SNS-01 这边不加上拉**（上拉 `R54` 2.2 kΩ 在 MAIN-01 上）✅ rev1 已经是对的。
→ 这是待决 #54，**两块板要一起改**。

## 4.6 🔴 `UCC12050` 的 6 只 NC 脚必须接地

手册表 5-1 明文：

```
U3.6  U3.7  U3.8  → DGND    （"belong to primary-side voltage domain. Connect to GNDP"）
U3.10 U3.11 U3.12 → HV_GND  （"belong to isolated voltage domain. Connect to GNDS"）
```

**它们是 5 kV 隔离栅中间的金属，悬空会挂在中间电位上破坏场分布。** 不是可选项。

🟡 布局：手册说 `VISO` 的旁路电容要接到 **15 脚**（不是 9/16 脚）——
`C12`/`C14` 的地脚接 `U3.15`。
