## 1. 怎么确定哪两个脚是取样端 —— 两条独立证据，结论一致

### 证据 ①：手册尺寸图

```
外侧两脚：宽 1.5 +0.2/−0.1 mm，间距 17.78 mm   ← 电流端（宽 = 过电流）
内侧两脚：宽 1.1 +0.2/−0.1 mm，间距  7.62 mm   ← 取样端
（7.62 + 2×5.08 = 17.78 ✅ 自洽）
引脚长 5 ±0.3 mm，厚 0.8 mm
```

排列是 **［宽·电流］［窄·取样］［窄·取样］［宽·电流］**。

### 证据 ②：你自己那张符号图

符号上 **中间两个脚（2 和 3）标着 `+` / `−`** —— 画符号的人就是在标取样端。
外面两个脚（1 和 4）没有标，是电流端。

### → 判据

| 脚 | 类型 | 判据 |
|---|---|---|
| **1、4** | **电流端** | 焊盘/引脚**宽**（1.5 mm），在最外侧 |
| **2、3** | **取样端** | 焊盘/引脚**窄**（1.1 mm），在中间，符号上标 `+`/`−` |

🔴 **画 PCB 之前去立创封装库看一眼焊盘宽度确认**（万一那个封装的脚号顺序不是从左到右）。

## 2. 为什么不能把取样端和电流端并起来

并起来之后，芯片量到的就不再是「电阻片两端」，而是「电阻片 + 内部接触 + 5 mm 镀镍铜脚 +
焊点 + 参考点到 shunt 之间那段铜皮」。

```
寄生 0.15 mΩ → 电流读数偏大 1.0%
寄生 0.50 mΩ → 偏大 3.3%
寄生 1.00 mΩ → 偏大 6.7%
```

> 🔧 **更正我上轮写的「7~20%」** —— 那个数把整条 7 A 走线的电阻都算进去了。
> 短接发生在**焊盘上**时，焊盘之外的走线不进误差。
> **实际量级是 1~7%**，取决于参考点从铜皮哪里取。**结论不变：必须用开尔文。**

**但真正致命的不是那个百分比，是温漂：**

```
寄生的是铜，温度系数 +3900 ppm/°C
1 mΩ 寄生 → 对总温漂的贡献 = 6.7% × 3900 = 260 ppm/°C
而 PCS-10W 本体你打算订的是 25 ppm/°C
→ 总温漂被放大 【11 倍】；30 °C 温度变化下读数漂 0.78%
```

🔴 **等于花钱买了 25 ppm/°C 的合金箔，然后用一段铜把它的全部优势抵消掉。**
而且这个误差**标定不掉** —— 它随温度、随焊接、随铜皮走向变。

## 3. 网络清单（照这个改就对）

| 网络 | 成员 | 说明 |
|---|---|---|
| **`HV+`** | `U30.2`（变压器抽头进）<br>`U6.2`（输出 + 出）<br>`R2.1`（**OV 分压链上臂**）<br>`R12.1`（测量分压链上臂） | 🔴 **7.07 A**，宽铜<br>🔴 **两条分压链的上臂都要在这里** |
| **`TR_COM`** | `U30.1`（变压器 com 进）<br>`RS1.4`（宽·电流端） | 🔴 **7.07 A**，宽铜。**不许和 `HV_GND` 同网** |
| **`HV_GND`** | `RS1.3`（窄·取样端）<br>四颗 IC 的高压侧参考<br>两条分压链下臂 `R6.1` / `R19.1`<br>`R9.1`、`R10.2`、`R11.2` | 参考网，**几乎不走电流** |
| **`I_SNS`** | `RS1.2`（窄·取样端）<br>`R8.1`（→ AMC3301 INP）<br>`R1.1`（→ OC 的 IN） | 被测节点，**几乎不走电流** |
| **`OUT-`** | `RS1.1`（宽·电流端）<br>`U6.1`（输出 − 出） | 🔴 **7.07 A**，宽铜 |

### 电流走向自检

```
负载电流： 变压器抽头 → U30.2 → HV+ → U6.2 → 负载 → U6.1 → OUT- → RS1.1
           → 【电阻片】→ RS1.4 → TR_COM → U30.1 → 变压器 com        ✅ 全部过电阻片

分压电流： HV+ → 分压链 → HV_GND → RS1.3（取样脚，就在 RS1.4 那一端）
           → TR_COM → 变压器 com                                    ✅ 不过电阻片
```

✅ **待决 #59 满足**：分压链那 0.766 mA 不经过被测元件
（取样脚就在电流脚同一端，注入的电流直接走到最近的电流端）。

> 分压电流流经取样脚会不会破坏开尔文？镀镍铜脚 ≈ 0.2 mΩ → `0.766 mA × 0.2 mΩ = 0.15 µV`，
> 相对 150 mV 信号是 **0.0001%** ✅ 完全可以忽略。

## 3.5 🔴 一条极容易踩的坑：**去耦电容的地脚必须跟着芯片的地脚走**

`TR_COM` 和 `HV_GND` **不是同一个点** —— 它们只在 `RS1` 内部、经过
「取样点到电流端那一小段电阻片 + 镀镍铜脚」相连。

🔴 **所有高压侧芯片的去耦电容，地脚必须接 `HV_GND`（= 芯片地脚所在的网），不能接 `TR_COM`。**

| 电容 | 属于 | 地脚必须接 |
|---|---|---|
| `U1`/`U2` 的 `VDD1` 去耦（100 nF ∥ 1 µF ×2 组） | `AMC23C12` | `HV_GND`（= `U1.4`/`U2.4`） |
| `U1`/`U2` 的 `REF` 滤波（100 nF ×2） | `AMC23C12` | `HV_GND` |
| `U3` 的 `VISO` 去耦（10 µF + 100 nF） | `UCC12050` | `HV_GND`，🔴 **具体接 15 脚**（手册指定） |
| `U4`/`U5` 的 `DCDC_OUT`（1 µF + 1 nF ×2 组） | AMC3301/3330 | `HV_GND` |
| `U4`/`U5` 的 `HLDO_OUT`（100 nF + 1 nF ×2 组） | AMC3301/3330 | `HV_GND` |
| `C3` / `C6` / `C32`（三个输入滤波） | — | `HV_GND` |

**接错的后果**：去耦回路多绕一段 shunt 引脚（几 nH）+ 两块铜之间的距离。
对 100 nF 来说，回路电感多几 nH 就足以让它在几十 MHz 以上失效 ——
而这四颗芯片内部都是**几十~上百 MHz 的隔离载波**，全靠这些电容就地闭环。

手册原文（`AMC23C12` §8.4）：*"Place all four capacitors as **close to the device as possible**."*

> 🟢 顺带把「噪声耦合」这条算清楚，免得夸大：
> `TR_COM` 和 `HV_GND` 之间只有 **1~3.5 mV**（0.15~0.5 mΩ × 7.07 A）。
> 10 µF 在 10 kHz 是 1.59 Ω → 2.2 mA → 在取样脚 0.2 mΩ 上是 **0.44 µV** = 信号的 **0.0003%** ✅
> **这一条的危害是"去耦失效"，不是"噪声窜进测量"。**

## 3.6 🟡 网名建议

| 别用 | 用 | 为什么 |
|---|---|---|
| `GND1` | **`TR_COM`** | 🔴 `GND1` 同时是 `AMC23C12` 的**引脚名**。用它当功率网的网名，会出现<br>「引脚 `U1.4`『GND1』不在网络『GND1』里」这种极易看错的局面 |
| `SHUNT +` | **`OUT-`** | 它是**输出 − 的功率网**，叫 "SHUNT +" 会让人以为是取样点 |

## 4. PCB 上配套的三条

| # | 要求 | 为什么 |
|---|---|---|
| 1 | 🔴 **`RS1.2` 和 `RS1.3` 两根取样走线紧贴并行（按差分对走）**，远离主电流回路，环路面积最小 | 和主电流回路的互感是**标定不掉**的相位误差，随布局和电流方向变 |
| 2 | 🔴 **`TR_COM` / `OUT-` / `HV+` 三条 7.07 A 铜各 ≥5 mm @2 oz**（PCB 阶段按 IPC-2152 定准） | |
| 3 | 🔴 **`HV_GND` 的铜不要和 `TR_COM` 的铜混在一起** —— 它们只在 `RS1` 内部相连 | `TR_COM` 走 7 A，`HV_GND` 是参考。混在一起就等于又把开尔文短掉了 |

🔴 `RS1` 是 **22.5 × 17.5 × 8 mm 通孔件 + M3 螺丝（力矩 ≤0.9 N·m）**，板面提前留位、留 M3 孔、
下方铺铜散热（0.750 W）。
