# 〇、全局约定（先定下来，后面每段都按这个来）

## 0.0 ⚠️ 关于本文里的位号

**本文各段写的位号（`R31`/`C43`/`U25` 之类）都是举例**，和网表里已经占用的会冲突。
**实际画的时候按"下一个可用"往后排就行。**

截至 **rev16（2026-09-13）**，`R1~R33` / `C1~C53` / `U1~U26` **已全部用满，没有空位**：

```
电阻 → R34 起     电容 → C54 起     IC/连接器 → U27 起     二极管 → D9 起
```

## 0.1 封装与等级

| 用途 | 封装 | 精度/介质 | 耐压 |
|---|---|---|---|
| 普通上拉/下拉/限流 | 0603 | ±1% 厚膜 | 50 V |
| **分压器 / 门限电阻 / 滤波器** | 0603 | **±1% 薄膜**（低温漂 ≤50 ppm） | 50 V |
| **高压分压链** | **1206** | ±1% | **≥200 V 额定** |
| 去耦 100 nF | 0603 | **X7R** | **50 V** |
| **信号通路滤波电容** | 0603 | 🔴 **C0G/NP0，不能用 X7R** | 50 V |
| 体电容 / 输入电容 | 0805~1210 或电解 | X7R / 低 ESR | 见各段 |
| 36 V 段 | 0805 起 | — | **≥100 V** |

> 🔴 **信号通路（抗混叠、重构滤波、门限滤波）必须 C0G**。
> X7R 有 **直流偏压系数**（加 3 V 可能只剩 60% 容量）和 **压电效应**，
> 会让两条通道的 RC 不一致 → 直接变成相位误差。

## 0.2 去耦的统一做法

| 器件 | 去耦 |
|---|---|
| 每一片 IC 的每一个电源脚 | **100 nF X7R 0603，贴着脚放，过孔直接下地平面** |
| 每一路电源的入口 | 再加 **1 µF ~ 10 µF** |
| 隔离器件（AMC 系列） | 🔴 **两侧各自 100 nF ∥ 1 µF**，两侧地不许连 |

## 0.4 🔴 三个地怎么分、怎么在一个点汇合（2026-09-13 补写）

> rev12 把 `GND` 并进了 `AGND`，起因是上一轮我写的「要落在同一个物理点」有歧义。
> **同一个物理点 ≠ 同一个网络。**

| 网络 | 挂什么 |
|---|---|
| **`PGND`** | 36 V 回线、12 V 回线、母线体电容、TVS/crowbar、软启动栅极分压下臂、<br>**所有功率端子和干接点端子的地脚** |
| **`DGND`** | MCU 数字部分、CH340X、TCA9539、FRAM、TPS382x、USB、面板接口、5 V 回线端子 |
| **`AGND`** | `VSSA`、`VREF+` 的 1 µF+100 nF、`3V3_AVDD` 去耦、模拟 LDO 的 `GND` 脚、<br>`V_BUS_SENSE` 下臂、（将来）`J_SNS_A` 的三个 `AGND` 脚 |

**桥接：两只 0Ω，焊盘相邻，那一小块铜就是星点。**

```
   AGND ──[ R13 0Ω 0805 ]── DGND ──[ R16 0Ω 0805 ]── PGND
                              ↑
                    两只 0Ω 的焊盘挨着放 → 这一小块铜 = 星点
                    位置建议：U18.1（5V 回线端子的地脚）附近
```

🔴 **枢纽必须是 `DGND`，不能是 `AGND`**（rev13 接成了 `DGND—R13—AGND—R16—PGND`，
把模拟地放成了串联链的中间环节）。具体机理：

```
DDR-30L-5 是隔离模块：输入侧在 PGND、输出侧在 DGND。
隔离变压器初次级之间有 50~200 pF 寄生电容，开关时打出共模尖峰：
    i_CM = C × dV/dt ≈ 200 pF × (36 V / 20 ns) = 0.36 A 尖峰

枢纽是 AGND 时：PGND ─(寄生C)→ DGND ─[R13]→ AGND ─[R16]→ 回 PGND
                                            🔴 整股尖峰从模拟地上穿过去
枢纽是 DGND 时：PGND ─(寄生C)→ DGND ─[R16]→ 回 PGND
                                            ✅ 完全不碰 AGND
```

`AGND` 必须是**末端支路（leaf）**，上面只有它自己那 91 mA。

| 🔴 硬要求 | 为什么 |
|---|---|
| **三个网络在原理图里必须是三个网络** | 合成一个之后敷铜就是一整块，**DRC 不报错**，功放那 1.74 A 会从模拟区底下穿过去 |
| 🔴 **枢纽是 `DGND`，`AGND` 只能是末端支路** | 见上面的 DDR-30L 共模电流路径。**接成 `DGND—AGND—PGND` 串联链是错的** |
| **`R13` 贴着 `U18.1`（5 V 端子的地）放** | `AGND` 的 91 mA 从这里回 5 V 源；放远了会在 `DGND` 铜上走一段 |
| 🔴 **只能有一个功率地网名** | `GND` 和 `PGND` 不要同时存在；统一叫一个，另一个删掉 |
| **`R13` 和 `R16` 焊盘相邻** | 这才是"同一个物理点" |
| **不能只留一只桥** | 三路电源互相隔离，桥上几乎没有稳态电流，但**必须有直流通路定义电位**，否则域间会积累静电/共模电压 |
| **`U26`（→功放）的地脚直连 `C34` 负极** | 把功放 1.74 A（含 2f 与 400 kHz 开关分量）的回路锁在 `C34 ↔ U26` 一小圈里 |
| **`U10`(12V 进) 和 `U11`(12V 出) 挨着放** | 去 RLY-01 的 394 mA 在板上只走几毫米，不在 `PGND` 上画长压降 |

🔴 **`VREF+` 的回流点（`C23`/`C24`）最要小心**：基准被噪声调制 = **增益被调制**，
这是差分 ADC 的共模抑制**管不了**的。

## 0.5 🆕 反接保护：并联 crowbar vs 串联通流二极管（rev13 改成了串联）

| | 并联 crowbar | **串联通流（rev13 用的 `D9` MBR20200CT）** |
|---|---|---|
| 正常损耗 | **0 W** | **≈1.3 W**（2.10 A × Vf 0.60 V） |
| 母线压降 | 0 V | **≈0.6 V**（32 V → 31.4 V；功放模块下限 30 V，余量 1.4 V） |
| 反接时 | 短路 → 靠 DRS 自身 OCP 关断 | **直接阻断，什么都不烧** ✅ |
| 耐压要求 | 要顶住 TVS 钳位 **82 V** → ≥100 V | 只要顶住反接的 43~56 V → **100 V 就够**，200 V 是过度 |

**选串联就必须处理热：**

| 散热方式 | θJA | **Tj @45 °C 机箱内** |
|---|---|---|
| 立式 TO-220，散热片悬空 | ≈62 °C/W | **123 °C**（Tj max 150 °C）🟡 管壳 120 °C，会烤旁边的电解电容 |
| **卧式贴板 + 螺丝固定到覆铜**（推荐） | ≈35~40 °C/W | **94 °C** ✅ |
| 加一小片铝散热器 | ≈12 °C/W | **61 °C** ✅ |

🔴 **TO-220 的散热片 = 共阴极 = `36V_RAW` 电位。** 加金属散热器必须绝缘，或确保不碰别的东西。

🔴 **串联二极管之后，`V_BUS_SENSE` 的分压上臂 `R28` 要接在二极管【之前】。**
Vf 随电流从 0.45 V（轻载）变到 0.62 V（满载）= **170 mV 的负载相关漂移**，
而 `V_BUS_SENSE` 的分辨率是 14.9 mV/LSB。
LiFePO₄ 的低压预警窗口只有 1.7 V（33 V 报警 ↔ 31.3 V 切断），170 mV 就吃掉 10%，
而且功放一开一关电压就跳一下，软件会误判成电池在掉。

### 🔧 更正：编码器 A/B 的电容**不是 100 nF，是 10 nF**

`绘图计划-MAIN-01剩余部分.md` §1.3 写的「10 kΩ + 100 nF」**偏大，本条更正为 10 nF**。

```
算一下最坏边沿间隔：
  面板编码器 24 PPR、手转最快约 5 圈/秒
  → 每通道 120 脉冲/s = 240 边沿/s  →  边沿间隔 4.2 ms
  （四倍频计数时整体 480 计数/s）

10 kΩ × 100 nF → τ = 1 ms，上升到 VIH(2.31 V) 要 1.2 ms = 边沿间隔的 29%  ❌ 会丢步
10 kΩ × 10 nF  → τ = 100 µs，上升到 VIH 要 120 µs = 边沿间隔的 2.9%       ✅
```

```
PC6 (38) TIM3_CH1 ──┬── J13.14  ENC_A
                    ├──[ 10kΩ ]── 3V3
                    └──[ 10nF C0G ]── DGND

PC7 (39) TIM3_CH2 ──┬── J13.15  ENC_B     （同上）
编码器公共端 C  ─────── J13.16  DGND
```

### 🆕 编码器选型（用户 2026-09-12 问「选那种就固定几个档的」）→ **带定位(detent)的增量式**

| 项 | 要求 |
|---|---|
| 类型 | **EC11 系列**，立式、**带按键**（5 脚版本，`Encoder ENTER` 要用） |
| 🔴 **脉冲数 = 定位数** | **20 脉冲/20 定位** 或 24/24。<br>🔴 **千万别买「15 脉冲/30 定位」** —— 那种每两档才走完一个正交周期，**一半的定位点停在 A/B 中间态**，手一抖就来回计数 |
| 引脚 | `A→PC6`、`C(公共)→DGND`、`B→PC7`；按键两脚 → `Encoder ENTER` + `DGND` |
| 轴 | D 型半轴或滚花轴，轴长 15/20 mm 按面板厚度 |
| 寿命 | 机械 ≥30000 圈 |

**带定位为什么正好**：停在定位点时 **A/B 处于同一个稳定状态**（通常都断开、都被上拉为高），
所以静止时的接触抖动不会产生计数 —— 这是它比无定位编码器可靠的根本原因。

**软件**：`TIM3` 编码器接口 ×4 倍频 → **1 档 = 4 个计数** → 右移 2 位。

> 剩余的机械抖动交给 **TIM3 的输入数字滤波器**：
> `TIM3_CCMR1.IC1F = IC2F = 0b0011`（f_DTS 采样 8 次）。
> 硬件滤波 + 定时器滤波 + 四倍频编码器模式，比任何软件轮询都可靠。

## 1.5 36 V 段的分支熔断与顺序调整

```
DRS 36V ──[ F1 6.3A ]──┬── D5 SMCJ48A ── PGND      （TVS，ns~µs 级）
                       ├── D8 SS10P6C  ── PGND      （反接/crowbar；位号由 U10 改 D8）
                       │
          36V_RAW ─────┼──[ F2 T1A ]──→ DDR-30L-12 ──→ 12V
                       ├──[ F3 T1A ]──→ DDR-30L-5  ──→ 5V
                       └──[ F_AMP T4A ]──→ Q1 软启动 ──→ 36V_AMP ──→ J_AMP_PWR
```

## 2.1 `J_SNS_A` 8P —— 模拟板间接口（ADR-015 定义，不变）

| 脚 | 网络 | 脚 | 网络 |
|---|---|---|---|
| 1 | `3V3_AVDD` | 5 | `AGND` |

| 3 | `I_OUTP` | 7 | `V_OUTN` |
| 4 | `I_OUTN` | 8 | `AGND` |

**线束**：`I_OUTP/N` 一对绞线、`V_OUTP/N` 一对绞线、外面总屏蔽，
🔴 **屏蔽层只在 MAIN-01 这头接 `AGND`**（两头都接就成了地环路天线）。

🔴 **再强调一次 ADR-015 的硬性要求**：SNS-01 上 AMC3301/AMC3330 的 `GND2`

## 2.2 抗混叠 RC —— 两组，**必须一模一样**

```
J_SNS_A.3 I_OUTP ──[ R 100Ω ]──┬──────────── PA6 (20)  ADC2_IN3  (+)
                               │
                          [ C 10nF C0G ]     ← 差模电容
                               │
J_SNS_A.4 I_OUTN ──[ R 100Ω ]──┴──────────── PA7 (21)  ADC2_IN4  (−)

  （另外两只共模电容各 1 nF C0G，PA6→AGND、PA7→AGND）

J_SNS_A.6 V_OUTP ──[ R 100Ω ]──┬──────────── PC0 (8)   ADC1_IN6  (+)
                          [ C 10nF C0G ]
J_SNS_A.7 V_OUTN ──[ R 100Ω ]──┴──────────── PC1 (9)   ADC1_IN7  (−)
```

| 器件 | 值 | 封装/介质 | 为什么 |
|---|---|---|---|
| 4 × 串联电阻 | **100 Ω ±1% 薄膜** | 0603 | 差模 R 合计 200 Ω |
| 2 × 差模电容 | **10 nF ±2% C0G** | 0603 | f_c = 1/(2π·200·10n) = **79.6 kHz** |
| 4 × 共模电容 | **1 nF ±5% C0G** | 0603 | 容值取差模的 1/10，失配引起的共模→差模转换可忽略 |

### 🔴 选型的关键不是截止频率，而是**两条通道的一致性**

相位是 V 和 I **相减**得到的，所以滤波器的绝对相移不影响结果，**失配才影响**：

```
10 kHz 处单极点相移 = −atan(10/79.6) = −7.16°
dφ/d(f_c)  在此处 ≈ 1.55e-6 rad/Hz

若两组 RC 的 f_c 差 5%（3.98 kHz） → 相位差 0.35°   ❌ 超预算
若两组 RC 的 f_c 差 3%（2.39 kHz） → 相位差 0.21°   🟡 勉强
```

**所以：**
1. 电容用 **C0G ±2%**，🔴 **绝对不能用 X7R**（直流偏压系数会让两只不一样）
2. 4 只电阻同一批次、同一盘 ±1% 薄膜
3. **布局对称**：两组 RC 的走线长度、过孔数、离地平面的距离都尽量镜像
4. 残余误差用 **纯电阻负载做一次软件校准**（接已知的无感电阻，测到的相位就是系统误差，存进 FRAM）

> 抗混叠够不够？采样率 = 125 × f，最慢 2 kHz 时 **250 kSPS**，Nyquist 125 kHz。
> 79.6 kHz 一阶在 125 kHz 只衰减 −4.3 dB —— 看着不够，
> 但 **AMC3301/AMC3330 本身的带宽只有几百 kHz**，超出部分已经被它们滚降掉了。
> 真正的抗混叠是「AMC 内部滤波 + 这一级 RC」串起来的。

## 2.3 ADC 配置（给软件的，画图时确认脚位就行）

```
ADC1 规则组（差分 ch6）: PC0(IN6,+) / PC1(IN7,−)  ← 电压 AMC3330
ADC2 规则组（差分 ch3）: PA6(IN3,+) / PA7(IN4,−)  ← 电流 AMC3301
        ↑ 两者跑【规则通道双重同步模式】，同一触发、同时采保，采样时差 = 0

ADC1 注入组（4 通道，10 Hz）:
   IN8 = PC2  V_BUS_SENSE
   IN9 = PC3  NTC1
   IN1 = PA0  NTC2
   IN2 = PA1  NTC3
```

🔴 **相位为什么必须同步采样**：10 kHz 下差 0.25 µs 就是 **0.9°**。
如果用一个 ADC 轮流扫 V 和 I，哪怕最快的 2.5 个周期采样时间（170 MHz 下 ≈15 ns）
加上转换时间也有 µs 级间隔 → 相位直接废掉。

## 3.2 元件取值与计算

| 位号 | 值 | 封装/介质 | 说明 |
|---|---|---|---|

| `C45` | **2.2 µF 盒式薄膜 50 V** | 5 mm 脚距 | 🔴 **隔直**，不能用 X7R（音频段压电+偏压失真） |
| `R34` | **100 kΩ** | 0603 | 泄放，功放没插时定义直流电平 |

```
f_c = 1/(2π·R·√(C43·C44)) = 1/(2π·2000·√(4.7n×2.2n)) = 24.7 kHz
Q   = ½·√(C43/C44) = ½·√(4.7/2.2) = 0.731        （≈ 巴特沃斯 0.707）

对 10 kHz 基波的衰减：u = 10/24.7 = 0.405
|H| = 1/√((1−u²)² + (u/Q)²) = 0.997  →  −0.02 dB   ✅ 几乎不衰减

镜像抑制（最坏工况 2 kHz，更新率 125×2k = 250 kSPS，首镜像 248 kHz）：
   二阶 LPF：(248/24.7)² = 101×  →  −40 dB
   零阶保持 sinc：sinc(248/250) = 0.008  →  −42 dB
   合计 −82 dB                                       ✅
```

> V/I/相位都是在**变压器输出端**量的，激励链上的任何相移都被闭环外掉了。

### 为什么不能用 10 kΩ（这是本轮新算出来的）

**基准已经改成 VREFBUF 2.9 V**（ADR-010），而分压器挂在 3.3 V 上：

| 温度 | NTC 阻值 | **10 kΩ 上拉时的电压** | **22 kΩ 上拉时的电压** |
|---|---|---|---|
| −20 °C | 105.4 kΩ | **3.014 V** 🔴 **超过 2.9 V 基准，削顶** | **2.730 V** ✅ |
| 0 °C | 32.6 kΩ | 2.52 V | 1.985 V ✅ |
| 25 °C | 10.0 kΩ | 1.650 V | **1.031 V** ✅ |
| 60 °C | 2.49 kΩ | 0.657 V | 0.335 V ✅ |
| 80 °C | 1.27 kΩ | 0.372 V | 0.180 V ✅ |

```
B3950 公式： R(T) = 10k × exp(3950 × (1/T − 1/298.15))
25 °C 处灵敏度： dV/dT = 3.3 × 22k/(32k)² × (−3950/298.15² × 10k) = −31.5 mV/°C
60 °C 处灵敏度： −10.7 mV/°C
12 bit @2.9 V → 1 LSB = 708 µV → 60 °C 时 0.066 °C/LSB       ✅ 分辨率远远够
```

| 位号 | 值 | 封装 | 说明 |
|---|---|---|---|
| `R43` × 3 | **22 kΩ ±1% 薄膜** | 0603 | 🔴 关键值 |
| `R44` × 3 | **1 kΩ** | 0603 | 线束保护 + 和 C48 组成 RC |
| `C48` × 3 | **100 nF C0G** | 0603 | 🔴 **给 ADC 采保电容供电用的**：分压器源阻抗最高 18 kΩ，没有它采样建立不了 |

> ⚠️ **非比率式**：分压器挂 3.3 V、ADC 基准 2.9 V，所以 LDO 的 ±2% 误差会直接进来。
> 25 °C 时 = 20.6 mV / 31.5 mV·°C⁻¹ = **±0.65 °C**。风扇调速和过温保护完全够 ✅
> （🔴 **不要为了比率式把分压器挂到 `VREF+` 上** —— VREFBUF 的驱动能力有限，
> 3 路共 272 µA 的动态负载会污染整条精密测量链的基准。）
>

## 5.0 🔴 先定板级归属：AMC23C12 ×2 + UCC12050 **都放 SNS-01**，不放 MAIN-01

**理由（ADR-015 的直接推论）：**

1. AMC23C12 的 `IN` 是**单端输入，相对于 `GND1`**。
   OC 那片要量 shunt、OV 那片要量高压分压链 —— **两者都在高压侧**。
   放 MAIN-01 就得把 shunt 引线和 250 Vrms 分压链拉到主板上，
   与「220 V 强电/高压不上 PCB」的方案 A 直接冲突。
2. 两片的 `GND1` 是**同一个节点**（变压器次级公共端 / 输出回线）
   —— 这正是需求原文说「一片 UCC12050 供两片」成立的前提 ✅
3. AMC3301/AMC3330 **自带隔离 DC/DC**（所以 `J_SNS_A` 上只有 3V3_AVDD），
   而 AMC23C12 **没有**，必须靠 UCC12050 —— 两者天然应该同板。

> 📌 这是对 **ADR-015 的补充，不是推翻**：8P 模拟接口 `J_SNS_A` **定义完全不变**，
> 只是**另加一个 8P 数字接口 `J_SNS_D`**。记为 **ADR-015 补充条款**。

## 5.1 🔴 SNS-01 上有**三个互不相连**的地

| 地 | 属于谁 | 怎么回主板 |
|---|---|---|
| `GND1`（高压侧） | 2 × AMC23C12 的 `VDD1/IN/REF/GND1` + UCC12050 的 `VISO/GNDS` | **不回**，浮在输出回线上 |

## 5.3 OC 那一片（过流）—— 门限电阻怎么算

```
                  高压侧                        低压侧
   shunt 15mΩ ─┬─[ 10Ω ]─┬── IN (2)      (8) VDD2 ──── +3V3_SNS ─┬[100nF]┬[1µF]─ DGND
               │      [ 1nF ]                                    └───────┴──────
               │         │                (6) OUT ────────────→ J_SNS_D.6  OC_FAULT#
   输出回线 ───┴─────────┴── GND1 (4)     (7) LATCH ──────────← J_SNS_D.5  PROT_LATCH
                                          (5) GND2 ──────────── DGND
   +5V_ISO ── VDD1 (1) ─┬[100nF]┬[1µF]─ GND1
                        └───────┴──────
   REF (3) ──[ R_REF ]──┬── GND1
                   [ 100nF ]
```

```
shunt = 15 mΩ，额定 8 Arms  →  峰值 11.31 A  →  169.7 mV 峰
跳闸点取额定峰值的 1.3 倍 = 14.7 A = 220.6 mV

R_REF = (V_trip − V_HYS)/100 µA        V_HYS = 4 mV （V_REF < 450 mV 时）
      = (0.2206 − 0.004)/100e-6 = 2166 Ω   →  E96 取 【2.15 kΩ】

实际： V_REF = 215 mV，跳闸 = 215 + 4 = 219 mV
       → 14.6 A 峰 = 【10.3 Arms】 = 额定的 1.29×     ✅
```
✅ `V_REF` = 215 mV < `V_MSEL` 最小值 500 mV → **窗口比较器模式**（±219 mV 双门限），
正是交流电流需要的 —— 正负半周都保护。

| 位号 | 值 | 封装/介质 | 说明 |
|---|---|---|---|
| `R_REF(OC)` | **2.15 kΩ ±1% 薄膜** | 0603 | 门限；1% 电阻 + 1% I_REF + 1% 比较器 → 总误差约 3%，保护用足够 |
| `C_REF` | **100 nF X7R** | 0603 | 🔴 贴 REF 脚放，手册明确要求 |
| `R_IN` | **10 Ω** | 0603 | 手册推荐；只增加约 10 ns 传播延时 |
| `C_IN` | **1 nF C0G** | 0603 | 与 10 Ω 组成 15.9 MHz 极点；shunt 源阻抗只有 mΩ，不会引入分压误差 |
| `VDD1` 去耦 | **100 nF ∥ 1 µF 低 ESR** | 0603+0805 | 对 `GND1` |
| `VDD2` 去耦 | **100 nF ∥ 1 µF 低 ESR** | 0603+0805 | 对 `DGND` |

🔴 **接线要点：shunt 的一端必须就是 `GND1`。**
AMC23C12 是**单端输入**，不是差分 —— 它只认 `IN` 相对 `GND1` 的电压。
（AMC3301 是差分，无所谓；两者可以共用同一对开尔文抽头。）

## 5.4 OV 那一片（过压）—— 高压分压链

```
输出 HV ──[402k]──[402k]──[402k]──[402k]──┬── IN (2) 经 [10Ω]
                                          │
                                     [ R_bot 1kΩ ]   ∥  [ 100pF ]
                                          │
   输出回线 = GND1 ───────────────────────┴
```

```
输出最大 250 Vrms → 353.6 V 峰
跳闸点取 1.15 倍 = 406.6 V 峰

分压比 = (4×402k + 1k)/1k = 1609 : 1
IN 处 = 406.6/1609 = 252.7 mV

R_REF = (0.2527 − 0.004)/100e-6 = 2487 Ω  →  E96 取 【2.49 kΩ】

实际： V_REF = 249 mV，跳闸 = 253 mV
       → 253 mV × 1609 = 407.1 V 峰 = 【287.9 Vrms】 = 250 Vrms 的 1.15×  ✅
```

| 位号 | 值 | 封装 | 核算 |
|---|---|---|---|
| 4 × 上臂 | **402 kΩ ±1%** | 🔴 **1206，额定 200 V** | 250 Vrms 时每只 88 V 峰；输出端 GDT 是 600 V，浪涌时每只 150 V < 200 V ✅ |
| `R_bot` | **1 kΩ ±1%** | 0805 | — |
| 功耗 | 155 µA → 每只 9.7 mW，合计 **38.9 mW** | | 1206(250 mW) 余量 26× ✅ |
| `C_IN(OV)` | 🔴 **100 pF C0G，不是 1 nF** | 0603 | 见下 |

### 🔴 为什么 OV 这一片的输入电容是 100 pF 而不是手册推荐的 1 nF

分压器下臂只有 1 kΩ，**电容会和它并联**，把分压比在工作频率上带歪：

```
1 nF   @10 kHz → Xc = 15.9 kΩ，1 kΩ ∥ 15.9 kΩ = 941 Ω → 分压比偏 6%  ❌ 门限漂 6%
100 pF @10 kHz → Xc = 159 kΩ，1 kΩ ∥ 159 kΩ = 994 Ω  → 分压比偏 0.6% ✅
```
100 pF 配上约 1 kΩ 的源阻抗，极点在 1.6 MHz —— **抗噪够，附加延时只有 0.1 µs** ✅
（想用 1 nF 就得在上臂并 0.62 pF 做补偿，不现实。）

🔴 **这一条高压分压链必须和 AMC3330 的测量分压链完全独立**（需求原文的原话），
不能共用 —— 测量链坏了保护链还得活着。

## 5.6 🔴 `PD2 = AMP_ENABLE + HARD OK` 到底怎么实现

Visio 原文写的是一个脚同时干两件事。**能做到，但有个失效危险，建议加一只与门。**

### 方案 ①（照需求原文，一个脚）

```
3V3 ──[ R 2.2kΩ ]──┬── AMP_ENABLE ──→ J_AMP.3
                   ├── OC_FAULT#   (开漏，来自 J_SNS_D.6)
                   ├── OV_FAULT#   (开漏，来自 J_SNS_D.7)
                   └── PD2 (55)  配成【开漏输出】，写 0 = 禁止，写 1 = 放开并可读回
```
🔴 **问题：MCU 复位时 PD2 是高阻 → 节点被上拉到 3.3 V → 功放被使能。**
虽然此时继电器全释放（TBD62083A 输入有下拉）、DAC 无输出，实际不会出声，
但「复位默认使能功率级」这个状态本身不该存在。

### 方案 ②（**推荐**，加一只 SOT-353 与门，多占 2 个脚）

```
3V3 ──[ R51 2.2kΩ ]──┬── HARD_OK ──┬──────────→ U25.A (74LVC1G08)
                     ├── OC_FAULT# │                            └─→ U25.Y ──[R54 100Ω]──→ J_AMP.3 AMP_ENABLE
                     ├── OV_FAULT# ├──→ PA15 (51)  HARD_OK_MON  ┌─→ U25.B
                     └──[ C49 1nF ]                             │
                                                    PD2 (55) ───┴──[ R52 10kΩ ]── DGND
```

| 位号 | 值 | 说明 |
|---|---|---|
| `U25` | **74LVC1G08**（2 输入与门，SOT-353） | 供电 3V3 + 100 nF 去耦 |
| `R51` | **2.2 kΩ**（不是 10 kΩ） | 线与节点要跨线束，节点要够硬。灌电流 1.5 mA < AMC23C12 的 4 mA 上限 ✅ |
| `C49` | **1 nF C0G** | τ = 2.2 µs。比较器延时 280 ns + 这个 = 总触发延时约 3 µs，比软件快 4 个数量级 |
| `R52` | **10 kΩ 下拉** | 🔴 **关键**：MCU 复位 → PD2 高阻 → 被拉低 → 与门输出低 → **功放禁止** ✅ 失效安全 |
| `R54` | 100 Ω | 线束阻尼 |

**新增两个脚**（都从 10 个空闲脚里出）：
| 脚 | 引脚 | 用途 |
|---|---|---|
| **51** | `PA15` | `HARD_OK_MON` 输入 —— 软件读得到「是硬件跳的还是我自己关的」 |
| **60** | `PB7` | `PROT_LATCH` 输出 |

### `PROT_LATCH` 怎么用

```
PB7 (60) ──┬── J_SNS_D.5 ──→ 两片 AMC23C12 的 LATCH (7)
           └──[ R53 10kΩ ]── 3V3
```
| 状态 | LATCH | 行为 |
|---|---|---|
| MCU 复位 / MCU 死了 | 高阻 → 被 `R53` 拉高 | **锁存模式已武装** ✅ 一跳就锁死，不会自己恢复 |
| 正常运行 | MCU 保持高 | 锁存模式 |
| 清故障 | MCU 拉低 **≥3.2 µs** 再放开 | 手册：`LATCH` 下降沿清除，去抖时间 1.8~3.2 µs |

🔴 **`LATCH` 绝对不能悬空**（手册明写 "Do not leave the input pin unconnected"）。
`R53` 同时保证了「MCU 不在场时默认是最安全的锁存模式」。

### ✅ 顺带查到一条很漂亮的失效安全特性

手册 §7 原文：高压侧电源 `VDD1` 掉到欠压阈值以下超过 `t_HS,FLT`（100 µs），
**`OUT` 会被主动拉低** —— *"This delay allows the system to shut down reliably
when the high-side supply is missing."*

**也就是说：UCC12050 坏了 / 线束断了 / 隔离电源起不来 → 功放自动被切掉** ✅
这条保护链是**天生失效安全**的，不需要额外做监视。

### 🟡 线束拔掉怎么办

`HARD_OK` 是线与节点，**线束拔掉 = 上拉把它拉高 = 看起来"一切正常"** ❌
所以留了 `J_SNS_D.8 = SNS_PRESENT#`（SNS-01 上直接短到 `DGND`）：

```
3V3 ──[ R55 10kΩ ]──┬── PB0 (24)  SNS_PRESENT#
                    └── J_SNS_D.8
```
软件在使能功放前必须确认 `PB0 = 低`。**不加这一根线的话，
拔掉采样板就等于关掉了全部硬件保护。**

**完整切换时序（软件必须照这个来）：**
```
① AMP_ENABLE 拉低（功放静音）      ← 🔴 带载切换会拉弧打坏触点
② 等 10 ms（功放输出衰减完）
③ 断开当前抽头继电器
④ 等 ≥30 ms                        ← 🔴 两只抽头同时闭合 = 变压器次级匝间短路
⑤ 需要换变压器时切 K_TRANS，再等 ≥30 ms
⑥ 闭合新抽头
⑦ 等 ≥30 ms
⑧ AMP_ENABLE 放开
```

# 附录 C · 连接器形式（用户 2026-09-12 问「接口可以用牛角吗」）

「牛角」= **带护套 + 防呆缺口的双排 IDC 简易排针（DC3 系列）**，配灰排线一次压接。

| 接口 | 牛角？ | 说明 |
|---|---|---|
| **`CN1` 面板 16P** | ✅ **推荐** | DC3-16P-2.54。现在的地线插花排布（2/4/7/10/13/16）正好配排线 |
| **`CN2` → RLY-01** | ✅ 推荐，但🔧**改两点** | ① **2.0 mm → 2.54 mm**（2.0 牛角要配 1.0 mm 排线，工具和料都难买）<br>② **10P → 14P**，把地线插花排到 6 根（现在 8 路信号只有 2 根地） |
| **`J_SNS_D` 数字 8P** | ✅ 可以 | 纯逻辑 |
| **`J11` 12 V→RLY 4P** | 🟡 可以 | 394 mA；2.54 牛角单脚约 1 A、28 AWG 排线约 1 A ✅ 够，但余量不大 |
| **`J15` NTC 6P** | ✅ 可以 | µA 级 |
| 🔴 **`J_SNS_A` 模拟 8P** | 🔴 **不能用** | ADR-015 要求「两对输出各自绞线 + 总屏蔽」。**排线是平行扁线，绞不起来、屏蔽层也没处接**。<br>→ 用 **XH/PH 单排带扣端子 + 自己做屏蔽绞线束** |
| 🟡 **`J_AMP` 信号 4P** | 🟡 勉强 | `DDS_OUT` 是模拟信号，但 2 Vpp 抗扰度高。**用的话信号旁边必须排地** |
| 🔴 **36 V / 12 V / 5 V 电源、功放供电** | 🔴 **不能用** | 1.74 ~ 2 A。必须 **KF301/KF128 螺钉端子**或 VH3.96 |

**三条注意：**
1. 🔴 **选带锁扣的**（DC3 标准型自带卡扣），机箱振动不会松
2. 🔴 **排线地线插花** —— 信号旁边永远有一根地
3. 🔴 **单脚按 ≤1 A 用**；要过大电流就并几根脚
