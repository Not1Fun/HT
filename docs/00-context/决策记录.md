## ADR-004 · 接地：全机单点星型接地

- **日期**：2026-09-09
- **决策人**：Claude 提出，待用户确认
- **背景**：DDR-30L 是隔离型 DC/DC，PGND / GND_AUX / DGND 本可各自独立。但：
  - MCU 的 DAC 输出要送到 TPA3255 的输入 → **PGND 与 DGND 必须共地**
  - ULN2803 的输入来自 TCA9535（DGND 域），输出驱动 12V 继电器 → **GND_AUX 与 DGND 也必须共地**
  - 结论：整机实际上是单地系统，DC/DC 的隔离只用于抑制共模噪声
- **决定**：
  - **PGND / GND_AUX / DGND** 在 **PWR-01 上一个星点**汇合（用 0Ω 跳线 R100/R101，便于调试时断开查地环路）
  - **⚠️ 修订（2026-09-09）：AGND 不参与 PWR-01 的星点。**
    AGND 只存在于控制板（U6 供 VDDA/VREF+），PWR-01 上 `V_BUS_SENSE` 的 AGND
    只经 J3 回控制板。若在 PWR-01 本地再连一次 DGND，AGND 就有两条通路，构成**地环路**。
  - 控制板内部的 AGND ↔ DGND 用**一只 0Ω 连接，放在 MCU 的 VSSA (pin 27) 旁**
    （VREF- 与 VSSA 内部同绑，是测量系统的零点）。PCB 用**单一完整地平面 + 布局分区**，
    不切缝。详见 `docs/02-digital/MCU最小系统-设计与计算.md` §1.7
  - 星点经 R103（0Ω，或 1MΩ ∥ 10nF）单点接 PE
  - 功率地铜箔独立回到星点，不与数字地共用回流路径（TPA3255 的开关电流有几安培）
- **注**：4 路 PC817C **仍然保留**。它隔离的不是电源域，而是 **DRS 到板子那几十厘米走在强电区的线束地环路**，有价值。

## ADR-005 · AC 插座：改用 IEC C14 三合一模块

- **日期**：2026-09-09
- **决策人**：Claude 建议，**待用户确认**
- **背景**：用户送检 `RT-C06-A1B-CC`（立创 C6775838，IEC 320-C6 米老鼠，2.5A/250VAC，**PCB 弯插**）
- **否决理由**：
  1. **弯插 = 装在 PCB 上**，与 ADR-002（强电不上板）直接冲突
  2. C6 额定 2.5A：230V 下 DRS 输入 1.4A 够用（1.79×），但 **115V 下 DRS 要 2.8A > 2.5A 超额定**
  3. 熔断器必须保护最弱环节，用 C6 就得选 T2A，与 16A 开关、T3.15A 熔断器不匹配
  4. C5 米老鼠线是笔记本适配器级别，工业现场不常备
- **建议**：**IEC 60320 C14 三合一模块**（插座 + 5×20 保险丝座 + 双刀开关），面板卡扣安装，10A/250VAC
  - 一个件替掉现 BOM 三项：三孔插座 + 16A 船型开关 + 保险丝
  - 机箱只开一个方孔，强电接线 6 根降到 4 根
  - 选型必须确认：① 开关是 2P/DPST ② 保险丝座接受 5×20 **陶瓷**管 ③ 带 CCC/UL/VDE
- **备选**：若结构上必须用 C6，**至少换成面板安装版（非弯插）**，熔断器改 T2A，并在文档写死「仅限 220–240V」

### ADR-005 后续（2026-09-09）：用户送检 IEC320 C14 三合一模块

用户改送 `IEC320 C14 品字电源插座 10A/15A，UL/CUL/VDE/KC/CCC，面板螺钉安装，
带保险丝座 + 带灯船型开关`（淘宝件）。

**形式判定：✅ 通过** —— C14 品字、面板螺钉安装、集成保险丝座与开关，符合 ADR-002 与 ADR-005。

**电流判定：✅ 通过** —— 「10A/15A」是同一接口的双标称（IEC 10A / UL 15A），不是两种规格。
实际工作电流 1.4A，两者都远超。**推荐 10A 版**（与 T3.15A 熔断器的保护关系更清晰），15A 版亦可。

**待卖家确认三项（阻塞下单）：**

| # | 项 | 要求 | 判断方法 |
|---|---|---|---|
| 1 | 开关极数 | **双刀 2P**（同时断 L/N） | 数端子：C14 三脚 + 开关 2 脚 = 单刀；+ 开关 4 脚 = 双刀。带灯 ≠ 单刀，KCD4 带灯双刀存在 |
| 2 | 保险丝座尺寸 | 5×20mm（绝大多数是） | 问卖家，决定买哪种保险丝 |
| 3 | 内部接线拓扑 | 惯例 `L → 保险丝 → 开关 → 出线` | 要接线图；顺带确认插簧是 4.8 还是 6.3mm |

**若只有单刀可选**：安规上允许（GB4943 对可插拔 A 型设备不强制双极断开），但必须同时做到
① 开关断的是 L 线（装配确认，不能装反）② 保险丝也在 L 线上
③ 机箱贴警示「检修前必须拔电源线，不能只关开关」。

理由：国内插座 L/N 反接常见，单刀若断的是 N，关机后机内 EMI 滤波器与 DRS 输入端仍带电，
而这台设备要在变电站现场开箱检查。

**采购渠道建议：改从立创商城采购**，不从淘宝。这是唯一直接接 220V 的件，
淘宝件的认证 logo 印得多、能给证书编号的少；立创有商品编号可追溯且能与 BOM 关联。

**勘误（修正 2026-09-09 早先的说法）**：5×20 陶瓷管与玻璃管**外形尺寸完全相同**，
座子能装玻璃管就能装陶瓷管，不存在「模块只适配玻璃管」的问题。
陶瓷 vs 玻璃的区别在**分断能力**（陶瓷 ≥1500A，玻璃约 35A），这是**买保险丝**时的选择，与座子无关。
座子只需确认是 5×20 还是 6×30。

**RV1 不含在模块内**，必须另配：TMOV14 320Vac（带热脱扣），跨接 L-N，位置在保险丝之后。

## ADR-006 · 母线软启动与反接保护分开处理

- **日期**：2026-09-09
- **决策人**：Claude 提出，待用户确认
- **背景**：P-MOS 的体二极管方向是 D→S，导致：
  - **反接保护**接法（D 接电源、S 接负载）→ 正常时体二极管正向导通 → **拦不住上电冲击**
  - **软启动**接法（S 接电源、D 接负载）→ 正常时体二极管反偏能阻断 → 但**反接时体二极管导通**
  - 两个功能不能共用一只 MOS，全做要两只反向串联，成本翻倍
- **决定**（折中）：
  | 措施 | 器件 |
  |---|---|
  | Q1 只做软启动 | P-MOS（S→+36V_RAW，D→+36V_AMP），栅极 RC τ≈1s |
  | 反接靠 crowbar | D2 反并联肖特基（K→+36V_RAW，A→PGND），反接时导通烧断 F1 |
  | 一次防呆 | J1 用极性防呆连接器 |
- **前提**：电池侧已有 F_BAT 与 DC 断路器，DRS 到板子是固定线束，装配时接反概率可控。

## ADR-009 · 两颗 TPS73633 都保留；基准第一版用外部 3.3V

- **日期**：2026-09-09
- **决策人**：Claude 论证，用户询问后确认方向
- **背景**：用户问「如果内部基准更好，是否可以去掉多余的那颗 TPS73633」。
- **结论：不能去掉，两颗都保留。**

**理由一：换 VREFBUF 省不掉任何一颗 LDO。**

| LDO | 负载 | 换 VREFBUF 后 |
|---|---|---|
| U13 → D3V3 | MCU 4×VDD、TCA9535、FM24V10、逻辑、上拉 | 不受影响 |
| U6 → A3V3 | **VDDA(29)** + VREF+(28) + AMC3301/3330 低压侧 | **VDDA 与 AMC 仍需供电** |

VREFBUF 本身靠 VDDA 供电（Table 78：2.9V 档要求 VDDA = 3.135~3.6V；
Figure 3：VDDA → 带隙 → 缓冲器 → VREF+）。**没有 A3V3 就没有 VREFBUF。**

**理由二：两颗分开的意义是数字/模拟电源隔离，与基准方案无关。**
U13 带的是 170MHz 内核的开关电流与 GPIO 边沿；若与 VDDA 共用一颗 LDO，
噪声会经共享输出阻抗耦合到 ADC 的模拟电源与基准。对测 |Z| 与相位的仪器不可接受。

**决定：**
- 两颗 TPS73633 保留
- `A3V3 → VREF+` 加 0Ω 跳线（0603），零成本保留切换 VREFBUF 的余地
- 第一版用 3.3V 外部基准；|Z|/R/X/相位不受 VREF 精度影响，
  V/I/VA/W 绝对值出厂标定一次即可
- 待 AMC3301/AMC3330 手册到位、且实测温漂不满意时再评估切换

## ADR-008 · 继电器驱动器与继电器放继电器板，不放 PWR-01

- **日期**：2026-09-09
- **决策人**：Claude 提出，待用户确认
- **决定**：ULN2803/TBD62083 与 8 个小继电器（K_TRANS + 7 抽头）、2 只 G7L KSAFE
  全部放在继电器板（RLY-01，紧挨变压器）。PWR-01 只经 J11 给它供 12V（2 根线 + T1A 熔断）。
- **理由**：
  1. **续流回路要短**：关断继电器时线圈反峰靠驱动器内部 COM 二极管钳位。
     驱动与线圈分处两板时，几十厘米线束成天线，di/dt 打出的 EMI 会串进
     AMC3301/AMC3330 采样链
  2. **线束减半**：驱动在继电器板只需 8 根 3.3V 信号 + 2 根 12V 电源；
     放 PWR-01 则要 8 根信号进 + 8 根功率线出
  3. 12V 侧 316 mA（两只 G7L）不必跨板往返
- **影响**：PWR-01 的 12V 电路简化为「接收 → 保护储能 → 分四路」。

**配套的一条硬性要求**：J11 这一路**必须用熔断器，不能用 PTC**。
PTC 跳闸后是高阻带残压状态，继电器会卡在半吸合/抖动、触点持续拉弧 ——
对 KSAFE 安全切断继电器而言比彻底断开危险得多。风扇、蜂鸣器不是安全相关，用 PTC 无妨。

## ADR-010 · 采样链定案：VREFBUF 2.9V、shunt 15mΩ、分压 443.9:1

- **日期**：2026-09-11
- **决策人**：Claude 论证（依据 AMC3301/AMC3330 手册入库后的核算）
- **背景**：用户补入两颗 AMC 的 datasheet，并提出「模拟部分好像用不到 3V3」。

**① AMC 低侧供电：接 A3V3 (3.3 V)，不接 5 V。**
两颗都支持 3.0/3.3/5.5 V，但 MCU 的 VDDA/VREF+ 必须 3.3 V（A3V3 省不掉）；
且 **VCMout = 1.44 V 与 VDD 无关**（手册测试条件 VDD = 3.0~5.5 V），
接 5 V 在信号上无任何好处，只多耗散 ≈0.1 W 且电源更脏。

**② 基准改用内部 VREFBUF 2.9 V（推翻 ADR-009 的「第一版用外部 3.3V」）。**

STM32 Table 66：差分模式 `V_CMIN = VREF+/2 ± 0.18 V`（窗口仅 ±180 mV）

| VREF+ | 要求窗口 | AMC VCMout (1.39/1.44/1.49) | |
|---|---|---|---|
| 3.3 V | 1.47 ~ 1.83 V | 1.39 ~ 1.49 V | ❌ typ 1.44 低于下限 |
| **2.9 V** | **1.27 ~ 1.63 V** | 1.39 ~ 1.49 V | ✅ 全部落入 |
| 2.5 V | 1.07 ~ 1.43 V | 1.39 ~ 1.49 V | ❌ typ 超上限 |

**这不是精度优化，是规格匹配。** 硬件：`A3V3 → VREF+` 的 0 Ω **不装**；
软件：`VREFBUF_CSR.VRS = 10, ENVR = 1`。
⚠️ 0 Ω 与 VREFBUF 二者只能存其一，同时存在会损坏 VREF+ 输出级。

*备选*（若不启用 VREFBUF）：改单端模式，OUTP/OUTN 各占一 ADC，
ADC1/2 与 ADC3/4 两对同步采样后软件相减；单端无共模限制，但占 4 个 ADC 且存在 ADC 间失配。

**③ 分流电阻必须 15 mΩ（结案待决事项 #2）。**
8 Arms → 峰值 11.31 A：15 mΩ → 170 mV，占 AMC3301 线性区 ±250 mV 的 68% ✅；
20 mΩ → 226 mV，占 90.5%，感性负载过冲即出线性区，且精度规格仅在 ±250 mV 内保证。

**④ AMC3330 分压下臂 1.02 kΩ → 806 Ω（0.1%）。**
原 351:1 使 250 Vrms 时 AMC 输入 1.009 V，超出 V_FSR = ±1 V。
改后 443.9:1 → 0.7975 V（占 79.7%），削顶点对应 392 Vrms（余量 57%）。
上臂 7×51 kΩ 不变：总耗散 0.175 W，每只 25 mW / 35.7 Vrms。

**⑤ A3V3 负载修正**：原估 50 mA → 实际 **typ 71 / max 96 mA**
（AMC 内置隔离 DC/DC，IDD max 40/41 mA）。U6 的 Tj 由 64–67 °C 修正为 **76–83 °C**，仍安全。

完整推导：`docs/03-analog/采样链-AMC3301-AMC3330-设计与计算.md`
