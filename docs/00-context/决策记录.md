## ADR-004 · 接地：全机单点星型接地

- **日期**：2026-09-09
- **决策人**：Claude 提出，待用户确认
- **背景**：DDR-30L 是隔离型 DC/DC，PGND / GND_AUX / DGND 本可各自独立。但：
  - MCU 的 DAC 输出要送到 TPA3255 的输入 → **PGND 与 DGND 必须共地**
  - ULN2803 的输入来自 TCA9535（DGND 域），输出驱动 12V 继电器 → **GND_AUX 与 DGND 也必须共地**
  - 结论：整机实际上是单地系统，DC/DC 的隔离只用于抑制共模噪声
- **决定**：
  - **PGND / GND_AUX / DGND** 在 **PWR-01 上一个星点**汇合（用 0Ω 跳线 R100/R101，便于调试时断开查地环路）
  - **⚠️ 修订（2026-09-09）：AGND 不参与 PWR-01 的星点。**
    AGND 只存在于控制板（U6 供 VDDA/VREF+），PWR-01 上 `V_BUS_SENSE` 的 AGND
    只经 J3 回控制板。若在 PWR-01 本地再连一次 DGND，AGND 就有两条通路，构成**地环路**。
  - 控制板内部的 AGND ↔ DGND 用**一只 0Ω 连接，放在 MCU 的 VSSA (pin 27) 旁**
    （VREF- 与 VSSA 内部同绑，是测量系统的零点）。PCB 用**单一完整地平面 + 布局分区**，
    不切缝。详见 `docs/02-digital/MCU最小系统-设计与计算.md` §1.7
  - 星点经 R103（0Ω，或 1MΩ ∥ 10nF）单点接 PE
  - 功率地铜箔独立回到星点，不与数字地共用回流路径（TPA3255 的开关电流有几安培）
- **注**：4 路 PC817C **仍然保留**。它隔离的不是电源域，而是 **DRS 到板子那几十厘米走在强电区的线束地环路**，有价值。

## ADR-005 · AC 插座：改用 IEC C14 三合一模块

- **日期**：2026-09-09
- **决策人**：Claude 建议，**待用户确认**
- **背景**：用户送检 `RT-C06-A1B-CC`（立创 C6775838，IEC 320-C6 米老鼠，2.5A/250VAC，**PCB 弯插**）
- **否决理由**：
  1. **弯插 = 装在 PCB 上**，与 ADR-002（强电不上板）直接冲突
  2. C6 额定 2.5A：230V 下 DRS 输入 1.4A 够用（1.79×），但 **115V 下 DRS 要 2.8A > 2.5A 超额定**
  3. 熔断器必须保护最弱环节，用 C6 就得选 T2A，与 16A 开关、T3.15A 熔断器不匹配
  4. C5 米老鼠线是笔记本适配器级别，工业现场不常备
- **建议**：**IEC 60320 C14 三合一模块**（插座 + 5×20 保险丝座 + 双刀开关），面板卡扣安装，10A/250VAC
  - 一个件替掉现 BOM 三项：三孔插座 + 16A 船型开关 + 保险丝
  - 机箱只开一个方孔，强电接线 6 根降到 4 根
  - 选型必须确认：① 开关是 2P/DPST ② 保险丝座接受 5×20 **陶瓷**管 ③ 带 CCC/UL/VDE
- **备选**：若结构上必须用 C6，**至少换成面板安装版（非弯插）**，熔断器改 T2A，并在文档写死「仅限 220–240V」

### ADR-005 后续（2026-09-09）：用户送检 IEC320 C14 三合一模块

用户改送 `IEC320 C14 品字电源插座 10A/15A，UL/CUL/VDE/KC/CCC，面板螺钉安装，
带保险丝座 + 带灯船型开关`（淘宝件）。

**形式判定：✅ 通过** —— C14 品字、面板螺钉安装、集成保险丝座与开关，符合 ADR-002 与 ADR-005。

**电流判定：✅ 通过** —— 「10A/15A」是同一接口的双标称（IEC 10A / UL 15A），不是两种规格。
实际工作电流 1.4A，两者都远超。**推荐 10A 版**（与 T3.15A 熔断器的保护关系更清晰），15A 版亦可。

**待卖家确认三项（阻塞下单）：**

| # | 项 | 要求 | 判断方法 |
|---|---|---|---|
| 1 | 开关极数 | **双刀 2P**（同时断 L/N） | 数端子：C14 三脚 + 开关 2 脚 = 单刀；+ 开关 4 脚 = 双刀。带灯 ≠ 单刀，KCD4 带灯双刀存在 |
| 2 | 保险丝座尺寸 | 5×20mm（绝大多数是） | 问卖家，决定买哪种保险丝 |
| 3 | 内部接线拓扑 | 惯例 `L → 保险丝 → 开关 → 出线` | 要接线图；顺带确认插簧是 4.8 还是 6.3mm |

**若只有单刀可选**：安规上允许（GB4943 对可插拔 A 型设备不强制双极断开），但必须同时做到
① 开关断的是 L 线（装配确认，不能装反）② 保险丝也在 L 线上
③ 机箱贴警示「检修前必须拔电源线，不能只关开关」。

理由：国内插座 L/N 反接常见，单刀若断的是 N，关机后机内 EMI 滤波器与 DRS 输入端仍带电，
而这台设备要在变电站现场开箱检查。

**采购渠道建议：改从立创商城采购**，不从淘宝。这是唯一直接接 220V 的件，
淘宝件的认证 logo 印得多、能给证书编号的少；立创有商品编号可追溯且能与 BOM 关联。

**勘误（修正 2026-09-09 早先的说法）**：5×20 陶瓷管与玻璃管**外形尺寸完全相同**，
座子能装玻璃管就能装陶瓷管，不存在「模块只适配玻璃管」的问题。
陶瓷 vs 玻璃的区别在**分断能力**（陶瓷 ≥1500A，玻璃约 35A），这是**买保险丝**时的选择，与座子无关。
座子只需确认是 5×20 还是 6×30。

**RV1 不含在模块内**，必须另配：TMOV14 320Vac（带热脱扣），跨接 L-N，位置在保险丝之后。

## ADR-006 · 母线软启动与反接保护分开处理

- **日期**：2026-09-09
- **决策人**：Claude 提出，待用户确认
- **背景**：P-MOS 的体二极管方向是 D→S，导致：
  - **反接保护**接法（D 接电源、S 接负载）→ 正常时体二极管正向导通 → **拦不住上电冲击**
  - **软启动**接法（S 接电源、D 接负载）→ 正常时体二极管反偏能阻断 → 但**反接时体二极管导通**
  - 两个功能不能共用一只 MOS，全做要两只反向串联，成本翻倍
- **决定**（折中）：
  | 措施 | 器件 |
  |---|---|
  | Q1 只做软启动 | P-MOS（S→+36V_RAW，D→+36V_AMP），栅极 RC τ≈1s |
  | 反接靠 crowbar | D2 反并联肖特基（K→+36V_RAW，A→PGND），反接时导通烧断 F1 |
  | 一次防呆 | J1 用极性防呆连接器 |
- **前提**：电池侧已有 F_BAT 与 DC 断路器，DRS 到板子是固定线束，装配时接反概率可控。

## ADR-012 · 继电器与驱动器确认移到继电器板 RLY-01（ADR-008 转为已确认）

- **日期**：2026-09-11
- **决策人**：**用户拍板**（「那还是移动到继电器板吧」）
- **决定**：ADR-008 由「Claude 提出，待用户确认」转为 **已确认执行**。
  `U10 (ULN2803/TBD62083)` 与 `K1–K8` 从控制板**删除**，连同 2 只 G7L KSAFE 放 RLY-01。

### 控制板要做的删改

| 动作 | 对象 |
|---|---|
| **删除** | `U10`（SOP-18）、`K1–K8`（G2RL-2 ×1 + G5RL-1A ×7） |
| **删除** | `GND` 网络里的 `U10.9` |
| **新增** | `J11` 2P 5.08mm 端子 → RLY-01 供 12 V（**串 T1A 熔断器，不能用 PTC**） |
| **新增** | `J12` 10P IDC（或 2×5 排针）→ RLY-01 送 8 路逻辑 + 2 根地 |
| **保留** | `U8` TCA9535 留在控制板（它的 P10–P17 是本板的输入，搬不走） |

### 板间接口：走 8 根逻辑线，**不走 I²C**

ADR-008 原案就是 8 根 3.3 V 信号 + 2 根 12 V。看到 rev5 加了 `SCL3/SDA3`，
先说清楚：**那两根是本板 I²C3 总线（接 U8 TCA9535 + U9 FRAM），不是给 RLY-01 的。**

把 I²C 拉到 RLY-01 看起来能省 5 根线，但**不采纳**：

| | 8 根逻辑线（采纳） | I²C 拉过去（不采纳） |
|---|---|---|
| 电平 | 3.3 V CMOS **推挽**，噪声裕度大 | **开漏**，靠上拉恢复，裕度小 |
| 线束环境 | 旁边就是继电器线圈和 D 类功放 | 同上，但开漏总线扛不住 |
| 失效模式 | 单根受扰 = 单路误动作 | **总线锁死 = 8 路全失控** |
| 安全性 | — | 其中 2 只是 **G7L KSAFE 安全切断继电器**，总线锁死时命令不出去 |
| 器件 | 不增加 | 要在 RLY-01 再加一片扩展器 |
| TCA9535 引脚 | 16 脚刚好用满（P0x 输出 / P1x 输入） | 要拆成两片 |

**多 5 根线换掉一个「安全继电器失控」的失效模式，值。**

### 仍然成立的两条（来自 ADR-008 与首轮评审）

- **J11 必须用熔断器不能用 PTC**：PTC 跳闸后是高阻带残压，继电器卡半吸合、触点持续拉弧
- **TCA9535 没有 RESET 引脚** → 看门狗复位 MCU 时继电器停在故障前状态（评审 P0-5）。
  继电器挪到板外后这条**更严重**了：控制板复位，RLY-01 上的输出寄存器不动。
  → 待决 #4（换 TCA9539，RESET 接 MCU NRST）**升级为必做**

## ADR-013 · 功放独立成板；DDS 经差分线送过去

- **日期**：2026-09-11
- **决策人**：Claude 论证（回答用户「内部 DDS 到功放是不是最好在一块板子上」）
- **背景**：用户担心 DAC 输出跨线束变脏。

**决定：功放保持板外件（沿用 ADR-002 / SH1），DDS 不与功放同板。**

**理由：**

1. TPA3255 是 D 类，PVDD 30–43 V、几安培、开关几百 kHz、输出 dV/dt 每纳秒几伏；
   控制板上是 1 LSB = 708 µV 的差分 ADC、AMC 采样链和 VREFBUF。
   **且 D 类开关噪声与输出信号相关**，不会被平均掉，直接变成 |Z| 与相位的系统误差
2. 它自身耗散 ≈7 W 要散热器，板上上千 µF 体电容，本来就是独立模块（TPA3255EVM）
3. **跨板的真正问题是「单端传」不是「跨板」**：功放回流 1.67 A（峰值 3 A）
   在 15 mΩ 回线上造成 25–45 mV 地偏移，单端传时原封不动叠进信号（−32 ~ −27 dB），
   且落在 2× 输出频率上（BTL 供电电流 ∝ sin²）→ 谐波失真
   → **用差分/伪差分传输即可完全抵掉**，一根屏蔽双绞线解决

**接口与滤波器要求见 `docs/03-analog/DDS输出到功放-板级归属与接口.md`。**

> ## 🔄 更正（2026-09-11）：理由 3 的**危害程度被我说重了**
>
> 「25–45 mV 地偏移叠进信号」这个计算没错，但**对这台仪器的实际后果有限**：
> 偏移落在 **2× 输出频率**上，而本机测量是**相干采样 + DFT 取基波 bin**
> （N = 125 点整周期），**二次谐波落在别的 bin 里被天然抑制**
> → 对 |Z| / R / X / 相位基本无影响，实际只是输出波形多几个百分点二次谐波。
>
> **「功放独立成板」的结论不变**（真正的理由是理由 1 的 EMI 打进 AMC 采样链、
> 7 W 散热、本来就是成品模块），**但「必须差分」降级为「能差分更好」**。
>
> 用户选的成品模块（晒邦 TPA3255 600W）是 **RCA 单端输入**，做不了差分，
> 按上述更正，单端 + 屏蔽双绞 + 功放回线单独回星点即可。
> 见 `docs/01-power/功放模块核对-晒邦TPA3255-600W.md` P2-B。

> ⚠️ TPA3255 手册不在 `reference/` 里，输入共模范围、增益档、CLIP_OTW 是否开漏、
> RESET/MUTE 时序**全部标「待核实」**，手册入库后补。

## ADR-015 · AMC3301 / AMC3330 贴着 shunt 放，不放主板

- **日期**：2026-09-12
- **决策人**：**用户拍板**（「贴着 shunt」）—— 待决事项 #18 的答案，选**方案 B**
- **决定**：`AMC3301`（电流）与 `AMC3330`（电压）**放在 shunt / 变压器那一侧**
  （与 RLY-01 同板，或另做一小块采样板），**不放 MAIN-01**。

### 理由

**隔离器件的意义就是把"脏的那一侧"留在原地。**

| | 方案 A（放主板，已否决） | **方案 B（贴 shunt，采纳）** |
|---|---|---|
| 走线束的是什么信号 | shunt 上的 **120 mV 差模**（15 mΩ × 8 Arms） | **隔离后、增益 8.2× 之后的 ±0.696 V 差分** |
| 同样绝对干扰下的相对误差 | 基准 | **小 8.2 倍** ✅ |
| 小信号所处环境 | 要穿过 8 Arms 大电流区的几十厘米线束 | **不出板，回路面积最小** ✅ |
| AMC 高压侧参考地 | 在线束远端（浮着） | **就在 shunt 上** ✅ |

### 🔴 配套的硬性要求：AMC 低压侧的 `GND2` 必须由主板经线束单独供给

方案 B 把风险从"小信号走线束"换成了"**差分信号的共模必须落在 ADC 的窗口里**"。
这个窗口很窄：

```
STM32 差分 ADC（VREF+ = 2.9 V）：V_CMIN = VREF+/2 ± 0.18 V = 1.27 ~ 1.63 V
AMC 的 VCMout                   = 1.44 V
                                → 可容忍的共模偏移只有 ±170 mV
```

**偏移来自主板 `AGND` 与 AMC 低压侧 `GND2` 之间的电位差。**
只要 `GND2` 只经这根线束接主板 `AGND`、**不在采样板上就地接地**，偏移就只有
AMC 自身电流在回线上的压降：

| 线束 | 回线电阻 | 81 mA（两片 max）造成的偏移 | 对 ±170 mV 的余量 |
|---|---|---|---|
| 0.5 m 24AWG | 42 mΩ | **3.4 mV** | **50×** ✅ |
| 0.5 m 22AWG | 26 mΩ | 2.1 mV | 79× ✅ |
| 1.0 m 24AWG | 84 mΩ | 6.8 mV | 25× ✅ |

**余量极大 ✅ —— 但前提是那条"不就地接地"的规则。**
一旦采样板上把 `GND2` 就近接到功率地，8 Arms 回流的压降就会直接吃掉这 170 mV。

### 板间接口（MAIN-01 ↔ 采样板）

| # | 信号 | 方向 | 说明 |
|---|---|---|---|
| 1 | `3V3_AVDD` | 主板 → 采样板 | 两片 AMC 低压侧，typ 56 / **max 81 mA** |
| 2 | `AGND` | 主板 → 采样板 | 🔴 **唯一的接地路径**，采样板上不得再就地接地 |
| 3 | `I_OUTP` | ← | AMC3301 差分输出 + |
| 4 | `I_OUTN` | ← | AMC3301 差分输出 − |
| 5 | `V_OUTP` | ← | AMC3330 差分输出 + |
| 6 | `V_OUTN` | ← | AMC3330 差分输出 − |
| 7~8 | `AGND` ×2 | — | 夹在信号之间，减小回路面积 |

**线束要求：**

- **两对输出各自绞在一起**（`I_OUTP/I_OUTN` 一对、`V_OUTP/V_OUTN` 一对），外面一层总屏蔽
- 屏蔽层**只在主板这一头**接 `AGND`（单端接地，避免地环路）
- 容性负载不是问题：0.5 m 线束约 50 pF，10 kHz 下 Xc = 318 kΩ，
  而 AMC3330 手册要求负载 ≥10 kΩ ✅ 余量 30 倍
- **抗混叠滤波（100 Ω + 10 nF）放在主板端、ADC 输入之前**，顺带兼做共模抑制

### 对 MAIN-01 的改动

- **删掉 `U11` / `U12`**（目前只放了 SOIC-16 封装，没连线）
- 新增一个 **8P 接口**（IDC 或带扣端子）按上表定义
- 抗混叠 RC（2 组 100 Ω + 10 nF）留在主板端

### 🆕 补充条款（2026-09-12，AMC23C12/UCC12050 手册核对后）

**`AMC23C12` ×2 和 `UCC12050` 也放采样板（SNS-01），不放 MAIN-01。**
上面那张 8P 模拟接口表 **定义完全不变**，只是**另加一个 8P 数字接口**。

**理由：**

1. `AMC23C12` 的 `IN` 是**单端输入，相对于 `GND1`** —— OC 那片要量 shunt、
   OV 那片要量 250 Vrms 分压链，**两者都在高压侧**。放主板就得把 shunt 引线和
   高压分压链拉上 PCB，与方案 A「高压不上 PCB」直接冲突。
2. 两片的 `GND1` 是**同一个节点**（变压器次级公共端）—— 这正是需求原文说
   「一片 UCC12050 供两片」成立的前提。
3. `AMC3301`/`AMC3330` **自带隔离 DC/DC**，`AMC23C12` **没有**，必须靠 `UCC12050`
   → 两者天然同板。

**🆕 模拟接口由 8P 扩到 9P（2026-09-13）**：加第 9 脚 `SHIELD`，经 **`R38` 0Ω** 接 `AGND`。
原文只说「屏蔽层只在主板这头接 AGND」，没说接在哪 —— 现在有落点了。
座子用 **XH2.54-9P 带扣**，🔴 **不能用牛角/排线**（绞线和屏蔽做不了）。
实际位号：`CN4`。逐脚接法见 `绘图-第2+3步-模拟采样链与DDS输出链.md`。

**新增 `J_SNS_D` 8P（数字/保护）：**

| 脚 | 网络 | 说明 |
|---|---|---|
| 1 | `+5V_SNS` | UCC12050 的 `VINP`，**64 mA** |
| 2 | `DGND` | 🔴 5 V 的**专用回线** |
| 3 | `+3V3_SNS` | 两片 `VDD2`，合计 4.4 mA（🔴 必须 3.3 V，否则 `LATCH` 的 VIH 够不着） |
| 4 | `DGND` | — |
| 5 | `PROT_LATCH` | ← MCU `PB7` |
| 6 | `OC_FAULT#` | → 开漏 |
| 7 | `OV_FAULT#` | → 开漏 |
| 8 | `SNS_PRESENT#` | 板上直接短到 `DGND`，主板端上拉 → 拔线束能报警 |

🔴 **SNS-01 上有三个互不相连的地**：`GND1`（高压侧，浮空）、
`AGND`（只经 `J_SNS_A` 回主板，**不得就地接地**）、
`DGND`（只经 `J_SNS_D` 回主板）。
**UCC12050 一次侧那 64 mA 绝对不能流在 `AGND` 线上** —— 会吃掉 ADC 差分共模
仅有的 ±170 mV 窗口。这就是为什么 `J_SNS_D` 必须有自己的地线。

## ADR-009 · 两颗 TPS73633 都保留；基准第一版用外部 3.3V

- **日期**：2026-09-09
- **决策人**：Claude 论证，用户询问后确认方向
- **背景**：用户问「如果内部基准更好，是否可以去掉多余的那颗 TPS73633」。
- **结论：不能去掉，两颗都保留。**

**理由一：换 VREFBUF 省不掉任何一颗 LDO。**

| LDO | 负载 | 换 VREFBUF 后 |
|---|---|---|
| U13 → D3V3 | MCU 4×VDD、TCA9535、FM24V10、逻辑、上拉 | 不受影响 |
| U6 → A3V3 | **VDDA(29)** + VREF+(28) + AMC3301/3330 低压侧 | **VDDA 与 AMC 仍需供电** |

VREFBUF 本身靠 VDDA 供电（Table 78：2.9V 档要求 VDDA = 3.135~3.6V；
Figure 3：VDDA → 带隙 → 缓冲器 → VREF+）。**没有 A3V3 就没有 VREFBUF。**

**理由二：两颗分开的意义是数字/模拟电源隔离，与基准方案无关。**
U13 带的是 170MHz 内核的开关电流与 GPIO 边沿；若与 VDDA 共用一颗 LDO，
噪声会经共享输出阻抗耦合到 ADC 的模拟电源与基准。对测 |Z| 与相位的仪器不可接受。

**决定：**
- 两颗 TPS73633 保留
- `A3V3 → VREF+` 加 0Ω 跳线（0603），零成本保留切换 VREFBUF 的余地
- 第一版用 3.3V 外部基准；|Z|/R/X/相位不受 VREF 精度影响，
  V/I/VA/W 绝对值出厂标定一次即可
- 待 AMC3301/AMC3330 手册到位、且实测温漂不满意时再评估切换

  全部放在继电器板（RLY-01，紧挨变压器）。PWR-01 只经 J11 给它供 12V（2 根线 + T1A 熔断）。
- **理由**：
  1. **续流回路要短**：关断继电器时线圈反峰靠驱动器内部 COM 二极管钳位。
     驱动与线圈分处两板时，几十厘米线束成天线，di/dt 打出的 EMI 会串进
     AMC3301/AMC3330 采样链
  2. **线束减半**：驱动在继电器板只需 8 根 3.3V 信号 + 2 根 12V 电源；
     放 PWR-01 则要 8 根信号进 + 8 根功率线出
  3. 12V 侧 316 mA（两只 G7L）不必跨板往返
- **影响**：PWR-01 的 12V 电路简化为「接收 → 保护储能 → 分四路」。

**配套的一条硬性要求**：J11 这一路**必须用熔断器，不能用 PTC**。
PTC 跳闸后是高阻带残压状态，继电器会卡在半吸合/抖动、触点持续拉弧 ——
对 KSAFE 安全切断继电器而言比彻底断开危险得多。风扇、蜂鸣器不是安全相关，用 PTC 无妨。

## ADR-010 · 采样链定案：VREFBUF 2.9V、shunt 15mΩ、分压 443.9:1

- **日期**：2026-09-11
- **决策人**：Claude 论证（依据 AMC3301/AMC3330 手册入库后的核算）
- **背景**：用户补入两颗 AMC 的 datasheet，并提出「模拟部分好像用不到 3V3」。

**① AMC 低侧供电：接 A3V3 (3.3 V)，不接 5 V。**
两颗都支持 3.0/3.3/5.5 V，但 MCU 的 VDDA/VREF+ 必须 3.3 V（A3V3 省不掉）；
且 **VCMout = 1.44 V 与 VDD 无关**（手册测试条件 VDD = 3.0~5.5 V），
接 5 V 在信号上无任何好处，只多耗散 ≈0.1 W 且电源更脏。

**② 基准改用内部 VREFBUF 2.9 V（推翻 ADR-009 的「第一版用外部 3.3V」）。**

STM32 Table 66：差分模式 `V_CMIN = VREF+/2 ± 0.18 V`（窗口仅 ±180 mV）

| VREF+ | 要求窗口 | AMC VCMout (1.39/1.44/1.49) | |
|---|---|---|---|
| 3.3 V | 1.47 ~ 1.83 V | 1.39 ~ 1.49 V | ❌ typ 1.44 低于下限 |
| **2.9 V** | **1.27 ~ 1.63 V** | 1.39 ~ 1.49 V | ✅ 全部落入 |
| 2.5 V | 1.07 ~ 1.43 V | 1.39 ~ 1.49 V | ❌ typ 超上限 |

**这不是精度优化，是规格匹配。** 硬件：`A3V3 → VREF+` 的 0 Ω **不装**；
软件：`VREFBUF_CSR.VRS = 10, ENVR = 1`。
⚠️ 0 Ω 与 VREFBUF 二者只能存其一，同时存在会损坏 VREF+ 输出级。

*备选*（若不启用 VREFBUF）：改单端模式，OUTP/OUTN 各占一 ADC，
ADC1/2 与 ADC3/4 两对同步采样后软件相减；单端无共模限制，但占 4 个 ADC 且存在 ADC 间失配。

**③ 分流电阻必须 15 mΩ（结案待决事项 #2）。**
~~8 Arms → 峰值 11.31 A：15 mΩ → 170 mV，占 68%；20 mΩ → 226 mV，占 90.5%，余量不足。~~

🔧 **2026-09-14 更正（结论不变，理由换了）**：变压器规格表给出最大电流是 **7.07 Arms** 不是 8 Arms。
重算：**15 mΩ → 150.0 mV 峰，占 ±250 mV 的 60.0%**；**20 mΩ → 200 mV，占 80.0%** ——
20 mΩ 其实**没有**超线性区。**但仍然选 15 mΩ**，理由是：
① 60% vs 80% 的余量（感性负载过冲、扫频瞬态都要留地方）；
② 功耗 **0.750 W vs 1.00 W**，直接决定待决 #52 上不上板。
已购的 20 mΩ 留作备件。

**④ AMC3330 分压下臂 1.02 kΩ → 806 Ω（0.1%）。**
原 351:1 使 250 Vrms 时 AMC 输入 1.009 V，超出 V_FSR = ±1 V。改后 **443.9:1**。

🔧 **2026-09-14 更正（分压比不变）**：最大输出电压由 250 Vrms 改为 **223.6 Vrms**。
443.9:1 → **0.712 V（占 71.2% FS）**，削顶点 313.9 Vrms（**余量 1.40×**）。
上臂 7×51 kΩ 不变：总耗散 **0.140 W**，每只 **20 mW / 31.9 Vrms**。

**⑤ A3V3 负载修正**：原估 50 mA → 实际 **typ 71 / max 96 mA**
（AMC 内置隔离 DC/DC，IDD max 40/41 mA）。U6 的 Tj 由 64–67 °C 修正为 **76–83 °C**，仍安全。

完整推导：`docs/03-analog/采样链-AMC3301-AMC3330-设计与计算.md`

## ADR-016 · 风扇不做调速，12 V 常开满速

- **日期**：2026-09-12
- **决策人**：**用户拍板**（「风扇不要控制，直接满速输出就行」）

**电路**：`12V_AUX ──[F5 T1A]──→ J14(2P) ──→ 风扇`，端子处并 100 µF(≥25 V) + 100 nF。

**三条配套结论：**

1. **买到四线风扇也不用接 PWM** —— Intel 四线规范里 **PWM 脚悬空 = 全速**，
   PWM/TACH 两根直接不接即可，不用换风扇。
2. 🔴 **3 路 NTC 一定还要画**。取消的是"调速"，不是"测温"。
   过温要能降功率/停机，NTC 是唯一的温度来源（尤其在 ADR-017 砍掉功放 OTW 之后）。
3. `F5` 由 T500mA 改 **T1A** —— 电机启动电流是额定的 2~3 倍（0.2 A → 瞬时 0.5 A），
   且和 `F2`/`F3` 同料号。

**释放引脚**：`PB10`(30, TIM2_CH3) 和 `PA11`(45, TIM4_CH1) 回空闲池。

> 🟡 建议在 `PB10` 处保留 **BSS138 + 100 Ω + 10 kΩ 下拉的位（不装元件）**，
> 万一整机噪声太大想加调速，补三个件即可，不必改板。

## ADR-018 · 删掉与门 `U29`，输出切断挂账到换功放

- **日期**：2026-09-18
- **决策人**：**用户拍板**（「那就先不管这个安不安全了，后面换功放再加，可以先把这几个 NTC 加回来，把这个与非门删了吧」）

### 背景

用户当天先确认**「这款功放没有使能引脚」** → 硬件保护链
（`AMC23C12` OC/OV → `U29` 与门 → `AMP_ENABLE`）**失去了执行机构**：
与门的输出没有下家。我给的 A+C 分层方案（`Q4` AO3400 静音 + 断继电器线圈）需要改 7 处原理图。
**用户选择不改，先把这颗没用的门删掉，等换功放时一并做。**

### 决策

| | 内容 |
|---|---|
| ❌ **删** | `U29`（74LVC1G08）、`R45`（100 Ω）；网络 `$4N2` / `AMP_ENABLE` 随之消失 |
| ❌ **不做** | `功放无使能脚-输出切断方案.md` 的全部 7 条改动（`Q4`/`R58`/74LVC1G00/`CN3` 扩 14P/改网名） |
| ✅ **留** | `HARD_OK_MON`（`R54` 2.2 kΩ↑ + `C75` 1 nF + `CN9.3/.4` + **`PA15`**）、`PROT_LATCH`(PB7)、`SNS_PRESENT#`(PB0)、`PD2`+`R44` |
| 🔧 **改** | `CN5` **保持 6P**，`.1`/`.2`/`.3` 丝印标 `NC`（**不减成 3P** —— 换功放那天使能线原地回到 `.3`，板子不用重画） |

### 🔴 由此改变的保护架构（事实陈述，供换功放时对账）

**执行机构从「与门 + 功放使能脚」变成「MCU 的中断服务程序」：**
`OC/OV → HARD_OK_MON → PA15 (EXTI) → 停 DAC/DMA → 静音`。

| | |
|---|---|
| 🟢 **MCU 正常时** | EXTI 延迟 12 cycles @170 MHz = **70.6 ns** + ISR → **软件静音 < 1 µs**，和原来的硬件通路同一数量级 |
| ✅ MCU 复位/掉电 | 仍安全 —— DAC 停 → `C65` 2.2 µF 是**串联隔直电容** → 输出归零 |
| ✅ `UCC12050` 坏/线束断 | 仍看得见 —— AMC `VDD1` 掉电 >100 µs → `OUT` 主动拉低 |
| ✅ 拔采样板 | 仍看得见 —— `SNS_PRESENT#` |
| 🔴 **MCU 跑飞但 DMA 还在输出** | **唯一没人管的故障**，只有 IWDG 兜底（喂狗 ≤300 ms，`t_tout` min 0.9 s / max 2.5 s）→ **最坏 2.5 s** |
| 🔴 1.0~1.45× 持续过载 | **本来就没人管**（OC 跳闸在 1.46×）→ 归 **T-3** 管 |

**那 2.5 s 窗口的量级**：热 —— 铜损 2.1×、多出 ≈50 J、变压器 ΔT **< 0.1 °C**（热时间常数是分钟级）；
电 —— OV 门限 288 Vrms vs 端子 250 V 超 15%，爬电/间隙按 ≤300 V 档设计扛得住；
人 —— 归门互锁和机箱管，本来就不归 OC/OV。
→ 🟢 **机箱关着、互锁生效时实际风险很小**；🔴 **开箱调试、互锁被短接时它是真实暴露面。**

### 配套

- **待决 #57 同时结案**：3 路 NTC 全部加回（ADR-018 的另一半），T-3 优先级上升
- **待决 #56 作废**：`74LVC1G08` 不用买了
- 特批跨缝信号**由 4 根退回 3 根**（`SNS_PRESENT#` / `V_BUS_SENSE` / `PA12`）
- 逐脚改动单与 8 条自检判据：**`docs/00-context/绘图-rev22改动-NTC回归与删与门.md`**

### 🔴🔴 2026-09-18 晚补记（审图 #28）：rev22 把 `HARD_OK_MON` 也一起删了

本 ADR 明写「✅ **留** `HARD_OK_MON` 整条」，实际 rev22 里 `R54`/`C75` 不存在、`PA15` 悬空、
`OC_FAULT#`/`OV_FAULT#` 成了两个单节点网。

→ **上面 §「由此改变的保护架构」那张表整个不成立** ——
表里每一行「MCU 看得见」的前提都是 `PA15`，现在 `PA15` 没接：
**OC/OV 保护既没有执行机构、也没有指示，等于完全不存在。**

🔴 **必须补回来**（6 个件，两根线各占一个脚，见待决 #54 的结案）。
补回来之后本 ADR 的分析才重新成立。
