## ADR-004 · 接地：全机单点星型接地

- **日期**：2026-09-09
- **决策人**：Claude 提出，待用户确认
- **背景**：DDR-30L 是隔离型 DC/DC，PGND / GND_AUX / DGND 本可各自独立。但：
  - MCU 的 DAC 输出要送到 TPA3255 的输入 → **PGND 与 DGND 必须共地**
  - ULN2803 的输入来自 TCA9535（DGND 域），输出驱动 12V 继电器 → **GND_AUX 与 DGND 也必须共地**
  - 结论：整机实际上是单地系统，DC/DC 的隔离只用于抑制共模噪声
- **决定**：
  - PGND / GND_AUX / DGND / AGND 在 **PWR-01 上一个星点**汇合（用 0Ω 跳线 R100/R101/R102，便于调试时断开查地环路）
  - 星点经 R103（0Ω，或 1MΩ ∥ 10nF）单点接 PE
  - 功率地铜箔独立回到星点，不与数字地共用回流路径（TPA3255 的开关电流有几安培）
- **注**：4 路 PC817C **仍然保留**。它隔离的不是电源域，而是 **DRS 到板子那几十厘米走在强电区的线束地环路**，有价值。

## ADR-005 · AC 插座：改用 IEC C14 三合一模块

- **日期**：2026-09-09
- **决策人**：Claude 建议，**待用户确认**
- **背景**：用户送检 `RT-C06-A1B-CC`（立创 C6775838，IEC 320-C6 米老鼠，2.5A/250VAC，**PCB 弯插**）
- **否决理由**：
  1. **弯插 = 装在 PCB 上**，与 ADR-002（强电不上板）直接冲突
  2. C6 额定 2.5A：230V 下 DRS 输入 1.4A 够用（1.79×），但 **115V 下 DRS 要 2.8A > 2.5A 超额定**
  3. 熔断器必须保护最弱环节，用 C6 就得选 T2A，与 16A 开关、T3.15A 熔断器不匹配
  4. C5 米老鼠线是笔记本适配器级别，工业现场不常备
- **建议**：**IEC 60320 C14 三合一模块**（插座 + 5×20 保险丝座 + 双刀开关），面板卡扣安装，10A/250VAC
  - 一个件替掉现 BOM 三项：三孔插座 + 16A 船型开关 + 保险丝
  - 机箱只开一个方孔，强电接线 6 根降到 4 根
  - 选型必须确认：① 开关是 2P/DPST ② 保险丝座接受 5×20 **陶瓷**管 ③ 带 CCC/UL/VDE
- **备选**：若结构上必须用 C6，**至少换成面板安装版（非弯插）**，熔断器改 T2A，并在文档写死「仅限 220–240V」

### ADR-005 后续（2026-09-09）：用户送检 IEC320 C14 三合一模块

用户改送 `IEC320 C14 品字电源插座 10A/15A，UL/CUL/VDE/KC/CCC，面板螺钉安装，
带保险丝座 + 带灯船型开关`（淘宝件）。

**形式判定：✅ 通过** —— C14 品字、面板螺钉安装、集成保险丝座与开关，符合 ADR-002 与 ADR-005。

**电流判定：✅ 通过** —— 「10A/15A」是同一接口的双标称（IEC 10A / UL 15A），不是两种规格。
实际工作电流 1.4A，两者都远超。**推荐 10A 版**（与 T3.15A 熔断器的保护关系更清晰），15A 版亦可。

**待卖家确认三项（阻塞下单）：**

| # | 项 | 要求 | 判断方法 |
|---|---|---|---|
| 1 | 开关极数 | **双刀 2P**（同时断 L/N） | 数端子：C14 三脚 + 开关 2 脚 = 单刀；+ 开关 4 脚 = 双刀。带灯 ≠ 单刀，KCD4 带灯双刀存在 |
| 2 | 保险丝座尺寸 | 5×20mm（绝大多数是） | 问卖家，决定买哪种保险丝 |
| 3 | 内部接线拓扑 | 惯例 `L → 保险丝 → 开关 → 出线` | 要接线图；顺带确认插簧是 4.8 还是 6.3mm |

**若只有单刀可选**：安规上允许（GB4943 对可插拔 A 型设备不强制双极断开），但必须同时做到
① 开关断的是 L 线（装配确认，不能装反）② 保险丝也在 L 线上
③ 机箱贴警示「检修前必须拔电源线，不能只关开关」。

理由：国内插座 L/N 反接常见，单刀若断的是 N，关机后机内 EMI 滤波器与 DRS 输入端仍带电，
而这台设备要在变电站现场开箱检查。

**采购渠道建议：改从立创商城采购**，不从淘宝。这是唯一直接接 220V 的件，
淘宝件的认证 logo 印得多、能给证书编号的少；立创有商品编号可追溯且能与 BOM 关联。

**勘误（修正 2026-09-09 早先的说法）**：5×20 陶瓷管与玻璃管**外形尺寸完全相同**，
座子能装玻璃管就能装陶瓷管，不存在「模块只适配玻璃管」的问题。
陶瓷 vs 玻璃的区别在**分断能力**（陶瓷 ≥1500A，玻璃约 35A），这是**买保险丝**时的选择，与座子无关。
座子只需确认是 5×20 还是 6×30。

**RV1 不含在模块内**，必须另配：TMOV14 320Vac（带热脱扣），跨接 L-N，位置在保险丝之后。

## ADR-006 · 母线软启动与反接保护分开处理

- **日期**：2026-09-09
- **决策人**：Claude 提出，待用户确认
- **背景**：P-MOS 的体二极管方向是 D→S，导致：
  - **反接保护**接法（D 接电源、S 接负载）→ 正常时体二极管正向导通 → **拦不住上电冲击**
  - **软启动**接法（S 接电源、D 接负载）→ 正常时体二极管反偏能阻断 → 但**反接时体二极管导通**
  - 两个功能不能共用一只 MOS，全做要两只反向串联，成本翻倍
- **决定**（折中）：
  | 措施 | 器件 |
  |---|---|
  | Q1 只做软启动 | P-MOS（S→+36V_RAW，D→+36V_AMP），栅极 RC τ≈1s |
  | 反接靠 crowbar | D2 反并联肖特基（K→+36V_RAW，A→PGND），反接时导通烧断 F1 |
  | 一次防呆 | J1 用极性防呆连接器 |
- **前提**：电池侧已有 F_BAT 与 DC 断路器，DRS 到板子是固定线束，装配时接反概率可控。
