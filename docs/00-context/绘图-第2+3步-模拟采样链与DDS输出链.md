## 2.2b 🔴 **哪几只真的需要紧公差 —— 别买错也别多花钱**

| 位号 | 容值 | **公差要求** | 为什么 |
|---|---|---|---|
| `C54` `C55` | 10 nF | 🔴 **C0G，两只之间 ≤2%** | 直接变相位误差，见下表 |
| `C56`~`C59` | 1 nF | **C0G ±10% 就够** | 只占半电路 21 nF 里的 1 nF；<br>两通道差 20%（0.2 nF）= f_c 差 0.95% → **0.071°** ✅ |
| `C62` `C63` | 4.7 / 2.2 nF | **±10% 就够**（见 §3.2b） | 重构滤波在**激励链**上，不在测量链上 |

**`C54`/`C55` 的失配 → 相位误差**（f_c = 75.8 kHz，dφ/df_c = 1.711e−6 rad/Hz）：

| 两只 10 nF 的失配 | 半电路 C 差 | f_c 差 | **相位误差** |
|---|---|---|---|
| 5% | 4.76% | 3.61 kHz | **0.354°** ❌ |
| 3% | 2.86% | 2.17 kHz | 0.212° 🟡 |
| **2%** | 1.90% | 1.44 kHz | **0.141°** ✅ |
| 1% | 0.95% | 0.72 kHz | 0.071° ✅✅ |

### 🟡 如果 **10 nF C0G ±2%** 也买不到（很可能）

C0G 的容量密度低，10 nF 在 0603 已经接近极限，±2%（G 档）更难找。**两条退路：**

1. **用 0805 C0G ±5%，然后配对挑选** —— 买 10 只，用电容表挑**读数最接近的两只**做 `C54`/`C55`。
   同一盘 ±5% 料的实际分布很窄，挑完失配通常 <1% ✅ **这是最省事的办法**。
2. 实在只有 ±10%：也照样挑选配对。**要的是"两只一样"，不是"两只都准"** ——
   绝对值偏 10% 只是 f_c 变成 68~84 kHz，对测量毫无影响。

> 🔴 **绝对不能做的**：用 X7R。X7R 的直流偏压系数和温度系数会让两只在**工作状态下**
> 分道扬镳，挑选也救不回来。

### 🔴 选型的关键不是截止频率，是**两组的一致性**

相位是 V 和 I **相减**得到的 → 滤波器的**绝对**相移不影响结果，**失配才影响**：

**四条要求：**
1. 电容 **C0G ±2%**，🔴 **不能 X7R**（直流偏压系数让两只不一样）
2. 4 只电阻 **同批次 ±1% 薄膜**
3. 🔴 **布局镜像**：两组 RC 的走线长度、过孔数、离地平面距离尽量一致
4. 残余误差用**纯电阻负载**做一次软件校准（接已知无感电阻，测到的相位就是系统误差，存 FRAM）

> **抗混叠够不够？** 采样率 = 125 × f，最慢 2 kHz 时 250 kSPS，Nyquist 125 kHz。
> 75.8 kHz 一阶在 125 kHz 只衰减 −4.6 dB —— 看着不够。
> 🆕 **AMC 的带宽已从手册核实**：`AMC3301` **290~334 kHz**、`AMC3330` **300~375 kHz**，
> 它们自己先滚降一道。两级串起来在 125 kHz 约 −5.4 dB。
> 真正兜底的是：**高频那里只有 AMC 的本底噪声，没有相干信号** ——
> 混叠进来的是非相干噪声，相干 DFT 在基波处取值时会把它平均掉，不产生偏差。

## 2.3 ADC 配置（给软件，画图时只要确认脚位）

```
ADC1 规则组（差分 ch6）: PC0(IN6,+) / PC1(IN7,−)  ← 电压 AMC3330
ADC2 规则组（差分 ch3）: PA6(IN3,+) / PA7(IN4,−)  ← 电流 AMC3301
      ↑ 两者跑【规则通道双重同步模式】，同一触发、同时采保，采样时差 = 0

ADC1 注入组（4 通道，10 Hz）:
   IN8 = PC2  V_BUS_SENSE     IN9 = PC3  NTC1
   IN1 = PA0  NTC2            IN2 = PA1  NTC3
```
🔴 **相位为什么必须同步采样**：10 kHz 下差 0.25 µs 就是 **0.9°**。

### 计算

```
f_c = 1/(2π·R·√(C62·C63)) = 1/(2π·2000·√(4.7n × 2.2n)) = 24.74 kHz
Q   = ½·√(C62/C63) = ½·√(4.7/2.2) = 0.731            （≈ 巴特沃斯 0.707）

10 kHz 处：u = 10/24.74 = 0.404
|H| = 1/√((1−u²)² + (u/Q)²) = 0.9972  →  −0.02 dB       ✅ 基本不衰减
 2 kHz 处：+0.003 dB                                     ✅ 带内平坦

镜像抑制（最坏工况 2 kHz，更新率 125×2k = 250 kSPS，首镜像 248 kHz）：
   二阶 LPF  (248/24.74)² = 100.5×   →  −40.0 dB
   零阶保持 sinc(248/250) = 0.00806  →  −41.9 dB
   合计                                 −81.9 dB          ✅

10 kHz 工况（1.25 MSPS，首镜像 1.24 MHz）余量更大 ✅
```

> **滤波器 10 kHz 处的 −33.5° 相移完全不影响测量** ——
> V/I/相位都是在**变压器输出端**量的，激励链上的任何相移都被闭环外掉了。

## 3.2b 🆕 `C62` 4.7 nF 买不到紧公差怎么办 —— **±10% 完全可以**

用户反馈：**4.7 nF 只在 1206 有紧公差，其它封装都是 ±10%。**

### 结论：**±10% 直接用，不用为它上 1206。**

重构滤波在**激励链**上，不在测量链上 —— 它的 f_c 和 Q 偏一点，
只是让功放拿到的驱动幅度差零点几 dB，而**实际输出的 V 和 I 是在变压器输出端量的**。

**最坏情况算一遍**（`C62` `C63` 都取 ±10%）：

| 项 | 标称 | 最坏范围 | 影响 |
|---|---|---|---|
| `f_c` | 24.74 kHz | **22.5 ~ 27.5 kHz** | — |
| `Q` | 0.731 | **0.661 ~ 0.808** | 最坏在 12 kHz 处凸起 **+0.25 dB** |
| 10 kHz 处响应 | −0.02 dB | **−0.1 ~ +0.22 dB** | ✅ 无所谓，幅度由软件和音量电位器定 |
| 镜像抑制（2 kHz 工况，248 kHz） | −81.9 dB | 最坏 **−80.1 dB** | ✅ 仍然极好 |

**一句话：这一级没有精度要求。**

### 🟢 但有个更漂亮的替代 —— 想要 C0G ±5% 且只买一个料号

**`C62` 用两只 2.2 nF 并联（= 4.4 nF），`C63` 一只 2.2 nF，`R39`/`R40` 保持 2.0 kΩ。**

```
C62(4.4nF) / C63(2.2nF) = 2.000 → Q = ½√2 = 0.7071   ← 正好是巴特沃斯 ✅
f_c = 1/(2π × 2.0 kΩ × √(4.4n × 2.2n)) = 25.6 kHz
10 kHz 处 −0.10 dB ✅       248 kHz 镜像：LPF −39.5 dB + ZOH sinc −41.9 dB = −81.4 dB ✅
```

| 好处 | 说明 |
|---|---|
| **Q 正好 0.7071** | 比 4.7/2.2 的 0.731 还准 |
| **三只电容同一个料号** | `2.2 nF C0G ±5% 0603` 是货架常备品，好买、好备料 |
| 代价 | 多一个焊盘（新位号 **`C67`**），布局多占 1.6×0.8 mm |

> **两个方案都对，随你选**：
> 图省事 → `C62` = 4.7 nF **±10%**（什么封装都行）
> 图整齐 → `C62` = `2.2 nF ∥ 2.2 nF`（位号 `C62` + **`C67`**），Q 正好 0.707

### 幅度

```
DAC 满量程 = VREF+ = 2.9 V；带输出缓冲时实际可用 0.2 ~ 2.7 V
建议软件只用 0.29 ~ 2.61 V（10%~90%）→ 2.32 Vpp → 交流耦合后 ±1.16 V = 0.82 Vrms
```
功放模块的最终增益由它自己的音量电位器定（待决 #21）。

## 3.3 `CN5`（`J_AMP`）—— 🔴 **只能送一根地线**

```
CN5  6P 2.54 排针 / 牛角（只用 3 根，另外 3 根 NC 留给将来的 OTW/FAULT）

 1  AMP_GND      ┐
 2  DDS_OUT      ├─ 信号在两根地中间
 3  AMP_GND      ┘
 4  AMP_ENABLE
 5  NC   （预留 CLIP_OTW，ADR-017 已取消）
 6  NC   （预留 FAULT）

AMP_GND ──[ R45 10Ω 0805 ]── AGND          🔴 关键的一只电阻，见下
```

### 🔴 为什么只能送一根地、而且要串 10 Ω

功放模块**内部的信号地和电源地是同一个节点**。
如果 `CN5` 既送 `AGND` 又送 `DGND`，这两个地就在模块里被短接了，
**等于把 `R13` 那只 0Ω 桥旁路掉** —— 星型接地当场作废。

而且，就算只送一根地，它和电源线（`U26`）**都连到模块的同一个地**，
两根线并联成一个回路，功放的 1.74 A 回流会按电阻比分流：

```
电源线 18AWG 0.5 m 往返 ≈ 10 mΩ
信号地 24AWG 0.5 m 往返 ≈ 42 mΩ
不串电阻：信号地会分走 10/(10+42) = 19% × 1.74 A = 330 mA   🔴 全灌进 AGND
串 10 Ω ：信号地只分走 10m/(10m+10.042) = 0.1% = 1.7 mA      ✅
```

**对信号的影响**：模块输入阻抗按 10 kΩ 算，信号电流 0.25 mA 峰，
在 10 Ω 上只压降 **2.5 mV = 0.1%** ✅ 而且模块有增益电位器，无所谓。

> 🟡 **剩下的那点地偏移（功放回流在电源线上的 17 mV）落在 2f 上** ——
> ADR-013 已经分析过：BTL 供电电流 ∝ sin²，偏移落在 **2 倍频**，
> 相干 DFT 在**基波**处取值，天然抑制 ✅ 不用差分驱动。

2. **输入共模明确写了含双轨** —— Sallen-Key 的 `+IN` 跟着信号摆 0.2~2.7 V，这条必须硬保证。

**引脚和本文 §3.2 画的完全一致** ✅：`1`=OUTA `2`=−INA `3`=+INA `4`=−VS `5`=+INB `6`=−INB `7`=OUTB `8`=+VS

> ⚠️ **三份都不是原厂手册**（tokmas / 华轩阳 HXY / 一份正文与订货料号对不上的）。
> 料号相同 ≠ 参数相同，**拿到实物建议实测 GBW 和输出摆幅**。

### 🟡 一个软件上的小注意：RRI 的输入过渡点在 `V+ − 1.4 V ≈ 1.9 V`

DAC 输出 0.2~2.7 V **每周期都穿过它**，过渡处 `V_OS` 会跳一小步 → 一点失真。
**量级**：按 CMRR 96 dB 折算，`V_OS` 变化约 40 µV，相对 2.5 Vpp 是 **−96 dB** ✅ 可忽略；
而且**激励链上的失真会被输出端的 V/I 采样如实测到，不是误差**。

🟡 **想彻底躲开，零成本**：软件把 DAC 限制在 **0.2 ~ 1.8 V**（1.6 Vpp），
全程待在 1.9 V 以下只用一个输入对。代价是驱动从 0.82 Vrms 降到 0.57 Vrms ——
功放模块的音量电位器补得回来。**只是一个软件常数，不改硬件。**

> 📊 `3V3_AVDD` 负载：AMC 81 mA + VDDA 10 mA + `U27` 双通道 max 1.9 mA = **≈93 mA**。
> `TPS73633` 压差损耗 (5−3.3)×93 mA = **158 mW**，SOT-23-5 约 200 °C/W → 温升 32 °C ✅
