```

镜像抑制（2 kHz 工况，248 kHz）：LPF −39.5 dB + ZOH sinc −41.9 dB = −81.4 dB ✅
```

**三只电容同一个料号（2.2 nF 0603）** ✅ 正是建议的方案。

## 二、🔴 必改

### P-57 🔴🔴 `R44` 是 **2.2 kΩ 上拉到 3V3**，不是 10 kΩ 下拉到 DGND

```
'PD2'      ; R44.2 R45.1 U1.55
3V3        ; ... R44.1 ...            ← R44 2.2kΩ 拉到 3.3 V
'AMP_ENABLE'; CN5.3 R45.2
```

🔴 **失效安全方向反了**：
STM32 复位后 `PD2` 是**输入浮空（高阻）** → 被 2.2 kΩ 拉到 **3.3 V** →
`AMP_ENABLE` = 高 → **功放被使能**。

MCU 复位、看门狗咬、程序跑飞，功率级都是"默认开"。

### 这是我文档里写的方案①，但**方案①还没拍板，而且前提没到位**

我在 `绘图-第2+3步…` §3.3 里写过：

> ⚠️ 选方案①（开漏线与）则 `R43` 换成 2.2 kΩ **上拉**。

所以你按方案①画是有依据的。**但方案①成立有两个前提，现在一个都没满足：**

1. **`PD2` 必须配成开漏输出**（软件层面）—— 推挽的话它会和 AMC 的开漏 OUT 打架
2. 🔴 **第 5 步的两片 `AMC23C12` 的 `OUT` 必须挂到这个节点上** ——
   现在这个节点上只有 `PD2` 和一只上拉，**保护链一根线都没接进来**，
   等于只保留了方案①的缺点（复位默认使能），一点好处都没拿到

### 两条路，选一条

| | 做法 | 结果 |
|---|---|---|
| **A. 最小版（推荐现在就改）** | `R44` 改成 **10 kΩ，接 `DGND`**（下拉） | 复位时 `PD2` 高阻 → 被拉低 → **功放禁止** ✅<br>第 5 步选方案②（与门）时这只下拉原样保留 |
| **B. 坚持方案①（线与）** | `R44` 保持 2.2 kΩ 上拉，**但必须同时**：<br>① 软件把 `PD2` 配成开漏<br>② 第 5 步把两片 `AMC23C12` 的 `OUT` 接到 `AMP_ENABLE` 节点上 | 在第 5 步画完之前，**功放复位默认是开的** 🔴 |

**建议走 A。** 第 5 步真要选方案①时改一只电阻的事，而现在留着 B 就是留一个隐患。
→ **待决 #34 顺便在这里拍板：选 A（方案②/最小版）还是 B（方案①）。**

### P-58 🔴 `U27` 的 B 通道（`5`/`6`/`7` 脚）**完全悬空**

网表里 `U27` 只出现了 `.1 .2 .3 .4 .8`，**`U27.5`、`U27.6`、`U27.7` 一个网络都没进**。

运放的输入悬空会让那一路输出乱摆甚至自激，**串扰到 A 通道**，还白耗电流。

```
U27.5 (+IN_B) ──── AGND
U27.6 (−IN_B) ──┬─ U27.7 (OUT_B)          ← 接成跟随器
U27.7 (OUT_B) ──┘   （可留一个测试点，也可什么都不接）
```
`HMCP6022` 的输入共模含地 ✅，`+IN_B` 直接接 `AGND` 完全合法。

### P-59 🔴 `SHIELD` 只有 `CN4.1` 一个引脚 —— 屏蔽层没落地

```
'SHIELD' ; CN4.1          ← 整个网络就这一个引脚
```
我原来给的 `R38 0Ω → AGND` 没画（`R38` 这个位号被 Sallen-Key 的 2 kΩ 用掉了）。
**屏蔽层现在是悬空的，等于白留了一个脚。**

```
CN4.1 (SHIELD) ──[ R46 0Ω 0805 ]── AGND        ← 新位号 R46
```
> 为什么要串 0Ω 而不是直接连：将来万一发现屏蔽层引噪声进来，
> 拆掉这只电阻就能把它浮起来试，不用飞线。

## 三、🟡 建议

### P-60 🟡 `R40` 和 `R41` 两只 100 Ω 串成了 200 Ω

```
'OUT_A'  ; ... R40.2 ...
'$1N235' ; R40.1 R41.1
'$1N236' ; C65.1 R41.2
```
我原本只要**一只** 100 Ω（防线缆电容让运放自激 / 防短路）。

**200 Ω 的影响**：

| 功放模块输入阻抗 | 分压损失 |
|---|---|
| 10 kΩ（常见） | −0.17 dB ✅ 无所谓 |
| 600 Ω（低阻输入） | **−2.5 dB** 🟡 白掉一半驱动电压 |

模块有音量电位器，补得回来，**但没必要白掉**。
→ **建议把 `R40` 改成 0 Ω，或者直接删掉一只。**

### 🟡 BOM 上要把抗混叠电容单独拎出来

```
C0603 ! 10nF ; C5 C10 C44 C51 C52 C56 C57
```
`C56`/`C57` 现在和 `C5`/`C10`（LDO 的 NR 电容）、`C44`（光耦旁路）、
`C51`/`C52`（编码器滤波）**混在同一个 10 nF 组里**。

🔴 **`C56`/`C57` 必须是 C0G，而且两只之间 ≤2%**（买 ±5% C0G 挑选配对即可）；
另外五只用普通 X7R 就行。**出 BOM 时一定要分成两行，别让采购按一个料号买全部。**

同理 `C58`~`C61`（1 nF）也要 **C0G**（±10% 就够）—— 它们自己一组 ✅ 没混。
