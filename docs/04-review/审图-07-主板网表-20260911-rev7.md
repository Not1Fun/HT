## 🟡 P-16 · 三只 0Ω 并联桥接 `GND` ↔ `DGND` —— 一只就够，而且位置有要求

```
GND  ; **R16.2 R20.2 R21.2** U4.1 U7.1 U14.1 U16.1 U19.1 U20.1 U23.1 U25.1 U26.1
DGND ; … **R16.1 R20.1 R21.1** …
```

### 桥上其实几乎没有电流

| 电源 | 来源 | 回流走哪 |
|---|---|---|
| 12 V | DDR-30L-12（**隔离** DC/DC） | `U19.1` → `GND`，回 DDR-30L-12 自己的输出负端 |
| 5 V | DDR-30L-5（**隔离** DC/DC） | `U18.1` → `DGND`，回 DDR-30L-5 自己的输出负端 |
| 36 V | DRS | `U20.1` → `GND`，回 DRS |

**三个电源各自闭环，谁的回流都不经过这座桥。**
桥上只有共模/漏电/静电泄放电流，**一只 0805 0Ω 绰绰有余**。

### 三只并联的真正问题：违反单点星型接地

ADR-004 要求 `GND` / `DGND` / `AGND` **只在一个点汇合**。
三只 0Ω 如果在板上**分散放置**，就是三个连接点 → 围成地环路 →
36 V 母线上 1.97 A（功放峰值 3.34 A）的回流会有一部分抄近路穿过逻辑区。

**两种改法，选一种：**

| 方案 | 做法 |
|---|---|
| **A（推荐）** | **只留 `R20` 一只**，删掉 `R16` / `R21` |
| B | 三只都留，但**必须紧挨着并排放在同一个星点位置**（等效一个点），<br>BOM 里注明「必须相邻放置，不可分散」 |

不管哪种，这个星点都要放在 **36 V 进线端子附近**（大电流回流的源头），
不要放在板中央。

> 顺带：`R16` 这个位号在 rev6 里是 WDI 的串联 0Ω，rev7 改作地桥了。
> **位号复用容易在下一轮审图时误判，建议给地桥换个新位号**（比如 `R22`）。

## 🔴 P-17 · FRAM（U10）有四个脚没接

```
U10.4 = VSS  → DGND  ✅
U10.5 = SDA  → MCU_SDA3  ✅
U10.6 = SCL  → MCU_SCL3  ✅
U10.8 = VDD  → 3V3 + C31 100nF  ✅

U10.1 / U10.2 / U10.3 = A0 / A1 / A2   ← 未接
U10.7 = WP                              ← 未接
```

### 后果

- **A0/A1/A2 悬空** → I²C 从机地址随机 → **时好时坏，最难查的那类故障**
- **WP 悬空** → 写保护状态不确定；如果内部没有下拉，可能**整片只读**，
  故障记录和累计运行时长全写不进去

### 接法

| 脚 | 接到 | 说明 |
|---|---|---|
| 1 / 2 / 3 (A0/A1/A2) | **全部 `DGND`** | 只有一片，取基地址 |
| 7 (WP) | **`DGND`**（允许写） | 或接一路空闲 GPIO 做软件写保护 |

> ⚠️ **FM24V10 的手册不在 `reference/` 里**，上面按 24Cxx 系列的通用引脚定义给的。
> **基地址是 0x50 还是别的、WP 内部有没有下拉、A2 在 1 Mbit 器件上是不是被页地址占用**
> —— 全部标「待核实」。**把 FM24V10 手册放进来我核一遍。**
>
> 特别提醒：**1 Mbit 的 FRAM 通常要占用两个 I²C 地址（高位地址位借用 A2）**，
> 这时 A2 脚的接法和地址算法都不一样。这条必须查手册，不能猜。

### 顺带：I²C 总线电容复核

现在挂了 MCU + TCA9539 + FRAM 共 3 个器件 6 个引脚。
估算 Cb ≈ 50 pF（保守）不变 → **R17 / R18 = 4.7 kΩ @100 kHz 仍然正确** ✅

## 🟡 P-18 · `DSRX` / `DSTX` 是外接线束，建议加保护

屏是机箱内另一个部件，这两根线要走线束。当前是裸接。

**建议（留位即可，不装也行）：**

```
MCU PC10 ──[ 33Ω ]──┬── DSRX → 屏
                    └── TVS/ESD 阵列 → DGND
MCU PC11 ──[ 33Ω ]──┬── DSTX ← 屏
                    └── TVS/ESD 阵列 → DGND
```

- 33Ω 串阻：抑制线束反射和辐射（屏的波特率通常 115200~921600）
- ESD：DRS 的抗扰度是 ESD Lv3 (8 kV air)，**我们自己的对外接口也该有同等能力**

## 🆕 P-19 · 看完 DRS 官方规格书后，新增两条要画的东西

详见 `docs/01-power/DRS-240-36-规格核对与接线定义.md`。

### ① 给 DRS 的 MODBus 预留 `USART2` + RS-485 收发器位置

DRS-240 **内置 MODBus**（后缀空白型号），RJ45 通信口。
它能给出**电池实时电压、充电电流、充电阶段**——
而四路干接点里的 `BAT_OK` 对 LiFePO₄ **只有约 3 分钟预警**，基本没用。

| 项 | 值 |
|---|---|
| MCU 串口 | **USART2 = PA2 (pin 14) / PA3 (pin 17)，AF7** —— 已核实，当前空闲 ✅ |
| 收发器 | SP3485 / MAX3485 一类 + 120Ω 终端（留位不焊也行） |
| 隔离 | **大概率不需要**（DRS 的 `BAT−` 与 `−V` 几乎肯定共地，见该文档第九节，一表即知） |
| 物理层 | ⚠️ RS-485 还是 TTL **待核实** —— 要 MEAN WELL 的通信协议手册 |

**本版至少把 PA2/PA3 引到一个排针或留出收发器焊盘**，别把脚占掉。

### ② 四路光耦接哪一对触点，现在有官方答案了

全部接**「正常时闭合」**的那一对：

| 光耦 | 网络 | MCU | **DRS 端子** |
|---|---|---|---|
| U2 | `AC_OK` | PB11 (33) | **2 – 3** |
| U3 | `DC_OK` | PB12 (34) | **5 – 6** |
| U5 | `BAT_OK` | PB13 (35) | **8 – 9** |
| U15 | `CHARGE_OK` | PB14 (36) | **11 – 12** |

这样「闭合 = 正常 = MCU 读低」，与 SH1 标注一致 ✅。
**这是接线定义，不改原理图**，但要写进机箱接线文档。
