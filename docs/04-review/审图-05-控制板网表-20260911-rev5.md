## ⚠️ P-05 · 1N4148 的**位置**对了，**方向**从网表看不出来

现在四只二极管都并在自己那只光耦的 LED 两端了 ✅：

| 光耦 | 阳极侧（接 3.3 kΩ 那端） | 阴极侧（接干接点那端） | 二极管 |
|---|---|---|---|
| U2  | `$2N52` | `$2N77` | D3：`.1`→阳极侧，`.2`→阴极侧 |
| U3  | `$2N70` | `$2N72` | D1：同上 |
| U5  | `$2N78` | `$2N40` | D4：同上 |
| U15 | `$2N75` | `$2N76` | D2：同上 |

四只的接法完全一致（`.1` 全在阳极侧），这很好 —— 要么四只全对，要么四只全错。

**但网表只给脚号不给极性，所以从网表判断不了方向。**
按要求，**二极管的阴极（K）必须接在阳极侧网络**（`$2N52 / $2N70 / $2N75 / $2N78`），
也就是接 3.3 kΩ 那一端。所以：

- 若 `D*.1` = **阴极** → ✅ 对
- 若 `D*.1` = **阳极** → ❌ 二极管和 LED **同向并联**，常通 **(12−0.7)/3.3k = 3.42 mA**，
  把 LED 旁路掉 → **四路光耦永远不亮**

### 怎么查（三选一，一分钟）

1. **看原理图符号**：二极管三角形所指的那条横杠就是阴极。
   **要求：二极管的三角形方向必须和光耦 LED 的三角形方向相反**（头对脚）。
2. **点开符号看引脚名**：立创的二极管符号引脚一般标 `A` / `K`（或 `C`）。
3. **上板后实测**：12 V 上电、干接点全断开时，量 R9–R12 上的压降。
   正常应接近 12 V（LED 不通、无电流）；若量到 ≈11.3 V（3.42 mA），就是接反了。

接反不会烧东西（3.42 mA 对 1N4148 无压力），只是四路状态全部读不到。

> 建议顺手加：每路 LED 两端再并 **100 nF 0603**（和二极管同位置）抑制线束尖峰。
> 时间常数 3.3 kΩ × 100 nF = 330 µs，对秒级变化的状态信号无影响。**本轮仍未加。**

## 🔴 P-06 · SWD 排针只有 4 脚，**漏了 NRST**

```
H1 = HDR-TH_4P：  H1.1 SWCLK   H1.2 SWDIO   H1.3 3V3   H1.4 DGND
NRST ; C26.1 R14.1 U1.7      ← 没有引到 H1
```

**必须改成 5P，把 `NRST` 引出来。** 原因是这块板上有看门狗：

- `TPS3823A-33` 的复位周期是 **1.6 s**（`WDI ; U1.62 U21.4`）。
  调试时 MCU 停在断点上不喂狗 → **1.6 s 后强制复位**，调试器连接被打断
- 调试器需要 **connect under reset** 才能在这种板子上稳定连上，
  没有 NRST 就只能靠「上电瞬间抢连接」，很难用
- 芯片 BOOT0 误配置 / 软件把 SWD 脚改成普通 IO 时，**NRST 是唯一的救命线**

> 另外提醒：`WDI` 那条线上要留 **跳线/0Ω**，调试时断开让 WDI 悬空（芯片内部自激、不复位）。
> 见 MCU 文档 §5.4b。rev5 里 `WDI ; U1.62 U21.4` 是硬连的。

## 🟡 P-07 · `SCL3` / `SDA3` 是孤立网络，**缺上拉电阻**

```
SCL3 ; U1.40        ← PC8，I2C3_SCL（datasheet Table 13：AF8）✅ 复用正确
SDA3 ; U1.41        ← PC9，I2C3_SDA（AF8）✅
```

引脚选对了（已按 `reference/STM32G474RET6-DataSheet.pdf` Table 13 核实，
与需求文档 Visio 上写的 PC8/PC9 一致）。**但是：**

1. **两条都只有一个节点** —— `U8` (TCA9535) 和 `U9` (FRAM) 还没连上去
2. **没有上拉电阻**。I²C 是开漏，没有上拉整条总线不会工作

### 上拉取值

```
Rp_min = (VDD − VOL) / IOL = (3.3 − 0.4) / 3 mA = 967 Ω
Rp_max = t_r / (0.8473 × Cb)
```

总线电容 Cb 估算：MCU 2 脚 + TCA9535 2 脚 + FRAM 2 脚 + 走线 ≈ **50 pF**（保守取）

| 速率 | t_r 上限 | Rp_max | **取值** |
|---|---|---|---|
| 100 kHz | 1000 ns | 23.6 kΩ | **4.7 kΩ** ✅ 推荐 |
| 400 kHz | 300 ns | 7.08 kΩ | 2.2 kΩ |

**建议 4.7 kΩ ×2 上拉到 `3V3`，速率跑 100 kHz。**
FRAM 的写入量很小（累计运行时长、故障记录），不需要 400 kHz。

> ⚠️ `FM24V10` 的手册不在 `reference/` 里。**WP 引脚怎么接、A0/A1/A2 地址脚怎么配**

## 🔴 P-08 · 继电器已拍板移到 RLY-01，但网表里还在（ADR-012）

你已经定了「移到继电器板」，但 rev5 里还留着：

```
RELAY-TH_G2RL-2 ; K1
RELAY-TH_G5RL-1A ; K2 K3 K4 K5 K6 K7 K8
SOP-18_… ; U10                      ← ULN2803
GND ; … U10.9 …
```

**要删掉 `U10` 和 `K1–K8`**，换成两个连接器：

| 位号 | 规格 | 用途 |
|---|---|---|
| `J11` | 2P 5.08mm 螺钉端子 | 12 V → RLY-01，**串 T1A 熔断器（不能用 PTC）** |
| `J12` | 10P IDC（或 2×5 排针） | 8 路 3.3 V 逻辑 + 2 根 DGND 回线 |

`U8` (TCA9535) **留在控制板**：它的 P10–P17 是本板的输入信号，搬不走。
P00–P07 八路输出改成接 `J12`，驱动器 TBD62083A 放 RLY-01。

> 🔴 **连带升级为必做**：`TCA9535 → TCA9539`。
> 继电器在板外之后，控制板被看门狗复位时，RLY-01 上的输出寄存器**不会**跟着复位，
> 7 档抽头和 K_TRANS 会停在故障前状态。TCA9539 有 RESET 脚，接 MCU `NRST`。
> （原评审 P0-5 / 待决 #4，现在从「建议」变成「必须」。）
