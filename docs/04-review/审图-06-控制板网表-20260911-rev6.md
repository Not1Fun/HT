## 🔴 P-09 · TCA9539 有 4 个脚没接，而且 3 脚千万别当 A2

`U24.1 (/INT)`、`U24.2 (A1)`、`U24.3 (/RESET)`、`U24.21 (A0)` 全部悬空。

**最要命的一条**：TCA9535 的 3 脚是 `A2`（接地是正常做法），
**TCA9539 的 3 脚是 `/RESET`（接地 = 芯片被永久按在复位里，完全不工作）**。
如果符号是从 TCA9535 改过来的，很容易顺手接地。

另外 **7 位从机地址也变了：TCA9535 是 0x20–0x27，TCA9539 是 0x74–0x77**，软件要跟着改。

**接法、理由和电气核对见 `docs/02-digital/TCA9539-引脚分配与接法.md`**，结论：

| 脚 | 接到 |
|---|---|
| 1 `/INT` | **PC6 (pin 38)** + 10 kΩ 上拉到 `3V3`；EXTI6 上无冲突 |
| 2 `A1` | `DGND` |
| 3 `/RESET` | **`NRST`** —— 这是当初换 9539 的唯一理由 |
| 21 `A0` | `DGND` |

> 复位后 16 路 IO 全回到高阻输入 → RLY-01 上驱动器输入靠 10 kΩ 下拉被拉低 →
> 继电器全释放。**这条失效安全链要求 RLY-01 每路输入都有 10 kΩ 下拉，必做。**

## 🔴 P-11 · TCA9539 的 16 路 IO 全是孤立网络

```
'K_TRANS' ; U24.4          'CC / VA' ; U24.13
'TAP 1Ω'  ; U24.5          '2kHz'    ; U24.14
… 共 8 路输出，全部只有 U24 一个节点    … 共 8 路输入，同样只有一个节点
```

- **8 路输出**（K_TRANS + 7 档抽头）要接到 **`J12`**（10P IDC → RLY-01）。
  驱动器 TBD62083A 在 RLY-01 上，本板只出 3.3 V 逻辑电平
- **8 路输入**（CC/VA、4 个频率键、Encoder ENTER、SYSTEM ENABLE、Door interlock）
  要接到面板按键 / 编码器 / 门开关
  - ⚠️ TCA9539 **内部没有上拉**（这点和 PCA9555 不同），
    每路输入按键都要**外部 10 kΩ 上拉到 3V3**，按键接地
  - ⚠️ `Door interlock monitor` 只是监视，**门开关必须同时硬串进继电器线圈回路**
    （首轮评审 P0-2 / 待决 #5，画 RLY-01 前必须定）

## 🔴 P-12 · 36 V 段现在是四个端子直接并联，什么保护都没有

```
36V ; U20.2 U23.2 U25.2 U26.2
GND ; U4.1 U7.1 U14.1 U16.1 U19.1 U20.1 U23.1 U25.1 U26.1
```

U20 进、U23/U25/U26 出，**中间没有熔断、没有软启动、没有体电容、
没有 TVS、没有反接保护、没有 V_BUS_SENSE 分压** —— 现在这块板对 36 V 只是一块接线端子板。

既然确认是合并板（ADR-014），`器件选型与计算核对表.md` §3 那一整段就得画在本板上：

```
U20 (36V 进)
   │
  F0  T6.3A / ≥58VDC          ← 反接 crowbar 要有熔断器可烧，必须有
   │
   ├── D_CROWBAR 肖特基（K→36V_RAW，A→GND）    反接时导通烧断 F0
   ├── TVS SMCJ48A                             只吸收 ns–µs 浪涌，不是过压保护
   ├── V_BUS_SENSE 分压 2×100k / 10k = 21:1    43.2 V → 2.057 V（VREF+ 2.9V 下余量 29%）
   │
   ├── F2 T2A ─────────────────────→ U23  DDR-30L-12
   ├── F3 T2A ─────────────────────→ U25  DDR-30L-5
   └── F1 T5A ── Q1 P-MOS 软启动 ──┬─ 1000 µF/63V + 4×1µF/100V + 100nF
                                   └─→ U26  功放模块
```

要点：

| 项 | 值 / 说明 |
|---|---|
| **F0 主熔断** | **T6.3A / ≥58 VDC**（总电流 1.97 A，按 75% 降额 4.7 A，余量 2.4×）。<br>没有它，反接时 crowbar 肖特基会先于电池的 T15A 烧掉 |
| **F1 功放支路** | **T5A**（§3.2 原定 T10A 是按「没有软启动」选的，现已修订，见功放模块文档） |
| **Q1 软启动** | 只做软启动、不做反接（ADR-006）。栅极 R1 100k / DZ1 15V / CG 10µF / R2 10k，τ ≈ 1 s |
| **体电容** | **1×1000 µF/63V 就够** —— 功放模块自己有 2400 µF，且位置比板上更好 |
| **软启动重算** | C_total = 3400 µF → 充电 122 mA → MOS 最坏耗散 18V×122mA = **2.2 W / 1 s**，TO-220 SOA 覆盖 ✅ |
| **分压下臂接地** | ⚠️ 用**单独一根细走线直接回星点（开尔文）**，不要就近接在 36V 回流铜皮上。<br>1.97 A 在 2 mΩ 铜皮上就是 4 mV，乘 21 倍分压比 = 母线读数偏 84 mV |

> ⚠️ 另见 `docs/01-power/功放模块核对-晒邦TPA3255-600W.md`：
> **你选的这块模块标称 DC30–42 V，而母线均充时是 43.2 V，超了。买之前先看那份。**

## 🔴 P-13 · `GND` 和 `DGND` 在本板上没有任何连接 —— 合并之后星点就在本板上

```
GND  ; U4.1 U7.1 U14.1 U16.1 U19.1 U20.1 U23.1 U25.1 U26.1    ← 功率地
DGND ; …（一大堆）… R13.1 …                                     ← 逻辑地
AGND ; … R13.2 …                                               ← 模拟地，经 R13 (0Ω) 接 DGND
```

**两个地之间没有任何器件。**

### 情况变化说明（不是之前算错了）

审图 #02 的 F-02 写过「`GND` 与 `DGND` 在控制板上不连，**这是对的** ——
二者只在 PWR-01 星点汇合」。**那时候 PWR-01 是另一块板。
现在两块板合并了，那个星点就在本板上**，所以必须在本板显式连起来。

### 不连的后果

- `V_BUS_SENSE` 的分压是以 `GND` 为参考的，而 ADC 以 `AGND` 为参考 →
  **两个地浮着，母线电压根本没法测**
- 静电、共模干扰没有泄放路径
- 光耦两侧的电位差会漂到不确定的值（PC817 隔离耐压虽高，但不该让它浮着）

### 要做的

**在星点位置加一个显式的连接**：一只 `0Ω / 2010 封装`（或一段专门的铜桥），
位号建议 `R20`，网络 `GND` ↔ `DGND`。**整板 `GND`、`DGND`、`AGND` 三者只在这一个点汇合**：

```
         ┌── R13 (0Ω) ── AGND
DGND ────┤
         └── R20 (0Ω) ── GND ──→ 机壳 PE
```

布局时这个点要放在 **36 V 进线端子附近**（大电流回流的源头），
不要放在板中央 —— 否则功率回流会横穿逻辑区。

## 🟡 P-14 · BOOT0 电路：3P 选择器改成「固定下拉 + 临时上拉」

现状不插跳线帽 = BOOT0 悬空 = 启动模式不确定。既然现在要做串口下载，
更应该改成**默认安全**的接法：

```
BOOT0 ──┬──[ R15 10 kΩ ]── DGND          ← 焊死，默认正常启动
        └──[ R19  1 kΩ ]── H2(2P) ── 3V3  ← 要下载时才插跳线帽，此时 BOOT0 = 3.0 V
```

**上拉必须明显小于下拉**：两边都 10 kΩ 的话分压只有 1.65 V，正好压在阈值上。
详见 `docs/02-digital/串口打印与串口下载-USART1.md` §3。

## 🟡 P-15 · `R16` 建议从 0Ω 电阻改成 2P 排针

`R16` 的作用是**下载/调试时断开 WDI**，让 TPS3823 内部自激、不复位
（否则 1.6 s 超时会打断串口下载和 SWD 断点调试）。

**既然每次下载都要断开它，就不该是要动烙铁的 0805 电阻。**
换成 **2P 2.54 排针 + 跳线帽（位号 `H3`）**，丝印标「WDG · 拔下=禁用看门狗」，
跳线帽用**红色**，一眼能看出忘没忘插回去。
