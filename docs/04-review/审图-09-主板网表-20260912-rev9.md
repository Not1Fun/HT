## 🔴 P-20 · 齐纳 `D6` 串进了分压里 —— **栅极必炸**

```
rev9 实际连接：
  36V_RAW ──[ R26 220k ]── $2N102 ──[ D6 ]── $2N103 ──┬── Q1.1 (G)
                                                      └──[ R27 22k ]── GND
```

**`D6` 变成了和 `R26` 串联的一个器件，而不是并在 S-G 之间的钳位。**

### 后果：栅极完全没有钳位

| 母线 | 栅极电压 | **Vgs** | |
|---|---|---|---|
| 32.0 V | 2.85 V | **−29.2 V** | ❌ |
| **36.0 V** | 3.21 V | **−32.8 V** | ❌ |
| 43.2 V | 3.86 V | **−39.3 V** | ❌ |
| 55.9 V（DRS OVP 极限） | 5.02 V | **−50.9 V** | ❌ |

**MOSFET 栅极的绝对最大值是 ±20 V。一上电栅氧就击穿，Q1 直接报废。**

> 如果 `D6` 方向装反（反偏截止），栅极只被 R27 拉到 0 V → `Vgs = −Vbus`，**同样超限**。
> 两个方向都不行 —— 问题在拓扑，不在方向。

### 正确接法：齐纳**并联**在 S 与 G 之间

```
36V_RAW (S) ──┬──[ R26 220k ]──┬── G (Q1.1)
              │                │
              └──[ D6 齐纳 ]───┘        K → 36V_RAW    A → G
                               │
                          [ R27 22k ]
                               │
                              GND
```

**网表要变成：**

```
'36V_RAW'  ; … R26.1 **D6的阴极脚** …          ← 齐纳阴极也接 36V_RAW
'$2N103'   ; Q1.1 R26.2 R27.1 **D6的阳极脚**   ← R26 直接到栅极，齐纳阳极也在这里
（`$2N102` 这个网络消失）
```

### 齐纳选型核算（`DZ1 = 12 V / 500 mW`）

```
Iz = (Vbus − 12) / R27
```

| 母线 | Iz | Pz | Vgs |
|---|---|---|---|
| 32.0 V | 0.91 mA | 11 mW | **−12 V** |
| 36.0 V | 1.09 mA | 13 mW | **−12 V** |
| 43.2 V | 1.42 mA | 17 mW | **−12 V** |
| 55.9 V | 2.00 mA | 24 mW | **−12 V** |

- Iz 全程 ≥0.9 mA ✅ 齐纳工作在有定义的击穿区（低于 ~0.5 mA 时齐纳电压会变软）
- `Vgs = −12 V` 全母线范围恒定 ✅ 远低于 ±20 V 极限，也高于 IRF9540N 标 Rds(on) 用的 −10 V
- 封装 SOD-123 ✅ 合适；**500 mW 够用（最大才 24 mW）**

> ⚠️ **确认 `D6` 就是 12 V 齐纳**（网表里 Value 是 `{Value}` 占位符，看不出来）。
> 普通开关二极管放这里没有钳位作用。

## 🔴 P-21 · 米勒电容 `C33` 接错节点，而且选错了类型

```
rev9 实际：
  '36V_RAW' ; **C33.1** …          ← 源极 S
  36V       ; **C33.2** …          ← 漏极 D
  → C33 跨在 S 和 D 之间（直接并在 MOS 沟道两端）
```

### 错误 1：节点错 —— 必须接 **G→D**，不是 S→D

跨在 S-D 之间的电容**对软启动毫无作用**：
Q1 关断时它只是把输入的 dV/dt 耦合一点点到输出（3.3 µF / 3400 µF → 只抬 35 mV），
开通过程中它两端电压从 36 V 降到 0，但**不参与栅极电流平衡，控制不了 dVd/dt**。

**必须接到 `$2N103`（栅极）和 `36V`（漏极）之间。**

> 这正是上一轮 §3.5 更正的核心：电容必须在**栅-漏**之间形成米勒积分器，
> `dVd/dt = I_g / C_M`。接 S-D 或 S-G 都不起作用。

### 错误 2：用了**有极性的直插电解**，但 G-D 电压会换向

```
Q1 关断时：G ≈ S = 36 V，D = 0 V   →  V_GD = **+36 V**
Q1 导通后：G = S−12 = 24 V，D = 36 V →  V_GD = **−12 V**
```

**电压会换向 → 电解电容会被反压，鼓包/失效。**

### 错误 3：耐压不够

`CAP-TH_BD6.3-P2.50` 是 Φ6.3 mm 的小型径向电解，这个尺寸的 3.3 µF 通常只有
25~50 V 档。**关断时要扛 36 V，最坏 55.9 V（DRS OVP 上限）。**

### 正确选型

| 项 | 要求 |
|---|---|
| 容值 | **2.2 µF**（见下表取舍） |
| 耐压 | **≥100 V** |
| 类型 | **非极性**：盒式薄膜 MKT/MKP（引脚间距 15 mm 是常见规格） |
| 为什么不用 X7R 陶瓷 | X7R 的容值随直流偏压变化，而 **G-D 偏压在开通过程中要从 +36 V 扫到 −12 V** →<br>容值一路在变 → dV/dt 不恒定 → 浪涌波形不平坦。**薄膜没有这个问题** |

### 容值取舍（`I_g` 由 R26/R27 决定，C_load = 2400 µF 模块 + 板上体电容 1000 µF = 3400 µF）

| C_M | 浪涌 @36V | 斜坡 | Q1 峰值功率 @36V | @43.2V 浪涌 |
|---|---|---|---|---|
| 3.3 µF | 1.48 A | 83 ms | 27 W | 1.82 A |
| **2.2 µF ← 推荐** | **2.22 A** | **55 ms** | **40 W** | 2.73 A |
| 1.5 µF | 3.26 A | 38 ms | 59 W | 4.00 A |

**2.2 µF 是平衡点**：浪涌 2.2 A 对 F1（T5A，降额 3.75 A）和 DRS（6.6 A 能力，
减去稳态 1.97 A 还剩 4.6 A）都轻松；薄膜电容 2.2 µF/100 V 也是常规货。

> **开通总能耗恒定 = ½CV² = 2.2 J，与 C_M 无关**，全部耗在 Q1 上。
> C_M 只决定这 2.2 J 是"低功率拖长时间"还是"高功率短时间"。
>
> ⚠️ **Q1 的 SOA 必须对着手册曲线核**：`18 V / 2.2 A / 55 ms`（43.2 V 时 `21.6 V / 2.7 A / 54 ms`）。
> **待核实** —— IRF9540N 的 SOA 手册不在 `reference/` 里。

### SMD 替代（如果不想用直插薄膜）

**3 只 1 µF / 100 V X7R 1210 并联**。注意 36 V 偏压下 X7R 通常掉 30~40%，
实际约 1.9~2.1 µF，浪涌约 2.3~2.5 A —— 可以接受，但 dV/dt 不如薄膜平坦。

```
PC2 ; R29.1 R30.2 U1.10        ← 只有分压和 MCU，没有电容
```

|---|---|

## 🟡 P-24 · 三路输出全走 Q1，而且只有一只总熔断

```
'36V_RAWIN' ; F1.1 U23.2                     ← U23 现在是进线
'36V_RAW'   ; C33.1 D5.1 F1.2 Q1.3 R26.1 R28.2 U10.1
36V         ; C33.2 Q1.2 U20.2 U25.2 U26.2   ← U20/U25/U26 三路出线全在 Q1 之后
```

（顺带：进出线端子的角色和前几版对调了 —— `U23` 变进线、`U20` 变出线。记一下，不是错。）

### 问题 1：两路 DC/DC 也被软启动拖住

`DDR-30L-5` → 5 V → `TPS73633` → 3V3 → **MCU**。
Q1 慢开 55 ms，**MCU 要等 55 ms 之后才开始上电**。功能上没问题，但：

- 软启动斜坡到 18 V 时 DDR-30L 才脱离欠压、开始启动，**此时它的启动电流会叠加到浪涌上**
- 两路 DC/DC 的输入电容（µF 级）也算进 C_load

**建议：把两路 DC/DC 挪到 Q1 之前（接 `36V_RAW`），只让功放走 Q1。**
这样 MCU 立刻上电，浪涌计算也更干净 —— 这也是
`改板接法…§3.0` 原本画的拓扑。

### 问题 2：没有分支熔断

现在只有 `F1` 一只。任何一路线束短路都会烧掉总熔断，整机断电，且无法定位。

**建议按 §3.1 补齐：**

| 位号 | 规格 | 位置 | 实际电流 | 降额 75% | 余量 |
|---|---|---|---|---|---|
| **F0**（= 现在的 F1） | **T6.3A** | `U23` 进线处 | 1.96 A | 4.72 A | 2.4× |
| **F2** | **T2A** | → `DDR-30L-12` | 0.23 A | 1.50 A | 6.5× |
| **F3** | **T2A** | → `DDR-30L-5` | 0.07 A | 1.50 A | 22× |
| **F_AMP** | **T5A** | → Q1 → 功放 | 2.04 A | 3.75 A | 1.8× |

> 🔴 **`F1` 在网表里的 Value 还是 `{Value}`，没定值。**
> 四只都必须 **直流额定 ≥58 VDC、分断能力 ≥1500 A**（交流额定不能代用，直流没有过零点难灭弧）。
>
> ⚠️ 另外确认 `FUSE-TH_BD5.4-W22.5-P27.5-D0.8` 这个封装是**带座可更换**还是**直接焊死**。
> 主熔断器熔断后应该能换，不该拆板子动烙铁。

## 🟡 P-25 · `D5` / `U10` 两只 SMC —— 位号和选型要确认

```
'36V_RAW' ; … D5.1 … U10.1 …
GND       ; D5.2 … U10.2 …
```

两只封装都是 SMC、都接在 `36V_RAW` ↔ `GND`、**脚序也一样**，
从网表分不出哪只是 TVS、哪只是反接 crowbar。

| 器件 | 要求 |
|---|---|
| **TVS** | `SMCJ48A` 单向。**阴极 → `36V_RAW`，阳极 → `GND`**。<br>SMCJ43A 的 Vrwm 43 V < 母线最高 43.2 V，**正常工作就漏电发热，绝对不能用** |
| **crowbar 肖特基** | **阴极 → `36V_RAW`，阳极 → `GND`**（和 TVS 同向）。<br>按「扛 **9 A 持续 5 秒**」选：**SMC 里 ≥10 A 的档**，反向耐压 ≥60 V，**下面给足散热铜皮** |

> **为什么是"9 A 持续 5 秒"而不是"瞬间烧断熔断器"**：
> DRS 的输出有恒流限制（过载保护 105~135% → 约 8.9 A），**5 秒后 DRS 自己关断输出**。
> T6.3A 慢熔在 1.4 倍额定下未必 5 秒内熔断 —— **真正的兜底是 DRS 的 5 秒关断。**

### 位号问题

**`U10` 给了一只二极管。** `U` 前缀按惯例是 IC；而且 `U10` 在 rev8 里是 FRAM
（这一版已经改成 `U9` 了）。**建议改成 `D7`。**

> 这是第四次位号复用了（`R16`/`R19`/`R25`/`U10`）。
> **新器件请用没用过的位号**，不然每轮对比网表都要花时间分辨。

## 🔴 P-26 · USB ESD 仍然没加

```
'D+' ; U8.1 USB1.A6 USB1.B6        ← 连接器直接进芯片，中间什么都没有
'D-' ; U8.2 USB1.A7 USB1.B7
USB1 的 VBUS（A4/B4/A9/B9）仍然一个都不接
```

按 `改板接法…§2` 加：

```
USB-C A6/B6 ─┤I/O1├─→ CH340X pin1 (UD+)
USB-C A7/B7 ─┤I/O2├─→ CH340X pin2 (UD−)
             │VBUS├─ USB-C 的 A4/B4/A9/B9 ── 100 nF ── DGND
             │GND ├─ DGND（短粗线 + 过孔直下地平面）
```

🔴 **`VBUS` 脚必须接真实的正电源轨，不能悬空** —— USBLC6-2 是 rail-to-rail 拓扑，
每路 I/O 上有两只二极管（一只到 GND、一只到 VBUS）。**VBUS 悬空 = 正向 ESD 基本没防护。**

**把连接器的 VBUS 引出来只喂给 ESD 器件**（不接板上任何别处，不是给板子供电）——
这样 ESD 能量顺 USB 线缆的 VBUS/GND 原路走掉，不灌进板上 3V3（3V3 上挂着 MCU、基准、AMC 采样链）。
