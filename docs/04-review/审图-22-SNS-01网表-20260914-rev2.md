# 一、先回答问题：**能，而且比原方案好。**

## 1.1 我推荐的接法

```
                  ┌──────────────── SNS-01（高压区）────────────────┐
                  │                                                 │
变压器抽头 ───→ J4.1 ──────── HV+ 走线（7.07 A）──────── J3.1 ───→ 输出 + 端子
                  │             │            │                     │
                  │        [OV 分压链]   [测量分压链]               │
                  │        4×402k:1k     7×51k:806Ω                 │
                  │             └──────┬─────┘                      │
                  │                    ↓ 下臂都回 HV_GND            │
变压器 com  ───→ J4.2 ──┬─[ RS1 shunt 15 mΩ 四端 ]─┬── J3.2 ───→ 输出 − 端子
                  │      │                          │              │
                  │   取样脚                     取样脚            │
                  │  = HV_GND                  = SHUNT_L           │
                  └─────────────────────────────────────────────────┘
```

| | 原方案（J3 功率 2P + J4 取样 1P） | **新方案（J4 输入 2P + J3 输出 2P）** |
|---|---|---|
| 端子数 | 2 只（一只功率、一只取样） | 2 只（都是功率） |
| `HV+` 取样线 | 一根细线拉到板上 | **在板上从 7 A 走线直接取** |
| 🔴 **取样线断掉** | **电压测量和 OV 保护同时静默失效**（软件能靠"有电流无电压"发现，但硬件 OV 就是死的） | **不存在这个失效模式** —— 那根线断了就没有输出了 ✅ |
| 板上 7 A 走线 | 1 条 | **2 条** |
| 板面 / 发热 | 小 | 略大，多约 0.1 W |

**「取样线断了 = 硬件过压保护静默失效」这一条，值得多走一条 7 A 的铜。** 建议采纳。

## 1.2 但要跟着满足五条

| # | 要求 | 数 |
|---|---|---|
| 1 | 🔴 `J3`/`J4` **都要按功率端子选**：≥10 A、≥300 V、螺钉式 | 7.07 Arms；KF128/KF301-5.0 起步，**具体料号的额定电压/电流待核实** |
| 2 | 🔴 **两条 7.07 A 走线**，2 oz 下各 ≥5 mm（PCB 阶段我按 IPC-2152 算准确值） | 40 mm 长 5 mm 宽 2 oz ≈ 2 mΩ / 0.1 W / 压降 14 mV，**占 223.6 V 的 0.006%**，不影响测量 ✅ |
| 3 | 🔴 **分压链下臂必须回 `J4.2` 那一端（变压器侧）** | 待决 #59：否则 0.766 mA 分压电流被 shunt 当成负载电流，1000 Ω 档 **0.34%** |
| 4 | 🔴 **整个高压区（`HV+` 走线 + `HV_GND` 铜 + shunt + 两条分压链 + 四颗 IC 的高压侧）必须在隔离栅的同一侧**，栅下开槽、≥8 mm | 现在 `HV+` 横穿板子，隔离栅得是一条直线，四颗 IC 全部骑在上面 |
| 5 | 🟡 `HV+` 和 `HV_GND` 之间是**功能绝缘**（两者都是危险带电）；它们**对 `AGND`/`DGND`** 才是**加强绝缘** | 两类间距不一样，PCB 阶段分开算 |

## 1.3 🟡 GDT 要不要顺势搬到 SNS-01

既然两根线都上板了，差模 GDT 放 `J3` 旁边是很自然的，还能直接保护两条分压链。
**但我建议仍然放在输出端子/机箱侧** —— GDT 动作时是几百安培的浪涌，让它在 PCB 铜箔上跑不是好主意。
SNS-01 这边靠分压链本身限流（上臂 1206 额定 200 V，GDT 600 V 时每只 150 V ✅）。

# 二、🔴🔴 PCS-10W 手册到手 —— **它确实是四端开尔文，现在接法把开尔文废掉了**

手册「技术特点」第 4 条原文：**「四端连接」**。
尺寸图上也看得很清楚：**外侧两脚宽 1.5 mm、间距 17.78 mm（电流端）；内侧两脚宽 1.1 mm、间距 7.62 mm（取样端）**。

而 rev2 里：

```
'SHUNT +' ; R1.1 R2.1 R8.1 R12.1  RS1.1 RS1.2       ← 1、2 短接
GND1      ; ...                    RS1.3 RS1.4 ...   ← 3、4 短接
```

🔴🔴 **1+2、3+4 短接 = 把取样端和电流端并在一起 = 开尔文作废。**

后果（量化）：

```
shunt 本体 15 mΩ
7 A 通路上的 PCB 铜箔 + 焊点 + 镀镍铜脚，很容易凑出 1~3 mΩ
→ 电流读数偏大 【7~20%】，且随温度漂（铜 +0.39%/°C）

🔧 **2026-09-14 更正（审图 #23）**：`7~20%` 这个数把整条 7 A 走线的电阻都算进去了，
但短接发生在**焊盘上**时，焊盘之外的走线不进误差。**实际量级是 1~7%**（0.15 mΩ→1.0%、0.5 mΩ→3.3%、1 mΩ→6.7%）。
**结论不变**，而且真正致命的是温漂：寄生的是铜（+3900 ppm/°C），1 mΩ 就给总温漂贡献 **260 ppm/°C**，
而 PCS-10W 本体只有 25 ppm/°C → **总温漂放大 11 倍**，30 °C 下漂 0.78%，且标定不掉。
```

**对一台要显示 `|Z| / R / X / 相位` 的仪器，这是首要误差源** —— 而且是花了钱买四端件却没用上。

### 正确接法

```
J4.2（变压器侧）──── 电流端（宽脚）
                      取样端（窄脚）──┬── HV_GND ── 四颗 IC 的高压侧参考
                                       ├── R9 → AMC3301.7 (INN)
                                       ├── R10/R11 的 REF 回地
                                       └── 两条分压链的下臂

J3.2（输出−侧）──── 电流端（宽脚）
                     取样端（窄脚）──┬── R8 → AMC3301.6 (INP)
                                      └── R1 → AMC23C12(OC).2 (IN)
```

🔴 **立创封装 `PCS-10W` 里 1/2/3/4 号脚谁是电流端、谁是取样端，要去封装库核一眼**
（判据：**宽脚 = 电流端**）。

> 🟢 分压链那 0.766 mA 流经取样脚会不会破坏开尔文？
> 取样脚是镀镍铜脚、约 0.2 mΩ → `0.766 mA × 0.2 mΩ = 0.15 µV`，
> 相对 150 mV 信号是 **0.0001%** ✅ 完全可以忽略。而且它走的是同一端的电流脚，不穿过被测元件。

## 手册其余数据复核 —— 全部合格，而且余量很大

### 🔴 订货必须写全三项

照手册自己的订货示例格式：

```
PCS-10W    15mR    0.5%    25PPM
```

**TCR 的影响**（0.75 W 自发热按 20 °C 温升估）：

| TCR | 增益漂移 |
|---|---|
| 10 ppm/°C | 0.020% ✅ |
| **25 ppm/°C** | **0.050%** ✅ 推荐 |
| 50 ppm/°C | 0.100% ✅ 也可接受 |
| 100 ppm/°C | 0.200% 🟡 标定值会跟着温度漂 |

### 🔴 还要向厂家问一个手册没给的数：**残余电感 `L_s`**

手册只写「无感设计」，**没给数值**。这个数直接变成电流通道的相位误差：

```
相位误差 = arctan( 2π·f·L_s / 15 mΩ )
```

| `L_s` | 2 kHz | **10 kHz** |
|---|---|---|
| 0.5 nH | 0.024° | **0.120°** |
| 1 nH | 0.048° | **0.240°** |
| 2 nH | 0.096° | **0.480°** |
| 5 nH | 0.240° | **1.200°** |

```
要 ≤0.10° @10 kHz → L_s ≤ 0.42 nH
要 ≤0.25° @10 kHz → L_s ≤ 1.04 nH
```

🟢 **好消息：它和频率成正比、系统性、可重复** → 和 AMC 带宽差一样，
**被那张 4 点（2/5/8/10 kHz）相位标定表一起吃掉**。
所以不必把 `L_s` 卡到 0.42 nH，**关键是稳定**（合金箔 + 低 TCR 就是为这个）。

🔴 **但有一部分是标定不掉的：PCB 上开尔文取样走线的环路面积。**
那部分和主电流回路是互感耦合，会随布局而变、随电流方向而变。
→ **布局要求：两根取样走线紧贴并行（当差分对走），远离主电流回路，环路面积做到最小。**
这条我会写进 PCB 检查清单。

# 四、rev2 新发现 / 仍未改

## 4.1 🔴🔴 两条分压链的上臂还是接在 `SHUNT +` 上

```
'SHUNT +' ; R1.1 R2.1 R8.1 R12.1 RS1.1 RS1.2
                 ↑OV上臂  ↑测量上臂
```

**`HV+` 这个网络在图上根本不存在。** 于是两条链量的都是 shunt 压降：

| | 量到的 | 应该量 | 后果 |
|---|---|---|---|
| OV 保护 | 150 mV / 1609 = **93 µV** | 316 V 峰 / 1609 = 196.5 mV | **永远不会跳闸** |
| AMC3330 电压测量 | 150 mV / 443.9 = **338 µV** | 0.712 V | **电压读数永远接近 0** |

→ **这正是 §一 那两个端子要解决的事**：画上 `J4`/`J3` 之后，把 `R2.1` 和 `R12.1` 改接 `HV+`。

## 4.2 🔴🔴 `U4.15` / `U5.15`（`DCDC_GND`）悬空 —— 两片 AMC 都起不来

```
'$1N64'  ; C17.2 U4.15        ← 整个网络只有 2 个节点
'$1N112' ; C29.2 U5.15        ← 同样
AGND     ; ... U4.9 U5.9 ...  ← GND(9) 在 AGND 里，但 15 脚不在
```

手册表 5-1：**「15 DCDC_GND　Low-side ground reference for the isolated DC/DC converter;
**connect this pin to the GND pin**.」**

`DCDC_IN`(16) 从 `LDO_OUT`(13) 取电，回流要经 `DCDC_GND`(15)。15 脚悬空 →
**低压侧 DC/DC 没有回路 → 高压侧永远起不来 → AMC 输出被拉到失效安全值（−2.5 V 差分）。**
电流和电压两个通道全死。

**改法**：`U4.15` → `AGND`（和 `U4.9` 同网）；`U5.15` → `AGND`。
`C17`/`C29` 位置不动，仍然跨在 16–15 之间 ✅

## 4.3 🔴 `C23` / `C24` 两端都接在 `GND1` 上 —— 被短路了

```
GND1 ; ... C23.1 C23.2 C24.1 C24.2 ...
OC   ; R10.1 U1.3        ← 没有电容
OV   ; R11.1 U2.3        ← 没有电容
```

这两只 100 nF 应该是 `REF` 的滤波电容（手册 §8.4 图 8-6 的 `C5`）。
**改法**：`C23.1` → `OC` 网络、`C24.1` → `OV` 网络，另一端留在 `GND1`，**贴脚放**。

## 4.4 🔴 `SNS_PRESENT#` 是单节点网络

```
'SNS_PRESENT#' ; CN9.1        ← 只有一个节点
```

SNS-01 上要**直接短到 `DGND`**。不接的话主板那只 10 kΩ 上拉读到高 = "采样板不在" →
软件会一直禁止输出。**改法**：`CN9.1` 接 `DGND`。

## 4.5 🟡 `C19` / `C27` 应该是 100 nF，不是 1 µF

`HLDO_OUT`(5) 的去耦，TI 手册 §9 原文：
> "For the high-side LDO, use low-ESR capacitors of **1-nF (C6)** ... followed by a **100-nF** decoupling capacitor (C5)."

rev2 用的是 **1 µF + 1 nF**。1 nF 那只对 ✅，1 µF 那只手册要的是 100 nF。
LDO 的相位裕度和输出电容有关，**手册没有验证过 1 µF**。→ 建议照手册改 100 nF。

（其余去耦全对：`C16`+`C18` = 1 µF + 1 nF 在 `DCDC_OUT` ✅；
`C21`+`C22` = 1 µF + 1 nF 在 `VDD` ✅；`C17` 100 nF 在 `DCDC_IN`↔`DCDC_GND` ✅）

## 4.6 🟡 `R12`~`R19` 的精度和温漂

网表没写精度。测量分压链直接决定电压读数：

```
7 只上臂 ±1% 随机 → 合成 σ = 1%/√7 = 0.38%
下臂 ±1%
分压比误差 ≈ √(0.38² + 1²) = 1.07%
```

增益误差可以软件一次标定掉，**但温漂标不掉**：
厚膜 ±1% 典型 100 ppm/°C → 40 °C 变化 **0.4%**；薄膜 ±0.1% 典型 25 ppm/°C → **0.1%**。

→ 🟡 **`R12`~`R19` 建议 ±0.1% 薄膜**。
（`R2`~`R6` 那条 OV 保护链 **±1% 就够** —— 门限本来就设在 1.29×，不需要精度。）

## 4.7 🟡 `U4` 和 `U5` 用了两个不同的 SOIC-16 封装

```
U4 : SOIC-16_L10.3-W7.4-...     ← AMC3301
U5 : SOIC-16_L10.3-W7.5-...     ← AMC3330（和 UCC12050 U3 同一个）
```
`AMC3301` 和 `AMC3330` **都是 DWE 封装**，应该用同一个。差 0.1 mm 实际能焊，
但 🟡 建议统一，出 BOM / 贴片时不易混。
