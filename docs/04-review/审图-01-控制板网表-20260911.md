## 🔴 必改

### R-01 · 8 MHz 晶振接到了 LSE 引脚

```
'$3N26' ; C21.2 U1.3 U17.2      U1.3 = PC14-OSC32_IN
'$3N27' ; C22.2 U1.4 U17.1      U1.4 = PC15-OSC32_OUT
```

PC14/PC15 是 **LSE（32.768 kHz）** 振荡器引脚，驱动能力按 32 kHz 音叉晶体设计，
**无法起振 8 MHz 晶振**。

**改为 HSE 引脚：**

```
U17.1 → U1.5   (PF0-OSC_IN)
U17.2 → U1.6   (PF1-OSC_OUT)
```

C21 / C22 = 12 pF 取值正确（见 MCU 文档 §4.1，CS = 10 pF、晶振 CL = 16 pF），随之搬移即可。

### R-02 · 光耦一次侧无限流电阻 —— 通电即烧

```
12V ; U2.1 U3.1 U5.1 U15.1      PC817 的 LED 阳极直接接 12 V
```

PC817 的 LED 正向压降约 1.2 V，12 V 直接施加 → 电流数百 mA → **微秒级烧毁**。

**每路串 3.3 kΩ**（`12V → 3.3 kΩ → U2.1`）。校核：

```
I_F = (12 − 1.2) / 3.3 k = 3.27 mA
PC817C 档 CTR 200~400%  →  Ic = 6.5 ~ 13 mA
拉低 10 kΩ 上拉只需 3.3 V / 10 k = 0.33 mA
饱和余量 20 倍 ✅（按 10 年 CTR 衰减 50% 仍有 10 倍）
```

### R-03 · 光耦缺 1N4148 反并联保护

PC817 的 **LED 反向耐压仅 6 V**。J2 是现场接线到 DRS 干接点，接反即击穿。

**四路各并一只 1N4148**（阴极接 LED 阳极侧）。
建议顺带在 LED 两端并 **100 nF** —— 线束走在强电区，抑制尖峰误触发。

## 🟠 网络错误

### N-01 · `D3V3` 为悬空网络

```
D3V3 ; R1.2 R3.2 R5.2 R7.2      只有这四个，不连电源
3V3  ; ... U13.5 ...            LDO 输出实际在 `3V3` 这个名字上
```

R1/R3/R5/R7 是光耦输出的 10 kΩ 上拉，上端挂在不连电源的 `D3V3` 上，
**四路状态信号永远拉不高**。

**建议连命名一起统一**（与文档对齐）：

| 现网络名 | 改为 |
|---|---|
| `3V3` | **`D3V3`** ← 改完上拉自动接上 |
| `3V3_AVDD` | **`A3V3`** |
| `GND` | **`GND_AUX`** |

### N-02 · `AGND` 几乎是死网络，U6 的输入电容失效

```
AGND ; C6.1 C7.1                        只有这两个
DGND ; ... U6.2 U1.27 C8.1 C9.1 C19.2 C20.2 C23.2 C24.2 ...
```

- C6 / C7 是 U6 的输入去耦（4.7 µF + 100 nF），一端接 `5V_IN`，
  另一端接一个**不连任何东西**的网络 → **完全不起作用**
- U6.2（LDO 地）、U1.27（VSSA）、VDDA 去耦、VREF+ 去耦**全部落到 DGND**

**按 §1.7 重建 AGND：**

```
AGND ; U6.2  C6.1 C7.1  C8.1 C9.1  U1.27(VSSA)  C19.2 C20.2  C23.2 C24.2

AGND ──[ R_TIE 0Ω 0603 ]── DGND        PCB 上放在 VSSA (pin 27) 引脚旁
```

### N-03 · `GND` 为悬空网络；ULN2803 的 COM 未接

```
GND ; U4.1 U7.1 U10.9 U14.1 U16.1
```

四个端子的回线 + ULN2803 的 GND (pin 9) 挂在此网络，但**无电源回路来源**。
应为 `GND_AUX`（12 V 域地），需接 12 V 输入连接器的回线。

> ⚠️ **U10.10（ULN2803 的 COM）不在任何网络里。**
> 接继电器时必须接 **+12V_AUX**，否则内部续流二极管不起作用，
> 关断时线圈反峰（上百伏）直接打在输出管上。见 `docs/01-power/12V辅助电源-设计与计算.md` §6。

## 小建议

1. **C24（VREF+ 的 1 µF）建议换 0805，或选 25 V X7R。**
   VREFBUF 要求 `CL = 0.5 ~ 1.5 µF、ESR ≤ 2 Ω`。0603 的 1 µF 在 2.9 V 偏压下
   容值衰减 10~20%，虽仍 > 0.5 µF，但余量不大。

2. **给自动生成的网络命名**：`$3N28` → `VREF+`，`$3N26/$3N27` → `OSC_IN / OSC_OUT`，
   `$2N39` 等 → `AC_OK_RET` 之类。后续审图与 PCB 阶段会省很多事。
