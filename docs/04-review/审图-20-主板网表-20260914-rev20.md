## 1. ✅ R19-01 闭环 —— 改得干净，没有副作用

rev19 → rev20 的**全部差异只有两行**：

```diff
- 'HARD_OK_MON' ; C75.2 CN9.2 CN9.3 R44.2 R54.2 U1.51 U1.55 U29.1 U29.2
+ 'HARD_OK_MON' ; C75.2 CN9.2 CN9.3       R54.2 U1.51       U29.1
+ 'PD2'         ; R44.2 U1.55 U29.2
```

逐条对判据：

| 判据（审图 #19 §1） | rev20 | 结果 |
|---|---|---|
| `U29.1` 和 `U29.2` 必须在两个不同网络上 | `U29.1` ∈ `HARD_OK_MON`，`U29.2` ∈ `PD2` | ✅ |
| `U1.55`(PD2) 不能和 `R54`(2.2 kΩ 上拉) 同网 | `U1.55` ∈ `PD2`，`R54.2` ∈ `HARD_OK_MON` | ✅ |
| `R44` 10 kΩ 下拉要跟着 `PD2` | `R44.2` ∈ `PD2`，`R44.1` ∈ `DGND` | ✅ |
| `R54`/`C75`/`PA15` 留在 `HARD_OK` | `R54.1` ∈ `3V3`、`C75.1` ∈ `DGND`、`U1.51` ∈ `HARD_OK_MON` | ✅ |
| 与门输出串 `R45` 到 `AMP_ENABLE` | `U29.4` → `$4N2` → `R45.1`；`R45.2` → `AMP_ENABLE` → `CN5.3` | ✅ |
| `U29` 供电 | `U29.5` ∈ `3V3`、`U29.3` ∈ `DGND` | ✅ |

### 失效安全复核（现在是对的）

| 场景 | `HARD_OK`(A) | `PD2`(B) | `AMP_ENABLE` |
|---|---|---|---|
| MCU 复位 / 跑飞（`PD2` 高阻） | 高（`R54` 上拉） | **低**（`R44` 下拉） | **禁止** ✅ |
| 正常运行、软件允许 | 高 | 高 | 允许 ✅ |
| OC / OV 跳闸 | **低**（开漏拉低） | 高 | **禁止** ✅ |
| `UCC12050` 坏 / 线束断 | **低**（AMC `VDD1` 掉电 >100 µs 主动拉低） | — | **禁止** ✅ |
| 采样板整块拔掉 | 高（检测不到） | — | 靠 `SNS_PRESENT#` 由软件禁止 ✅ |

**再也没有推挽对开漏的贯通**：`PD2` 现在只驱动与门的 CMOS 输入（>1 MΩ）✅

**第 4+5 步在 MAIN-01 上收口。** 剩下的都是可选项或别的板子的事。
