## 2. 🔴🔴 必改（4 条）

### 2.1 🔴🔴 OV 分压链的上臂还在 `SHUNT +` 上 —— 过压保护仍然永不跳闸

```
'HV+'     ; R12.1 U30.2          ← 测量分压链上臂 ✅ 改对了
'SHUNT +' ; R1.1 R2.1 RS1.1      ← R2.1 = OV 分压链上臂 ❌ 还在 shunt 上
```

**两条分压链只改了一条。** OV 那条量到的还是：

```
(V(RS1.1) − V(GND1)) / 1609 = 150 mV / 1609 = 93 µV
跳闸门限 253 mV  →  永远够不着
```

**改法**：`R2.1` 从 `SHUNT +` 挪到 **`HV+`**。（两条链共用同一个 `HV+` 节点，
但**下臂各自独立** —— ADR 要的「两条互相独立的分压链」指的是链本身独立，上臂同源是应该的。）

### 2.2 🔴🔴 `RS1` 的 3 脚（取样）和 4 脚（电流）还并在 `GND1` 上

```
GND1 ; ... RS1.3 RS1.4 ... U30.1 ...
```

手册确认 **2、3 是取样端（窄 1.1 mm，间距 7.62 mm），1、4 是电流端（宽 1.5 mm，间距 17.78 mm）**，
你自己那张符号图上 `+`/`−` 也标在 2、3 上 —— 两条证据一致。

**3 和 4 并起来 = 那一侧的开尔文作废**，而且 `GND1` 这个铜皮上还挂着 `U30.1`，
**7.07 A 的负载电流正从这块铜上流过**，芯片的参考就取在这块铜上：

```
寄生 0.15 mΩ → 电流读数偏大 1.0%
寄生 0.50 mΩ → 3.3%
寄生 1.00 mΩ → 6.7%
```

> 🔧 **更正上两轮写的「7~20%」**：那个数把整条 7 A 走线都算进去了，
> 短接在焊盘上时焊盘之外的走线不进误差。**实际是 1~7%。结论不变。**

**真正致命的是温漂**：寄生的是铜（+3900 ppm/°C），1 mΩ 寄生就给总温漂贡献 **260 ppm/°C**，
而你打算订的 PCS-10W 是 **25 ppm/°C** → **总温漂放大 11 倍**，30 °C 下读数漂 **0.78%**，
**而且标定不掉**（随温度、焊接、铜皮走向变）。

**改法：拆成两个网络。**

```
'TR_COM'  = U30.1 + RS1.4       ← 7.07 A 宽铜
'HV_GND'  = RS1.3 + 四颗 IC 的高压参考 + 两条分压链下臂 + R9.1 + R10.2 + R11.2
```
🔴 **它们只在 `RS1` 内部相连，PCB 上两块铜不许混。**

### 2.3 🔴🔴 OC 的输入取在电流端（1 脚）而不是取样端（2 脚）

```
'SHUNT +' ; R1.1 R2.1 RS1.1      ← R1 = OC 的输入串阻，挂在 1 脚（电流端）
'I+'      ; R8.1 RS1.2           ← R8 = AMC3301 INP，挂在 2 脚（取样端）✅
```

**AMC3301 用对了取样脚，AMC23C12(OC) 用错了。** 两者应该取同一个取样脚
—— 否则硬件过流保护的门限会带上和测量不一样的寄生误差，跳闸点飘。

**改法**：`R1.1` 从 `SHUNT +` 挪到 **`RS1.2` 那个网络**（和 `R8.1` 同网，建议网名 `I_SNS`）。

### 2.4 🔴🔴 输出端子 `U6` 完全悬空 —— 负载电流没有回路

```
'OUT-' ; U6.1        ← 单节点网络
'OUT+' ; U6.2        ← 单节点网络
```

**`HV+` 到不了 `U6.2`，`RS1.1` 也到不了 `U6.1`。整条 7.07 A 的主回路断着。**

**改法**：
```
U6.2 → 'HV+'                （和 U30.2 同网）
U6.1 → 'OUT-' 且 'OUT-' 里要有 RS1.1
```

## 3. 改完之后的五个网络（照这个核）

| 网络 | 成员 | 电流 |
|---|---|---|
| `HV+` | `U30.2` `U6.2` **`R2.1`** `R12.1` | 🔴 7.07 A |
| `TR_COM` | `U30.1` `RS1.4` | 🔴 7.07 A |
| `OUT-` | `U6.1` `RS1.1` | 🔴 7.07 A |
| `HV_GND` | `RS1.3` + 四颗 IC 高压参考 + `R6.1` `R19.1` `R9.1` `R10.2` `R11.2` + 所有高压侧去耦 | ≈0 |
| `I_SNS` | `RS1.2` `R8.1` **`R1.1`** | ≈0 |

**电流走向自检**：

```
负载： 变压器抽头 → U30.2 → HV+ → U6.2 → 负载 → U6.1 → OUT- → RS1.1
       → 【电阻片】→ RS1.4 → TR_COM → U30.1 → 变压器 com       ✅ 全过电阻片
分压： HV+ → 两条分压链 → HV_GND → RS1.3 → TR_COM → 变压器 com  ✅ 不过电阻片（待决 #59 ✅）
```

## 4. 🟡 建议

| # | 事项 |
|---|---|
| 1 | 🔴 **`U30` / `U6` 是 `KF301-5.0-2P`，要核它的额定电流和电压**：我们要 **7.07 A / 223.6 Vrms**，需求是 **≥10 A、≥300 V**。KF301-5.0 各厂家标法不一（常见 10 A/300 V 或 17.5 A/300 V），**下单前确认料号** |
| 2 | 🟡 位号：`U30` 跳号了（板上其余是 `U1`~`U6`）。建议改 `U7` 或 `J1`/`J2`，出 BOM 不易混 |
| 3 | 🟡 `R12`~`R19`（测量分压链）建议 **±0.1% 薄膜（25 ppm/°C）** —— ±1% 厚膜是 100 ppm/°C，40 °C 下漂 0.4%，标定值跟着漂。`R2`~`R6`（OV 保护链）**±1% 够用** |
| 4 | 🟡 `U4`（W7.4）和 `U5`（W7.5）用了两个不同的 SOIC-16 封装。`AMC3301`/`AMC3330` **都是 DWE**，建议统一 |
| 5 | 🟡 `C15` 的介质要写明 **C0G/NP0**（10 nF 0805，直接跨在被测差模信号上） |
