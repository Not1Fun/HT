## 1. 🔴🔴 R19-01 · 与门的两个输入被短接在一起，而且和 `PD2` 同网

### 网表证据

```
'HARD_OK_MON' ; C75.2 CN9.2 CN9.3 R44.2 R54.2 U1.51 U1.55 U29.1 U29.2
```

这一个网络上同时挂着：

| 节点 | 是什么 |
|---|---|
| `U29.1` | 74LVC1G08 的 **A 输入** |
| `U29.2` | 74LVC1G08 的 **B 输入** |
| `U1.55` | **`PD2`** —— MCU 的软件使能输出（推挽） |
| `U1.51` | `PA15` —— 硬件状态监视输入 |
| `R54.2` | 2.2 kΩ **上拉**到 `3V3` |
| `R44.2` | 10 kΩ **下拉**到 `DGND` |
| `CN9.2` / `CN9.3` | 采样板两片 AMC23C12 的 **开漏输出** |
| `C75.2` | 1 nF 滤波 |

**与门的 A、B 两个输入接在同一个点上 → `Y = A·B = A` → 与门退化成一只缓冲器。**
软件使能和硬件保护被并到了一根线上，第 5 步的整个设计意图消失了。

### 三个后果，按严重程度排

#### ① 🔴🔴 复位/上电期间功放被使能 —— 失效安全方向反了

MCU 复位时 `PD2` 是高阻，采样板正常时两片 AMC23C12 的开漏输出也是高阻，
于是这个节点只剩 `R54`(2.2 kΩ 上拉) 和 `R44`(10 kΩ 下拉) 分压：

```
V = 3.3 V × 10 kΩ / (10 kΩ + 2.2 kΩ) = 2.705 V
```

74LVC1G08 在 VCC = 3.3 V 时 `V_IH` = 2.0 V → **2.705 V 判为高电平**
→ 与门输出高 → `AMP_ENABLE` 有效 → **上电瞬间、复位期间、看门狗复位后，功放都是使能的。**

> 审图 #18 刚刚确认过「`R44` 10 kΩ 下拉 → `PD2` 复位高阻即被拉低 → 功放禁止 ✅」。
> rev19 把 `R54` 的 2.2 kΩ 上拉并到了同一个节点上，**2.2 kΩ 打赢了 10 kΩ，方向整个反过来。**

#### ② 🔴 `PD2` 推挽输出和两片 AMC23C12 的开漏输出直接打架

`PD2` 是推挽。过流/过压跳闸时 AMC23C12 主动把 `OUT` 拉低，而 `PD2` 正在输出高：

| 器件 | 导通电阻 | 依据 |
|---|---|---|
| STM32 GPIO 上管 | ≈ 50 Ω | `V_OH ≥ V_DD − 0.4 V @ 8 mA` |
| AMC23C12 开漏下管 | ≤ 62.5 Ω | `V_OL` = 250 mV max @ `I_SINK` = 4 mA（手册 §6.9） |

```
节点电压 ≈ 3.3 V × 62.5 / (50 + 62.5) = 1.83 V   ← 落在 74LVC1G08 的禁区（V_IL 0.8 V ~ V_IH 2.0 V）
贯通电流 ≈ 3.3 V / 112.5 Ω = 29 mA
```

- 与门输出**不确定**，可能自激；
- 29 mA 超过 STM32 单脚推荐值 20 mA；
- 也超过 AMC23C12 `OUT` 脚的连续电流承受范围。

**也就是说：软件把 `PD2` 拉高，硬件保护就跳不动闸了。** 这正好是这条链要防的事。

#### ③ 🟡 `PA15` 的监视功能失去意义

`PA15` 现在读到的是「`PD2` 自己输出的值」和「硬件状态」的混合，分不出是谁把线拉低的。

### 改法（三刀，都在原理图上）

```
把 'HARD_OK_MON' 这一个网络拆成两个：

网络 A ── 'HARD_OK'（硬件状态）
    CN9.x (OC_FAULT#)    ← 采样板 AMC23C12 #1 开漏
    CN9.y (OV_FAULT#)    ← 采样板 AMC23C12 #2 开漏
    R54.2   2.2 kΩ 上拉到 3V3      ← 留在这边
    C75.2   1 nF 到 DGND           ← 留在这边
    U1.51   PA15（监视）           ← 留在这边
    U29.1   与门 A 输入            ← 只接 A
  🔴 R44 不在这边

网络 B ── 'SW_ENABLE'（软件使能）
    U1.55   PD2
    R44.2   10 kΩ 下拉到 DGND      ← 🔴 挪到这边来
    U29.2   与门 B 输入            ← 只接 B

与门输出不动：U29.4 → R45(100Ω) → AMP_ENABLE → CN5.3   ✅ rev19 这一段是对的
```

改完以后复核失效安全：

| 工况 | `HARD_OK`(A) | `SW_ENABLE`(B) | `AMP_ENABLE` |
|---|---|---|---|
| MCU 复位（`PD2` 高阻） | 高（2.2k 上拉） | **低**（`R44` 下拉） | **禁止** ✅ |
| 正常运行、软件允许 | 高 | 高 | 使能 ✅ |
| OC 或 OV 跳闸 | **低**（开漏拉低） | 高 | **禁止** ✅ |
| `UCC12050` 坏 / 线束断 | **低**（AMC `VDD1` 掉电 >100 µs 主动拉低） | — | **禁止** ✅ |
| 采样板整块拔掉 | 高（上拉，检测不到） | — | 靠 `SNS_PRESENT#` 由软件禁止 ✅ |

响应时间复核：AMC23C12 `t_pL` ≤ 410 ns + 74LVC1G08 传输延迟 ≈ 4 ns
→ **远小于 10 kHz 的一个周期（100 µs）** ✅。
`C75` 1 nF × `R54` 2.2 kΩ = 2.2 µs 只加在**释放沿**上；跳闸沿是开漏管子拉的（≈62 Ω × 1 nF = 62 ns），
**快跳慢放，方向正确** ✅。

## 2. 🔴 R19-02 · `OC_FAULT#` 和 `OV_FAULT#` 两个网名不存在，两根线被并成一根

`CN9.2` 和 `CN9.3` 现在是同一个网络。电气上这是一个「线或」，保护功能**仍然成立**，
但是：

- 板间连接器上两个脚送的是同一个信号，**白白浪费一根线**；
- **MCU 永远分不清这次跳闸是过流还是过压**。

对这台机器这件事是有意义的：过流 = 负载偏低阻/短路，过压 = 负载偏高阻/开路，
面板上提示的内容完全不同。而且 `PA15` 只有一个，要分辨就得再占一个脚 —— 现在还剩 10 个空闲脚。

**建议**（拆完 R19-01 之后一起做）：

```
CN9.x → 'OC_FAULT#' → 各自 2.2 kΩ 上拉 → PA15   （监视 1）
CN9.y → 'OV_FAULT#' → 各自 2.2 kΩ 上拉 → PB1(25) （监视 2，ADC1_IN12，本来空闲）
两者再一起进与门 A 输入 —— 用一只 74LVC1G08 的两个输入正好，
或者直接让两路开漏共用一只 2.2 kΩ 上拉（线或）+ 两只 10 kΩ 串到两个监视脚。
```

> 🟢 **最省事的版本**：保留线或（一只 `R54` 2.2 kΩ 上拉、一根线进与门 A），
> 只把 `CN9` 上多出来的那个脚改成 `OV_FAULT#` 单独引出、经 10 kΩ 串到 `PB1` 做诊断。
> 这样保护路径一点没动，只是多一路只读信息。

## 3. 🟡 建议项

### R19-03 · `CN9` 的脚序建议调一调（现在改不要钱，画完 PCB 就晚了）

rev19 实际：

| 脚 | rev19 | 建议 |
|---|---|---|
| 1 | `SNS_PRESENT#` | `SNS_PRESENT#` |
| 2 | `HARD_OK_MON` | **`DGND`** |
| 3 | `HARD_OK_MON` | `OC_FAULT#` |
| 4 | `PROT_LATCH` | `OV_FAULT#` |
| 5 | `DGND` | `DGND` |
| 6 | `3V3` | `PROT_LATCH` |
| 7 | `DGND` | `+3V3_SNS` |
| 8 | `5V_IN` | `+5V_SNS` |

理由：现在 `.1~.4` 四根信号连成一片、一根地都没插花，而两根 `DGND` 全挤在 `.5/.7`。
这根线要拉到**高压板旁边**，`UCC12050` 一次侧还在同一根线束里跑 64 mA 的开关电流 ——
故障线旁边必须有回线。调整后每一对故障线都紧挨一根 `DGND` ✅。

> 电源脚的回线离了 3 个脚位没关系：0.5 m 24AWG 单根 42 mΩ，64 mA → 2.7 mV，
> 相对逻辑电平几百 mV 的裕量可以忽略 ✅。

### R19-04 · 风扇端子 `U12` 上一只电容都没有

```
'$2N137' ; F6.2 U12.2        ← 只有保险丝和端子，没有电容
```

ADR-016 要求「端子处并 100 µF(≥25 V) + 100 nF」。
现在 `U28`(100 µF) + `C68`(100 nF) 挂在 `12V` 上，**隔着 `F6` 保险丝**。
直流上没问题，但风扇是有刷/无刷电机，换向尖峰的回路应该就地闭合。

**最少加一只 100 nF 直接并在 `U12.1`–`U12.2` 之间**（位号顺延 `C79`）；
100 µF 可以继续共用 `U28`。

### R19-05 · 蜂鸣器和 4 只光耦上拉挂在**未受保护**的 `12V` 段上

```
12V ; BUZZER1.1 C68.1 D9.1 F5.1 F6.1 R9.1 R10.1 R11.1 R12.1 U10.2 U28.1
                └─ 蜂鸣器 ─┘            └── F5/F6 在这之后才分出去 ──┘
```

`12V` 从端子 `U10` 直接进板，板载负载（蜂鸣器 30 mA + 4 只光耦 LED）接在 `F5`/`F6` **之前**。
绘图指南里蜂鸣器是挂 `12V_AUX`（`F6` 之后）的。

**不是功能错误**，但板上任一处短路都会直接打到 12 V 源上。
建议加一只 `F7` **T250mA** 给板载 12 V 支路，或确认 12 V 源自带限流并在 BOM 备注里写明。

### R19-06 · `12V_RLY` 端子 `U11` 同样没有电容

```
'$2N135' ; F5.2 U11.2
```
RLY-01 上 8 只继电器线圈、单只 44.2 mA，投切瞬间的 di/dt 要就地有储能。
**若 RLY-01 上已有 bulk 电容则可以不加**；否则在 `U11` 处并 100 µF/25 V + 100 nF。
→ 记到「画 RLY-01 时确认」。

### R19-07 · `U29` 用的是 SOT-23-5 封装，不是指南里写的 SOT-353

```
SOT-23-5_L3.0-W1.5-P0.95-LS2.8-BL ; U29
```
**不是错误** —— `74LVC1G08` 的 DBV(SOT-23-5) 和 DCK(SC-70-5/SOT-353) 引脚定义相同，
SOT-23-5 反而更好焊。网表里 `3`=`DGND` / `5`=`3V3` / `4`=输出 与
`1=A 2=B 3=GND 4=Y 5=VCC` 的通用定义一致 ✅。

> 🟡 **待核实**：本仓库里**还没有 74LVC1G08 的手册**。上面的引脚定义是按单门逻辑的通用封装约定核的，
> 下单前请把实际选定型号的手册传上来核一遍（尤其别买成 `74LVC1G32`(或门) / `74LVC1G00`(与非门)）。

## 5. ✅ 复核通过的部分

### 5.1 第 4 步 —— 12 V 进线储能

```
12V ; ... C68.1 ... U28.1        C68 = 100 nF 0805
GND ; ... C68.2 ... U28.2        U28 = 100 µF SMD 电解（BD6.3）
```
✅ 值、封装、接地（`GND` 不是 `DGND`）全对。

### 5.2 蜂鸣器（`PA12`）—— 全对，包括二极管方向

```
PA12    ; R40.1 R47.2 U1.46          R40 = 100 Ω 栅极串阻、R47 = 10 kΩ 下拉
'$3N257'; Q2.1 R40.2                 → Q2 栅极
'$3N256'; BUZZER1.2 D9.2 Q2.3        → Q2 漏极 + 蜂鸣器 − + D9 阳极
12V     ; BUZZER1.1 D9.1 ...         → 蜂鸣器 + + D9 阴极
GND     ; ... Q2.2 ... R47.1 ...     → 源极、下拉都回 GND
```

- 🔴 **`D9` 方向正确** ✅ —— 用板上已有的 `D1` 反证：`D1.1` 在光耦 LED 阳极侧、`D1.2` 在阴极侧，
  说明这套 SOD-123 符号 **pin 1 = 阴极**。`D9.1` 落在 `12V` 上 → **阴极朝 12 V** ✅，续流方向对。
- 🔴 **`Q2` 源极和下拉都接 `GND`，不是 `DGND`** ✅ —— 蜂鸣器 30 mA 的回流不污染 `DGND`。
- 🔧 下拉位置：指南写的是「下拉接在栅极」，rev19 接在 `PA12` 侧（100 Ω 的 MCU 那一端）。
  **等效** —— 栅极对 `GND` 仍是 10 kΩ + 100 Ω = 10.1 kΩ，复位时栅极照样被拉死 ✅。不用改。
- 🔧 位号：指南写 `R47`=100 Ω / `R48`=10 kΩ，rev19 是 `R40`=100 Ω（第 2+3 步删掉后复用）/ `R47`=10 kΩ。
  **复用 `R40` 是对的**，位号不留空洞 ✅。
- 🟡 软件约束不变：**相干采样窗口期间不要让蜂鸣器响**（板载有源蜂鸣器标称 2.4 kHz，正好落在 2–10 kHz 带内）。

### 5.3 3 路 NTC —— 全对

```
'$4N25' ; CN6.2 R48.1 R49.2   → R48 22kΩ↑3V3_AVDD, R49 1kΩ → 'ADC1_IN9' (C69 100nF, U1.11 = PC3)
'$4N27' ; CN7.2 R50.1 R51.2   → R50 22kΩ↑3V3_AVDD, R51 1kΩ → 'ADC1_IN1' (C70 100nF, U1.12 = PA0)
'$4N26' ; CN8.2 R52.1 R53.2   → R52 22kΩ↑3V3_AVDD, R53 1kΩ → 'ADC1_IN2' (C71 100nF, U1.13 = PA1)
AGND    ; ... CN6.1 CN7.1 CN8.1 ... C69.2 C70.2 C71.2 ...
```

| 检查项 | 结果 |
|---|---|
| 上拉 **22 kΩ**（不是 10 kΩ） | ✅ 三只都对 |
| 上拉接 `3V3_AVDD` | ✅ |
| 串阻 1 kΩ + 100 nF 到 `AGND`，f_c ≈ 84 Hz | ✅ |
| 三只连接器回线接 `AGND` | ✅ |
| ADC 通道落在 ADC1 注入组可用的 `IN9/IN1/IN2` | ✅ 与引脚分配总表一致 |
| 连接器脚序 `.1`=AGND `.2`=NTC（指南写的是反的） | ✅ **NTC 无极性，插反照样工作**，不用改 |

**削顶复核**（B3950、10 kΩ@25 °C）：

```
−20 °C：R_NTC = 10k × exp(3950 × (1/253.15 − 1/298.15)) = 105.4 kΩ
        V = 3.3 × 105.4/(105.4+22) = 2.73 V  <  VREF+ 2.9 V     ✅ 不削顶
        （若用 10 kΩ 上拉：3.3 × 105.4/115.4 = 3.01 V > 2.9 V   ❌ 削顶 —— 22 kΩ 就是为这个）
```

🟡 **两条软件注记**（不改硬件）：

1. **分压由 3.3 V 供电、却用 2.9 V 基准去量 —— 不是比例式测量。**
   `3V3_AVDD` 的绝对精度（LDO ±2%）会直接变成测温误差，在 NTC 曲线陡的地方约 1.5~2 °C。
   做过温保护完全够；要显示准确值就软件标定一次。
2. −40 °C 时分压是 3.13 V > 2.9 V 会削顶、读数饱和在「很冷」—— **方向是安全的**，
   而且 3.13 V < `V_DDA` 3.3 V，**不会灌 ADC 钳位二极管** ✅。本机也没有 −40 °C 工况。
3. 🔴 ADC 采样时间仍必须取 **640.5 cycles**（源阻抗最坏 ≈ 22k∥105k + 1k ≈ 19 kΩ）。
