## 🔴🔴 先说最要紧的：**整板 36 V 供电断了**

挪 `R28` 的时候，把它**插进了 36 V 主回路**，而不是留在分压链里。

```
实际网表：
  '$2N143' ; F1.2  R28.2                    ← F1 出来只连到 R28
  '$2N92'  ; D5.1  D8.1  D8.3  R28.1        ← TVS 和整流管只连到 R28 的另一端
  '36V_RAW'; D8.2  F2.1 F3.2 F4.1  R29.2
```

**也就是说：整机 2.1 A 的电流现在要穿过一只 100 kΩ 电阻。**

```
DRS 36V → U23 → F1 → 【R28 100kΩ】→ D8 → 36V_RAW → 两路 DC/DC + 功放
                      ▲
                      └── 🔴 这里断了，板子上电什么都不会亮
```

**同时分压也废了**：`R28` 离队之后，剩下 `R29 : R30 = 100k : 10k = 11 : 1`

| 母线 | `V_BUS_SENSE` |
|---|---|
| 32.0 V | **2.909 V** 🔴 已经削顶 |
| 36.0 V | **3.273 V** 🔴 |
| 43.2 V | **3.927 V** 🔴 还超了 VDDA，ADC 输入钳位二极管会导通 |

**整个量程全程削顶，母线电压读不出来。**

### ✅ 正确接法（照这个改）

```
       F1.2 ──┬─────────────────────┬── D5.1   (SMCJ51A 阴极)
              │                     ├── D8.1   (MBR20200CT 阳极1)
              │                     └── D8.3   (阳极2)
              │
              └──[ R28 100kΩ ]──[ R29 100kΩ ]──┬── V_BUS_SENSE ── U1.10 (PC2)
                                                ├──[ R30 10kΩ ]── AGND
                                                └──[ C40 100nF ]── AGND

       D8.2 (共阴极) ── 36V_RAW ── F2.1 / F3.2 / F4.1
```

**网表层面要做的两件事：**

| 改什么 | 具体 |
|---|---|
| ① **把 `$2N143` 和 `$2N92` 合成一个节点** | `F1.2`、`D5.1`、`D8.1`、`D8.3`、`R28.2` 全在同一个节点上。<br>🟡 顺手给它起个名：**`36V_IN`**（现在是自动网名，后面查线难受） |
| ② **恢复 `R28.1 ── R29.2` 这根线** | 就是原来的 `$2N96`。`R29.2` 从 `36V_RAW` 上**拿掉** |

改完之后分压回到 **21:1**，而且测的是 **D8 之前**（DRS 的真实输出）✅：

```
32.0 V → 1.524 V      43.2 V → 2.057 V      55.9 V → 2.662 V     ✅ 全程不削顶
分辨率 14.9 mV/LSB（母线侧）
```

> 你的**意图**是对的（`R28` 要挪到 `D8` 之前），只是连线时把电阻**串进了功率路径**，
> 而不是**从那个节点分一支出来**。分压器是"挂在"主线上的一条支路，不是主线本身。

## 三、🟡 P-51 `D8` 的封装 —— 网表里**和上一版一模一样**，确认一下是不是忘了换

```
rev13:  TO-220-3_L10.1-W4.7-P2.54-L ; D9
rev14:  TO-220-3_L10.1-W4.7-P2.54-L ; D8      ← 只有位号变了，封装名一个字都没变
```

**`W4.7` 正是 TO-220 立着时的本体厚度。** 卧式封装应该是：

| | 立式 | 卧式 |
|---|---|---|
| 外形尺寸 | 约 **10 × 4.7 mm**（只有本体的投影） | 约 **10 × 15~16 mm**（本体躺倒后从引脚到散热片末端） |
| 安装孔 | 无 | **有一个 φ3.2 的 M3 孔** |

请在立创里核一下 —— 有可能是**只把器件在板上放倒了，封装还是立式的孔位**。

### 🔴 更要紧的：卧式**本身不省热，省热的是"螺丝 + 覆铜"**

```
P = 2.10 A × Vf 0.60 V ≈ 1.26 W        （不变，D8 仍然承担 F2+F3+F4 全部电流）
```

| 做法 | θJA | **Tj @45 °C 机箱内** | 判定 |
|---|---|---|---|
| 立式，散热片悬空 | ≈62 °C/W | 123 °C | 🟡 没超 150 °C 但管壳 120 °C |
| **卧式，但只是躺着、没压覆铜** | ≈55~60 °C/W | **~118 °C** | 🟡 **几乎没改善** |
| **卧式 + M3 螺丝压到 ≥40×40 mm 双面覆铜 + 过孔阵列** | ≈30~40 °C/W | **≈89 °C** | ✅ 这才是要的 |
| 卧式 + 小铝散热片 | ≈12~15 °C/W | ≈64 °C | ✅ |

🔴 **TO-220 的散热片就是共阴极，带 `36V_RAW` 电位。**
螺丝孔周围的覆铜也就是 `36V_RAW` 的铜 —— 布局时**别让它碰到 `GND` 铜或固定柱**。
要加金属散热器就必须加绝缘片（导热硅胶片 + 绝缘套管）。

## 四、🟡 P-52 `12V_RLY` / `12V_AUX` 两个网名丢了

```
'$2N135' ; F5.2 U11.2        ← 应该叫 12V_RLY
'$2N137' ; F6.2 U12.2        ← 应该叫 12V_AUX
```
电气上没问题 ✅，但这两个名字在 `J11`（→RLY-01）和 `J14`（风扇）的接口定义文档里都在用，
**PCB 阶段按网名找线会方便很多**，顺手补上。

同理建议给 `$2N92`（合并后的节点）起名 **`36V_IN`**、给 `$2N110`（`F4→Q1` 源极）起名 **`36V_SW`**。
