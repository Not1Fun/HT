## 🔴 新出现的严重问题：PA13 (SWDIO) 被接到 NRST 网络

```
NRST  ; C26.1 R14.1 U1.7 U1.49
                         ↑
                    U1.49 = PA13 = SWDIO，不是 NRST
SWCLK ; U1.50            ← PA14 孤立，排针未接
```

**SWDIO 与 NRST 短接** → SWD 完全不能用，且每次复位都把 SWDIO 拉低。
推测是画 SWD 排针时把 PA13 误当成 NRST。

**改为：**

```
NRST  ; C26.1 R14.1 U1.7          + SWD 排针的 NRST 脚
SWDIO ; U1.49                     + SWD 排针
SWCLK ; U1.50                     + SWD 排针
```

## 本轮决定：WDI → PB9 (pin 62)

见 `docs/02-digital/MCU最小系统-设计与计算.md` §5.4b。要点：

- 从 Table 12 筛出「纯数字 + 无 ADC/OPAMP/COMP 复用 + 未占用」的脚，PB9/PC6/PC7 最干净
- **PB9 位于 pin 62，紧邻 pin 63/64 (VSS/VDD)**，TPS3823 布局在该电源角落时走线最短
- STM32 复位后 GPIO 默认模拟模式（高阻）→ WDI 看到悬空 → 内部自激不复位
  → **软件有充足时间初始化再开始喂狗**
- 喂狗需**下降沿**：周期性**翻转** PB9，周期 ≤ 500 ms；**放主循环，不要放中断**

## R-03 光耦 1N4148 —— 接法与理由

### ⚠️ 更正审图 #01 的理由

审图 #01 写「J2 是现场接线到 DRS 干接点，**接反即击穿**」。**该理由不成立** ——
DRS 是 Form C **干接点**（一对无源触点），**无极性**，两根线接反无任何影响。

**真正的风险：**

| # | 风险 | 说明 |
|---|---|---|
| ① | **12V 输入端子 (U19) 接反** | KF301 无防呆，装配接反 → 四路 LED 同时承受 −12 V → **全部击穿** |
| ② | **线束感应尖峰** | 四路信号线到 DRS 有几十厘米、走在强电区；继电器动作与功放开关会耦合出**随机极性**尖峰 |
| ③ | 将来信号源改为有源输出 | 届时就有极性了 |

**结论（要加二极管）不变，理由改正。**

### 接法（以 U2 为例）

```
  12V ──[ R10 3.3kΩ ]──┬──── U2.1  (PC817 阳极 A)
                       │      ▲
                    ┌──┴──┐   │  D1 阴极 (K) 接这边
                    │ D1  │   │
                    │1N4148   │  D1 阳极 (A) 接那边
                    └──┬──┘   │
                       │      ▼
  GND ─ U7.1   U7.2 ───┴──── U2.2  (PC817 阴极 K)
         └── DRS 干接点 ──┘
```

**方向记忆：与 LED 反着并 —— LED 阳极在哪，二极管的阴极就接哪。**

- 正常：LED 正偏发光，D1 反偏截止，**完全不影响**
- 出现反向电压：D1 正偏导通，把 LED 两端钳在 **−0.7 V**，远低于 6 V 反压极限

### 四路网络对应

| 光耦 | 阳极侧网络 | 阴极侧网络 | 二极管 |
|---|---|---|---|
| U2 | `$2N52` | `$2N39` | **D1**：A→`$2N39`，K→`$2N52` |
| U3 | `$2N54` | `$2N41` | **D2**：A→`$2N41`，K→`$2N54` |
| U5 | `$2N50` | `$2N40` | **D3**：A→`$2N40`，K→`$2N50` |
| U15 | `$2N56` | `$2N42` | **D4**：A→`$2N42`，K→`$2N56` |

**型号**：`1N4148W`（SOD-123）或 `1N4148WS`（SOD-323）。反压 75 V、正向 300 mA。

**顺带**：每路 LED 两端再并 **100 nF 0603**（与 D1 同位置）抑制线束尖峰。
时间常数 3.3 kΩ × 100 nF = 330 µs，对秒级变化的状态信号无影响。

### 更根本的一条：12V 输入加防反接

二极管防的是尖峰；**12V 端子接反**应从源头解决 —— 12 V 不只给光耦，
还给 ULN2803 与继电器（反接时 ULN2803 的内部二极管导通，大电流）。

**12V 端子后串 `SS34` 或 `1N5819` 肖特基**，610 mA 时压降约 0.4 V：

```
G5RL 必须动作电压 = 12 V × 80% = 9.6 V
12 − 0.4(肖特基) − 1.1(ULN2803)   = 10.5 V > 9.6 V   ✅ 余量 0.9 V
12 − 0.4(肖特基) − 0.4(TBD62083A) = 11.2 V > 9.6 V   ✅ 余量 1.6 V
```

后者是换 **TBD62083A** 的又一个理由。
或更省事：**12V 用防呆端子**（XH2.54 带扣 / KF2EDG 插拔式）。两者都做最好。
