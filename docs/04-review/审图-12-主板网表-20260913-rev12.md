## 二、🔧 勘误：上一轮 P-34「`C34` 封装装不下」是**错的**

你发的立创页面是实物证据：

```
Econd  1000uF63V13x25GF   (C49304993)
封装 插件 D13 × L25 mm · 脚间距 5 mm · 63 V · ±20%
ESR 50 mΩ · 纹波 1.8 A @100 kHz · 3000 hrs @105 °C · −40~+105 °C
```

**φ13 × 25 / 脚距 5.0 mm 的 1000 µF/63 V 确实存在**，现封装 `CAP-TH_BD13.0-P5.00` 是对的。
我上一轮按"1000 µF/63 V 一定是 φ18/P7.5"下的结论，是拿名牌长寿命料（Nichicon UPW 一类，
纹波 2.5 A）的体积去套，**不成立**。**P-34 撤销，不用改封装。**

### 顺便把这只电容的选型核一遍 ✅ 通过

| 项 | 值 | 核算 |
|---|---|---|
| 耐压 63 V | 正常最高 **43.2 V = 69%** ✅ | 55.9 V（DRS 过压保护点上限）= 89%，但那是**保护动作瞬间**，不是稳态 ✅ |
| **纹波 1.8 A @100 kHz** | D 类功放的直流侧电流含一个 **2f 分量**（BTL 供电电流 ∝ sin²）<br>幅度 ≈ 直流分量 1.54 A → **RMS 1.09 A @4~20 kHz** | 这 1.09 A 主要由**模块自带的 2400 µF** 承担，C34 隔着线束只分到一部分（估 0.4~0.5 A）。<br>4 kHz 处的频率降额系数约 0.7 → 可用 1.3 A → **余量 ≈2.6×** ✅ |
| 寿命 3000 h @105 °C | 机箱内 45 °C → 3000 × 2^((105−45)/10) = **19 万小时** ✅ | 即使自热到 55 °C 也有 9.6 万小时 ✅ |
| ESR 50 mΩ | 0.5 A 纹波 → 自热功耗 12.5 mW ✅ | 可忽略 |

> ⚠️ 唯一要留意的是**它的纹波额定只有名牌料的一半**。
> 如果将来功放模块自带的输入电容比预期少，这只可能要换成低 ESR 的长寿命料。
> **第一版可以用，量产前拿实物测一下它的温升**（贴片温度计或红外，环境 +10 °C 以内算正常）。

## 三、🔴 本轮必改

### P-42 🔴🔴 **功率地 `GND` 被并进了 `AGND`** —— 这是本轮最要紧的一条

rev12 里 `GND` 这个网络**消失了**，原来挂在它上面的东西全跑到 `AGND` 上：

```
AGND ; ... C34.2 C35.1 C36.1 C37.1 C38.1 C39.2  ← 母线体电容
           D8.2  SMC1.2                          ← crowbar / TVS
           R27.1                                 ← 软启动栅极分压下臂
           U23.1  U26.1                          ← 36V 进线 / 功放供电端子
           U20.1  U25.1                          ← 两路 DC/DC 输入端子
           U10.1  U11.1                          ← 12V 进 / 出端子
           U4.1 U7.1 U14.1 U16.1                 ← 四路 DRS 干接点端子
       ... 同时还有 ...
           U1.27(VSSA)  C23.2 C24.2(VREF+)  C19.2 C20.2(3V3_AVDD)  R30.1(V_BUS_SENSE)
```

#### 🔧 先认领我自己的责任

上一轮 P-38② 我写的是「**`R13` 和保留的那一只 GND 桥必须落在同一个物理点**」。
这句话有歧义，你按「那就并成一个网络」理解完全说得通。
**我的本意是：三个网络要保留，只是它们的桥接元件在 PCB 上要挨着放。**

> 🔴 **同一个物理点 ≠ 同一个网络。**
> 单点星型接地的意思是「三张铜皮只在一个地方相碰」，
> 而不是「三张铜皮合成一张」。合成一张之后，**布线软件就再也拦不住
> 功放那 1.74 A 从模拟区底下穿过去** —— 这才是真正的损失。

#### 为什么必须分开（按影响从大到小）

| 影响 | 说明 |
|---|---|
| ① **失去可执行性** | 合成一个网络后，敷铜就是一整块，**DRC 不会报任何错**。星型接地只能靠布线时手工"记得"，一改版就破功 |
| ② 🔴 **`VREF+` 的基准噪声** | `C23`/`C24` 的回流点如果和功率地同网，母线上的开关噪声会直接调制 **VREFBUF 2.9 V**。<br>基准被调制 = **增益被调制**，这是差分 ADC 的共模抑制**管不了**的 |
| ③ **ADC 共模窗口** | ADR-015 只留了 **±170 mV**。功放的 2f 电流（4~20 kHz、约 1 A RMS）+ 两路 DDR-30L 的开关回流<br>如果流过模拟区共享的那段铜，几 mV~几十 mV 就出来了。单看幅度还扛得住，但**它正好落在测量频段的 2 倍频上** |
| ④ **上电浪涌** | 软启动 1.48 A × 83 ms 的充电电流，现在会流过 `AGND` |
| ⑤ **干接点线束** | `U4/U7/U14/U16` 那四根线跑到机箱外的 DRS，一路拾取噪声，现在直接灌进模拟地 |

#### 改法：恢复成三个网络

**网络命名**（建议，和 `绘图指南` 一致）：

```
PGND   功率地  —— 36 V 回线 + 12 V 回线 + 体电容 + TVS/crowbar + 所有功率端子
DGND   数字地  —— MCU 数字部分、CH340X、TCA9539、FRAM、TPS382x、USB、面板接口
AGND   模拟地  —— VSSA、VREF+、3V3_AVDD、V_BUS_SENSE 下臂、（将来）J_SNS_A
```

**要从 `AGND` 挪回 `PGND` 的引脚（照抄即可）：**

| 类别 | 引脚 |
|---|---|
| 母线体电容 | `C34.2` `C35.1` `C36.1` `C37.1` `C38.1` `C39.2` |
| 保护器件 | `D8.2`（crowbar） `SMC1.2`（TVS） |
| 软启动 | `R27.1`（栅极分压下臂，1.78 mA） |
| 36 V 端子 | `U23.1`（进线） `U26.1`（→功放） `U20.1` `U25.1`（两路 DC/DC 输入） |
| 12 V 端子 | `U10.1`（进） `U11.1`（出→RLY-01） |
| DRS 干接点 | `U4.1` `U7.1` `U14.1` `U16.1` |

**留在 `AGND` 的（一个都不要动）：**

```
U1.27 (VSSA)  ·  C23.2 C24.2 (VREF+)  ·  C19.2 C20.2 (3V3_AVDD 去耦)
C6.1 C7.1 (U6 输入)  ·  C10.1 (U6 的 NR)  ·  U6.2 (模拟 LDO 的 GND)
C8.1 C9.1  ·  R30.1 C40.1 (V_BUS_SENSE 下臂)  ·  R13.2
将来：J_SNS_A 的三个 AGND 脚
```

#### 三个网络怎么在**一个物理点**汇合

关键事实：**三路电源（36 V / DDR-30L-12 / DDR-30L-5）互相隔离，各自闭环。**
所以桥上**几乎没有稳态电流**，一只 0Ω 就够，位置比数量重要。

```
                       ┌──────── AGND  （模拟）
   5V 回线端子 U18.1 ──┤  R13 0Ω
        ↑              └──────── DGND  （数字）
        │  ← DGND/AGND 两边的负载电流（约 235 mA）都从这里回 5 V
        │
      R16 0Ω  ←── 只有它跨到功率域
        │
       PGND   ──── 星点就设在 【C34 的负极焊盘】
```

| 要点 | 说明 |
|---|---|
| 🔴 **`R13` 贴着 `U18.1` 放** | `AGND` 的 91 mA（`3V3_AVDD` 负载）要经 `R13` → `DGND` → `U18.1` 回 5 V 源。<br>放远了，这 91 mA 会在 `DGND` 铜上走一段，`AGND` 跟着漂（虽然只有 ~1 mV） |
| 🔴 **补回一只 `R16` 0Ω**（`DGND` ↔ `PGND`） | 现在删得只剩 `R13`，`PGND` 和 `DGND` 之间**没有桥了**。<br>三路电源隔离，桥上没有稳态电流，但**必须有一条直流通路**定义电位，否则数字域和功率域之间会积累静电/共模电压 |
| 🔴 **`R13` 和 `R16` 两个焊盘挨着放** | 这两只 0Ω 相邻的那一小块铜 = 星点。这才是"同一个物理点"的意思 |
| 🟡 **`U10` 和 `U11` 挨着放** | 去 RLY-01 的 394 mA 从 `U10` 进、`U11` 出。挨着放，这股电流在板上只走几毫米，<br>不会在 `PGND` 上画一条长长的压降 |
| 🟡 **功放的电流环要短** | `U26`（→功放）的地脚**直接连到 `C34` 的负极**，别绕。<br>功放那 1.74 A（含 2f 和 400 kHz 开关分量）的回路就锁在 `C34 ↔ U26` 这一小圈里 |

### P-43 🔴 `12V_OUT` 是个悬空网络，而且没有熔断器

```
'12V_OUT' ; U11.2               ← 整个网络只有一个引脚
12V       ; R9.1 R10.1 R11.1 R12.1 U10.2
```

`U10`（12 V 进）和 `U11`（12 V 出 → RLY-01）**之间没有连线**。

```
12V ──[ F5  T1A ]──→ 12V_RLY ──→ U11.2        （→ RLY-01 的继电器）
    └─[ F6  T1A ]──→ 12V_AUX ──→ 风扇 + 蜂鸣器（第 4 步再画）

U10 的 12V 两脚之间就地并： 100 µF 电解(≥25 V) + 100 nF
```

| 熔断器 | 值 | 负载 | 余量 |
|---|---|---|---|
| `F5` | **T1A** | 继电器最坏同时导通 **393.5 mA**（2×G7L 316 + G2RL-2 33.3 + G5RL 44.2） | 750 mA ÷ 393.5 mA = **1.91×** ✅ |
| `F6` | **T1A** | 风扇 200 mA + 蜂鸣器 30 mA = 230 mA | **3.3×** ✅（电机启动瞬时 0.5 A 也过） |

🔴 **必须熔断器，不能用 PTC**（ADR-008/012：PTC 跳闸后带残压，继电器会卡半吸合、触点持续拉弧）。

🟡 顺便：网名 `12V_OUT` 建议改成 **`12V_RLY`**，因为后面还会有 `12V_AUX` 那一路，
两个都是"out"，名字要能分辨。

### P-31 🔴（未闭环）`Door interlock monitor` 还是没有出口

```
'Door interlock monitor' ; C50.1 RN2.5 U24.20      ← 只有上拉和消抖电容
```
`CN1` 的 16 脚已经占满。门开关在机箱门上，必须有地方接。

```
J16  机箱互锁 4P（KF301，或 2.54 牛角）
 1  DOOR_MON    ← 门行程开关（常闭）一端 → 'Door interlock monitor'
 2  DGND        ← 另一端
 3  COIL_LOOP   ← 温控链+门互锁串完之后的节点（12 V 域，去 PC817 监视 → PB15）

```

🔴 再说一次：**`P17` 只是"监视"。门开关必须同时硬串进 RLY-01 的 12 V 线圈回路**（待决 #5）。

## 四、🟡 建议

### P-44 🟡 TVS 的位号改回 `D5`，值还没定 → 建议 **SMCJ51A**

```
SMC_L6.9-W5.9-LS7.9-RD ! '{Value}' ; D8 SMC1
```
`SMC1` 不是标准位号（二极管用 `D`）。建议改 **`D5`**。

**取值理由（上一轮 P-39①）**：SMCJ48A 的击穿电压 53.3~58.9 V 与 DRS 过压保护点
48.6~55.9 V **重叠**，最坏组合下 TVS 会在一段**持续**的过压里导通，SMC 封装稳态耗不掉。
→ **SMCJ51A**（击穿 56.7~62.7 V，完全躲开 55.9 V；DDR-30L 耐 75 V 仍在保护范围内）。

### P-45 🟡 `D8`（反接保护）的值还没定 → **不要用 60 V 的肖特基**

上一轮 P-39②：`D5` 钳位时母线被拉到 77 V 左右，**SS10P6C 只有 60 V 反向耐压，会先于 TVS 击穿**。
反接保护**不在乎正向压降**，不必用肖特基。

**选型要求**（型号待你在立创现场挑，我不凭记忆写编号）：

| 项 | 要求 |
|---|---|
| 反向耐压 | **≥100 V** |
| 浪涌电流 `I_FSM` | **≥20 A / 8.3 ms** —— 要能撑到 `F1`(6.3 A) 熔断 |
| 封装 | SMC（和现在的焊盘兼容）或 TO-263 |
| 类型 | 普通整流 / 快恢复都行 |

### P-46 🟡 `CN3` 还是 10P，8 路信号只有 2 根地

牛角座换 2.54 已经很好 ✅。建议再扩到 **14P**：8 路信号 + 6 根地插花排布
（继电器控制线是静态信号，但排线要和 12 V 线圈线束平行走，插花地能压住串扰）。

### P-47 🟡 36 V 段的电容要单独标耐压

`C35~C38`（0805 1 µF）和 `C39`（0603 100 nF）现在混在通用的 `C0805 1uF` / `C0603 100nF` 组里。
**它们挂在 `36V_AMP` 上，必须单独标 ≥100 V。**

> ⚠️ 顺带提醒：**1 µF/100 V 的 X7R 在 43 V 直流偏压下容量会掉到标称的 30~50%**。
> 这不影响功能（它们是高频旁路，储能靠 `C34`），但心里要有数 —— 别指望那 4 µF 真的存在。

`C40`（`V_BUS_SENSE` 上，只有 2 V）留 50 V ✅ 没问题。

### ⚪ 老账

| 项 | 说明 |
|---|---|
| `DSRX`/`DSTX` 只有 MCU 一个脚 | 第 6 步：串 33 Ω + ESD |
| `USART2`（`PA2`/`PA3`）没占位 | 第 6 步：RS-485 收发器留位 |
| USB 外壳直连 `DGND` | 待决 #29：至少串一只 0Ω 留位 |
| `C21`/`C22` 12 pF | 按 8 MHz 晶振实际的 `CL` 核一次（P-41） |
| `F1` 是否慢熔 (T) | 待决 #37 |
| `F2`/`F3`/`F4` 的**电流值**还没填 | **T1A / T1A / T4A**，全部**慢熔 (T)**。72 V 额定 ✅ 已确认 |
