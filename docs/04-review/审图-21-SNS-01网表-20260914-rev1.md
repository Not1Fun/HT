## 2. 必改

### 2.1 🔴🔴 `U4.16` (DCDC_IN) 接到了 `5V_ISO` —— **这是最危险的一条**

```
'5V_ISO' ; ... U1.1 U2.1 U3.13 U3.14 U4.16
                                      ↑ 错
```

手册 §5 表 5-1 原文：

> **16 DCDC_IN　Power　*Low-side* input of the isolated DC/DC converter;
> connect this pin to the **LDO_OUT** pin.**

- `DCDC_IN`(16) 是 **AMC3301 自己低压侧**的 DC/DC 输入，必须接它自己的 `LDO_OUT`(13)；
- `5V_ISO` 是 UCC12050 的**隔离高压侧** 5 V。

**把 16 脚接到 `5V_ISO` = 把 AMC3301 的低压侧引脚直接拽到高压岛电位上。**
后果：① 功能上 AMC3301 的隔离 DC/DC 根本起不来；
② 安全上它把 5 kV 隔离栅在器件外面短路掉了，**爬电/间隙直接作废**。

🟢 **而且根本不需要**：**`AMC3301` 和 `AMC3330` 自带隔离 DC/DC**（这正是选它们的原因）。
**`UCC12050` 只给两片 `AMC23C12` 供电，一滴都不给 AMC3301/AMC3330。**

**改法**：`U4.16` ← `U4.13`（并 `100 nF` 到 `U4.15` DCDC_GND）。完整 16 脚接法见新文档 §2。

### 2.2 🔴🔴 两片 AMC23C12 的 `REF`(3 脚) 全部悬空 —— **过流/过压保护等于没有**

网表里根本没有 `U1.3` / `U2.3`，也没有 **2.15 kΩ** 和 **2.49 kΩ** 这两只电阻。

`REF` 脚内部是一个 **100 µA 恒流源**。悬空 → 电压一直冲到轨：

| 后果 | 说明 |
|---|---|
| 门限完全不可控 | `V_trip = R_REF × 100 µA`；`R_REF` = ∞ → 门限跑到 `V_REF` 上限 2.7 V<br>OC 换算：2.7 V / 15 mΩ = **180 A 才跳闸** |
| **窗口模式被关掉** | 手册 §7.1：`V_REF > V_MSEL`（min 500 mV）时进入**正比较器模式**，**`Cmp1` 被禁用**<br>→ **交流的负半周完全不保护** |

**改法**（值是审过的，直接用）：

```
U1.3 (OC) ──[ R10 2.15 kΩ ±1% ]── GND1      跳闸 219 mV 峰 = 10.3 Arms = 额定 1.46×
           └─[ C? 100 nF ]────── GND1       手册 §8.4 图 8-6 的 C5，贴脚放
U2.3 (OV) ──[ R11 2.49 kΩ ±1% ]── GND1      跳闸 253 mV 峰 → ×1609 = 288 Vrms = 1.29×
           └─[ C? 100 nF ]────── GND1
```

### 2.3 🔴🔴 OV 分压链的**上臂接到了 `HGND`**，不是被测高压

```
HGND ──[R2 402k]──[R3]──[R4]──[R5]──┬──[R7 10Ω]── U2.2 (OV 的 IN)
                                     ├─[R6 1kΩ]── GND1
                                     └─[C6 100pF]── GND1
```

`R2.1` 挂在 `HGND`（shunt 的一端）上。于是 OV 片量到的是：

```
(V_HGND − V_GND1) / 1609 = shunt 压降 / 1609 = 150 mV / 1609 = 93 µV
```

**过压保护挂在了一个永远只有 93 µV 的节点上 —— 它永远不会动作。**

**改法**：`R2.1` 从 `HGND` 改接到**输出 + 端子**（新网络 `HV+`）。

### 2.4 🔴🔴 `GND1` 没有接到 shunt —— 它现在是悬空的

`GND1` 网络里只有去耦电容、`U1.4`/`U2.4`、`U3` 的 GNDS、`R6.1`：
**没有任何一个节点连到 `U30`（shunt）。**

而 OC 片的输入是 `HGND ──[R1 10Ω]── U1.2 (IN)`，也就是说它量的是
**`HGND` 相对一个悬空 `GND1` 的电压** → 完全不确定。

**改法见 §2.5 —— 和下面那条一起改，一次改完。**

### 2.5 🔴 建议把 `GND1` 和 `HGND` 合并成**一个**高压地，并把 `R1.1` 挪到 shunt 另一端

现在的拓扑是「AMC3301 参考端 B、AMC23C12 参考端 A」——**两个高压参考在 shunt 两端**。
能工作，但板上就有两块高压铜、爬电/间隙要算两遍。

🟢 **合并成一个高压地更好**（`AMC23C12` 是单端输入，它的 `IN` 和 `GND1` 必须在两端，
所以只要把 `IN` 挪到另一端，参考端就能统一）：

```
【改前】                              【改后】
R1.1 ∈ HGND                          R1.1 ∈ 'SHUNT +'      ← 挪这一根
GND1、HGND 两个网络                   GND1 并入 HGND（一个网络，建议改名 HV_GND）

结果：
  HV_GND（= shunt 端 T，变压器侧）：U1.4 U2.4 U3.9/15/16 U4.2 U4.8 U30.3/4
                                     + R6.1（OV 下臂）+ R9.1（AMC3301 INN）
  被测节点只有两个：'SHUNT +'（shunt 端 L）和 'HV+'（输出 +）
```

✅ 一块高压铜、一套爬电距离、所有参考同电位。

#### 🔴 参考端必须选**变压器侧**，这不是风格问题 —— 分压链电流会不会流过 shunt 取决于它

```
负载电流：HV+ → 负载 → 输出− (端 L) → shunt → 端 T → 变压器 com     【要被测到】
分压电流：HV+ → 分压链 → 参考端 → 变压器 com

参考端 = 端 T（变压器侧）：分压电流直接回 com，【不过 shunt】 ✅
参考端 = 端 L（端子侧）  ：分压电流必须 端L → shunt → 端T，【被当成负载电流测进去】❌
```

误差多大：

```
两条分压链并联 = 1609 kΩ ∥ 357.8 kΩ = 292 kΩ
223.6 Vrms / 292 kΩ = 0.766 mA

1 Ω 档（7.07 A）   ：0.011%   可忽略
1000 Ω 档（0.2236 A）：【0.34%】 ← 而且是和电压同相的，会把负载读得偏阻性
```

**高阻档正是这台仪器最需要准的地方。** 而且上一轮说过，变压器侧在浪涌时也更安静 ——
**两个独立理由指向同一个答案。**

> 🔧 **顺带更正我上一轮的说法**：`绘图-第4+5步…` §5.5b 里我写「统一参考点是零成本的，
> 主要为了避免 `UCC12050` 的 6.4~8.6 mA 流过 shunt」。
> 看到实际拓扑后这条**不成立** —— `UCC12050` 的隔离侧和两片 `AMC23C12` 在同一个岛内闭环，
> 那股电流本来就不过 shunt。**真正的理由是上面这条分压链电流**，量级 0.34% 而不是 0.06%，
> 比我原来说的重要得多。该文已就地更正。

### 2.6 🔴 `UCC12050` 的 6 只 NC 脚必须接地，现在全悬空

手册表 5-1 写得很死：

> **6/7/8 NC**：Pins internally connected together. **Pins belong to primary-side voltage domain.
> Connect to GNDP on printed circuit board.**
> **10/11/12 NC**：Pin belongs to isolated voltage domain. **Connect to GNDS on printed circuit board.**

这不是"可接可不接" —— 它们是 5 kV 隔离栅中间的金属，**悬空会挂在中间电位上，破坏场分布**。

```
U3.6 U3.7 U3.8   → DGND   （= GNDP）
U3.10 U3.11 U3.12 → HV_GND（= GNDS）
```

## 4. 🟡 待核实 / 建议

### 4.1 🔴 `U30` 的封装 `PCS-10W` 是 4 端子开尔文还是 2 端子双焊盘？

```
'SHUNT +' ; R8.1 U30.1 U30.2       ← 1、2 短接
HGND      ; ... U30.3 U30.4        ← 3、4 短接
```

- **如果是 2 端子、每端两个焊盘**（为了过电流）→ **这样接是对的** ✅
- **如果是 4 端子开尔文型**（内侧两脚是取样脚）→ **1+2、3+4 短接就把开尔文废掉了** 🔴

为什么要紧（量化）：

```
shunt 本体 15 mΩ
PCB 走线 + 焊点电阻在 7 A 的通路上很容易有 1~3 mΩ
→ 电流读数偏大 【7~20%】，而且铜的温度系数 +0.39%/°C，会随温度漂

🔧 **2026-09-14 更正（审图 #23）**：`7~20%` 这个数把整条 7 A 走线的电阻都算进去了，
但短接发生在**焊盘上**时，焊盘之外的走线不进误差。**实际量级是 1~7%**（0.15 mΩ→1.0%、0.5 mΩ→3.3%、1 mΩ→6.7%）。
**结论不变**，而且真正致命的是温漂：寄生的是铜（+3900 ppm/°C），1 mΩ 就给总温漂贡献 **260 ppm/°C**，
而 PCS-10W 本体只有 25 ppm/°C → **总温漂放大 11 倍**，30 °C 下漂 0.78%，且标定不掉。
```

对一台要显示 `|Z| / R / X / 相位` 的仪器，这是**首要误差源**。
→ **把 `U30` 的规格书传上来，或者确认它是 4 端子的话按开尔文接：外侧两脚走电流、内侧两脚接 `R8`/`HGND`。**

> 🔧 顺带：**待决 #52（shunt 上不上板）看来已经拍板"上板"了**（`U30` 在图上）。
> 那就要跟着确认：**7.07 A 的铜箔宽度**（2 oz 下 ≥5 mm）、**0.75 W 的散热**，
> 以及这只电阻本体串在 **223.6 Vrms 回路**里，它周围的爬电/间隙按高压算。
> 我在 PCB 阶段给你算线宽。

### 4.2 🟡 `C15` 的介质要写明 **C0G/NP0**

`C15` 是 10 nF **0805**，直接跨在被测差模信号上。
🔴 **必须 C0G/NP0** —— X7R 的直流偏压系数和压电效应会直接进读数。
（0805 的 10 nF C0G 是有的；0603 做不出来。）

### 4.3 🟡 位号建议

`U30` 是一只电阻却占了 `U` 位号，而且跳到 30（这块板其它器件是 `U1`~`U4`）。
建议改成 **`RS1`** 或 `R10`，出 BOM 时不容易和 IC 混。**纯整理，不影响功能。**
