## 新发现

### F-01 · C24 与 C20 改反了

```
C0805 ! 1uF ; C20      ← VDDA 的，改成 0805 了
C0603 ! 1uF ; C24      ← VREF+ 的，仍是 0603
```

审图 #01 的建议是「**VREF+ 的 1 µF** 换 0805」。
**VREFBUF 对 VREF+ 的 CL 有硬要求（0.5–1.5 µF，ESR ≤ 2 Ω）**，VDDA 那只无此约束。

**→ C24 换 0805（或 25 V X7R），C20 无所谓。**

### F-02 · U10.9（ULN2803 的 GND）挂在 `GND` 网络上

```
GND ; U4.1 U7.1 U10.9 U14.1 U16.1 U19.1 U20.1
```

ULN2803 的逻辑输入来自 TCA9535（DGND 域），其输入阈值相对**自身 GND**。
`GND` 与 `DGND` 在控制板上不连（**这是对的**，避免地环路 —— 二者只在 PWR-01 星点汇合），
中间隔着线束压降。阈值裕度虽大，但不干净。

### F-03 · U10.10（COM）仍不在任何网络

驱动继电器时必须接 **+12V_AUX**，否则内部续流二极管失效，
关断时线圈反峰（上百伏）直接打在输出管上。

### F-04 · 架构待拍板：ULN2803 + K1–K8 放哪块板？

U10 与 K1–K8 现在都在本板封装列表里，但 **ADR-008 定的是移到继电器板（RLY-01）**。

- 若留在控制板 → **ADR-008 需作废/修订**，续流回路与线束需重算
- 若按 ADR-008 移走 → 本板删除 U10、K1–K8，只留 12 V 转接

**需用户决定。**

### F-05 · `36V ; U20.2` 无任何负载

36 V 进控制板做什么？若用于 `V_BUS_SENSE`，按原设计分压应在 PWR-01 上做。
**需用户确认用途。**
