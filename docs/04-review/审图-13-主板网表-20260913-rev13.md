## 二、🔴 P-46 三个地的**接法顺序**接错了 —— `AGND` 成了串联链的中间环节

rev13 的实际拓扑：

```
                      R13 0Ω                 R16 0Ω
        DGND ──────────[===]──────── AGND ───[===]──────── GND
          │
          │  R20 0Ω
          └──[===]──── PGND          ← 🔴 这个网络只有 R20.2 一个引脚，悬空
```

**问题：`GND` 和 `DGND` 之间唯一的通路，是从 `AGND` 的铜皮上穿过去的。**

### 🔴 这不是理论问题，有一条具体的电流路径

**`DDR-30L-5` 是隔离模块，它的输入侧挂在 `GND`、输出侧挂在 `DGND`。**
隔离变压器的初次级之间必然有寄生电容（典型 50~200 pF，有的还外加 Y 电容）。
模块开关时，开关节点的 `dV/dt` 通过这个电容打出**共模电流**：

```
i_CM = C × dV/dt ≈ 200 pF × (36 V / 20 ns) = 0.36 A 尖峰（几十 ns 宽，每个开关周期两次）

路径：GND ──(寄生电容)──> DGND ──[R13]──> AGND ──[R16]──> 回 GND
                                              ↑
                                🔴 整股共模尖峰电流从模拟地上穿过去
```

`AGND` 正是 `VREF+`（`C23`/`C24`）和 `VSSA` 的参考。
**基准被这种尖峰调制 = 增益被调制**，而这是差分 ADC 的共模抑制**管不了**的。

### 改法（很小的改动）

**把 `R16.1` 从 `AGND` 改接到 `DGND`**，然后**删掉 `R20` 和空网络 `PGND`**：

```
        AGND ──[R13 0Ω]── DGND ──[R16 0Ω]── GND
                            ↑
                    两只 0Ω 的焊盘挨着放，这一小块铜 = 星点
```

改完之后：
- `DDR-30L-5` 的共模电流在 **`DGND` ↔ `GND`** 之间直接闭合，**完全不碰 `AGND`** ✅
- `AGND` 变成一条**末端支路（leaf）**，上面只有它自己那 91 mA（`3V3_AVDD` 的负载电流）✅
- `DGND` 做中间枢纽是对的 —— 它本来就是最"皮实"的那个域

**星点放哪**：建议在 **`U18.1`（5 V 回线端子的地脚）附近**。
理由：`AGND` 那 91 mA 要经 `R13 → DGND → U18.1` 回 5 V 源，放近了这段路最短。

> 🔧 **顺带**：如果你更喜欢 `PGND` 这个名字，那就把 `GND` 整体改名 `PGND`（一个网络、换个名），
> **不要**同时存在 `GND` 和 `PGND` 两个网络。现在 `PGND` 是空的，`R20` 等于一只焊在死路上的 0Ω。

```
'12V_AUX' ; F6.1                 ← 同上
```

上一轮断在出线端，这一轮断在**进线端**。而且名字挂反了 ——

```

              └──→ R9/R10/R11/R12（四路 DRS 干接点光耦，13 mA，不用单独熔断）

U10 的两脚之间就地并： 100 µF 电解(≥25 V) + 100 nF
```

| 熔断器 | 值 | 负载 | 余量 |
|---|---|---|---|
| `F5` | **T1A / 72 VDC** | 继电器最坏同时导通 **393.5 mA** | **1.91×** ✅ |
| `F6` | **T1A / 72 VDC** | 风扇 200 mA + 蜂鸣器 30 mA = 230 mA | **3.3×** ✅ |

## 四、D9 = MBR20200CT：**拓扑从"并联 crowbar"变成了"串联通流"** —— 可以，但 1.3 W 的热必须处理

### 先确认你画的是什么

```
'$2N92'   ; D5.1  D9.1  D9.3  F1.2        ← 两个阳极都在 F1 之后
'36V_RAW' ; D9.2  F2.1 F3.2 F4.1 R28.2    ← 共阴极（也是散热片）在下游
```
`MBR20200CT` 是 **1 对共阴极**（TO-220：1=阳极1、**2=共阴极=散热片**、3=阳极2）。
两只阳极并在一起 → **两个二极管并联，电流从 `F1.2` 正向流到 `36V_RAW`**。

**这是串联通流二极管（反接时靠它阻断），不是并联 crowbar。** 两种做法都成立：

| | 并联 crowbar（原方案） | **串联通流（rev13）** |
|---|---|---|
| 正常工作损耗 | **0 W** | **约 1.3 W** ❌ |
| 母线压降 | 0 V | **约 0.6 V** ❌ |
| 反接时 | 短路 → 靠 DRS 自身 OCP 关断 | **直接阻断，什么都不烧** ✅ |
| 器件耐压要求 | 要顶住 TVS 的钳位 82 V → ≥100 V | 只要顶住反接的 43~56 V → **100 V 就够，200 V 是过度** |

**你选串联是合理的**（"接反了什么都不烧"对维修很友好）。但代价要算清楚：

### 🔴 热耗算一遍

```
过 D9 的总电流 = F2 支路 0.27 A + F3 支路 0.085 A + 功放支路 1.74 A = 2.10 A（32 V 最坏）
两只并联 → 每只 1.05 A

Vf：手册给的是 920 mV @10 A（25 °C）。1 A、结温 100+ °C 时约 0.55 ~ 0.65 V
    （⚠️ 精确值要查手册的 Vf-If 曲线，我按 0.60 V 算）

P = 2.10 A × 0.60 V ≈ 1.26 W      （范围 1.16 ~ 1.47 W）
```

| 散热方式 | θJA | ΔT | **Tj @45 °C 机箱内** | 判定 |
|---|---|---|---|---|
| **立式 TO-220，散热片悬空**（现状） | ≈62 °C/W | 78 °C | **123 °C** | 🟡 没超 Tj max 150 °C，但**管壳约 120 °C**，烫手、且会烤旁边的电解电容 |
| 卧式贴板 + 螺丝固定到覆铜 | ≈35~40 °C/W | 49 °C | **94 °C** | ✅ 舒服 |
| 加一小片铝散热器（10 °C/W） | ≈12 °C/W | 16 °C | **61 °C** | ✅ 很舒服 |

**建议：卧式贴板 + 螺丝固定，底下铺一块覆铜（两面 + 过孔阵列）。**
🔴 **注意：TO-220 的散热片就是共阴极，带 `36V_RAW` 的电位。**
加金属散热器的话要么加绝缘片，要么确保散热器不碰到任何别的东西。

> 🟡 **200 V 是过度设计**：串联接法下 D9 的反向应力只有反接时的 43~56 V，**100 V 档就够**
> （1.8× 余量）。100 V 档的 Vf 只低 0.05~0.07 V，省 0.1 W —— **不值得为此换料**，
> 手上这颗直接用就行。真想省这 1.3 W，只有回到并联 crowbar 一条路。

### ✅ 顺带的两个好处（不用改，记一下）

1. **掉电保持**：DRS 断电瞬间，`C34` 的电荷会经 `Q1` 的体二极管回灌到 `36V_RAW`，
   D9 挡住它流回 DRS → 两路 DC/DC 能多撑一小会儿 ✅
2. **负向浪涌**：`D5`(SMCJ51A) 正向钳在 −0.7 V，D9 再挡一道 ✅

### 📊 对基准表的影响（很小，但记一笔）

36 V 母线总功耗 **71 W → 72.3 W**；DRS 可用充电电流 3.91 A → **3.88 A @43.2 V**。
**基准表不用改**（都在取整误差里）。

## 五、🟡 P-48 `R28`（`V_BUS_SENSE` 分压上臂）建议挪到 D9 **之前**

```
'36V_RAW' ; D9.2 F2.1 F3.2 F4.1 R28.2      ← R28 现在挂在 D9 之后
```

**D9 的 Vf 随电流变化**，所以测到的电压带一个**随负载漂移**的误差：

```
轻载（只有 MCU，约 0.36 A）  → Vf ≈ 0.45 V
满载（功放全开，2.10 A）      → Vf ≈ 0.62 V
                              ──────────────
                  随负载漂移   ≈ 170 mV
```

`V_BUS_SENSE` 的分辨率是 **14.9 mV/LSB**，所以这是 **11 个 LSB 的负载相关误差**。

🔴 **更要紧的是它会毁掉电池电量估计**：CLAUDE.md 里写着
「`BAT_OK` 对 LiFePO₄ 只有约 3 分钟预警（33 V 报警 ↔ 31.3 V 切断）」——
整个预警窗口只有 **1.7 V**，而 170 mV 的漂移就吃掉了 **10%**。
而且功放一开一关电压就跳一下，软件会误判成电池在掉。

**改法**：把 `R28.2` 从 `36V_RAW` 改接到 **`$2N92`（F1 之后、D9 之前）**。
这样读到的就是 **DRS 的真实输出电压**，和 DRS 规格书、和将来 MODBus 读回来的数**对得上**。

> 分压比不变（21:1），32 V→1.524 V、43.2 V→2.057 V、55.9 V→2.662 V ✅ 全部不削顶。
