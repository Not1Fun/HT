## 二、`U27` 的 B 通道 —— 是**子件**问题，不是漏画

用户截图里的符号只有 `1/2/3/4/8` 脚。对照手册第 2 页脚位图：

```
HMCP6022  SOP-8
  1 OUTA   2 −INA   3 +INA   4 −VS
  5 +INB   6 −INB   7 OUTB   8 +VS        ← 这三个脚在【子件 B】上
```

**`1/2/3/4/8` 正好是「子件 A + 两个电源脚」** —— 这是双运放多子件符号的标准画法。

### 两条路

#### 🟢 方案 1（推荐）：换成**单运放** `HMCP6021T-I/OT`（SOT-23-5L）

手册订货表里就有，**参数完全相同**（11 MHz / RRIO / SR 11 V/µs / THD+N 0.0005% /
V_CM `V−`−0.1…`V+`+0.1）。

```
HMCP6021  SOT-23-5L
  1 OUT   2 −VS   3 +IN   4 −IN   5 +VS
```

**接法（只改 5 根线）：**

| 脚 | 接到 |
|---|---|
| `U27.1` (OUT) | `OUT_A` |
| `U27.4` (−IN) | `OUT_A` ← 跟随器 |
| `U27.3` (+IN) | `+IN_A` |
| `U27.2` (−VS) | `AGND` |
| `U27.5` (+VS) | `3V3_AVDD`（`C66` 1 µF + `C67` 100 nF 贴脚） |

| | |
|---|---|
| ✅ | **B 通道悬空的问题直接不存在** |
| ✅ | 静态电流少一半（只有一路 750 µA） |
| ✅ | 省面积；`SOT-23-5` 板上已有（`U21` TPS382x 同封装） |
| 代价 | 少一个"备用"通道 —— 而那通道本来也只是接地跟随器，没用途 |

#### 方案 2：保持双运放，**把子件 B 放出来**

再放一个同器件，位号同样写 `U27`，属性里把「子件」选成 **B**，然后：

```
U27.5 (+IN_B) ──── AGND
U27.6 (−IN_B) ──── U27.7 (OUT_B)          ← 接成跟随器
U27.7 (OUT_B) ──── （可留测试点，也可不接）
```

**改完的判据**：网表里出现 **`U27.5` / `U27.6` / `U27.7`**。

### 为什么不能就这么空着

`U27` 挂在 **`3V3_AVDD`** 上，而 `VDDA`(U1.29) 和 `VREFBUF` 的 `VREF+`(U1.28) 也在这条轨上。

CMOS 运放输入悬空 → 没有反馈、开环增益 105 dB → 输出顶到某一边；
**RRIO 输出级在这种状态下有自激风险**，那点噪声会顺着 `3V3_AVDD` 直接打进 ADC 的基准域。
基准被调制 = 增益被调制，差分 ADC 的共模抑制管不了。

**代价只有两根线（或换个料号），不值得赌。**

## 三、🟡 P-60（未改）`R40` + `R41` 两只 100 Ω 串成 200 Ω

```
'OUT_A'  ; ... R40.2 ...
'$1N235' ; R40.1 R41.1
'$1N236' ; C65.1 R41.2
```
原设计只要**一只** 100 Ω（防线缆电容让运放自激 / 防短路）。

| 功放模块输入阻抗 | 分压损失 |
|---|---|
| 10 kΩ（常见） | −0.17 dB ✅ |
| 600 Ω | **−2.5 dB** 🟡 |

→ **`R40` 改 0 Ω 或直接删掉。**
