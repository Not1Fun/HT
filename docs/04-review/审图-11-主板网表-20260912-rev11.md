## 二、🔴 必须改

### P-31 🔴 `Door interlock monitor` 有上拉有电容，但**没有引到任何连接器**

```
'Door interlock monitor' ; C50.1  RN2.5  U24.20        ← 只有上拉和电容，没有出口
```
`CN1` 16 个脚已经占满（7 路 TCA 输入 + 编码器 A/B + 3V3 + 6 根地），**门开关无处可接**。

**门开关在机箱门上，和 thermostat 一样属于机箱侧器件**，建议单独开一个接口：

```
J16  机箱互锁 4P（KF301 或牛角均可）
 1  DOOR_MON      ← 门行程开关（常闭）的一端
 2  DGND          ← 另一端
 3  COIL_LOOP     ← 温控链+门互锁 串完之后的节点（12 V 域，去 PC817 监视）
 4  GND
```
（如果按第 1 步的建议把 `J11` 做成 4P，`COIL_LOOP` 走 `J11.3`，那 `J16` 只要 2P。）

🔴 再强调：**`P17` 只是"监视"。门开关必须同时硬串进 RLY-01 的 12 V 线圈回路**（待决 #5）。

### P-32 🔴 编码器 `PC6`/`PC7` 没有上拉、没有滤波电容

```
PC6 ; CN1.12 U1.38          ← 只有连接器和 MCU
PC7 ; CN1.14 U1.39
```
机械编码器是**干接点**，不加上拉就是浮空，读出来是随机数。

```
PC6 (38) ──┬──[ 10 kΩ ]── 3V3
           └──[ 10 nF C0G ]── DGND        ← 🔴 是 10 nF 不是 100 nF
PC7 (39) 同上
```
`RN1`/`RN2` 的 8 个 10 kΩ 已经全给了 TCA9539 的 8 路输入，**要再加 2 只**
（可以再放一只 8P4R 只用 2 路，或者直接 2 只 0603 分立）。

> 为什么是 10 nF：100 nF 时 τ=1 ms，而编码器最快边沿间隔只有 4.2 ms（20 档、手转 5 圈/s），
> 上升沿要占掉 29% → **会丢步**。10 nF 时 τ=100 µs，只占 2.9% ✅

### P-33 🔴 `12V` 网络**没有输入端子**

```
12V ; R9.1 R10.1 R11.1 R12.1        ← 只有 4 只光耦限流电阻，没有电源来源
```
`DDR-30L-12` 的输出要接回板上（喂光耦 + 继电器 + 风扇 + 蜂鸣器）。
现在 `U18` 是 `5V_IN` 的端子，**12 V 的端子漏画了**。

```
J_12V_IN  KF301 2P：  12V / GND
本地去耦： 100 µF 电解（≥25 V）+ 100 nF
再往下分： ──[ F4' T1A ]──→ 12V_RLY → J11
           ──[ F5  T1A ]──→ 12V_AUX → 风扇 + 蜂鸣器
```
（`F4` 这个位号已经被功放那路用掉了，12 V 那两只熔断器要另起位号。）

### P-35 🔴 `F4` 应该挪到 `Q1` 之前

现在是 `36V_RAW → Q1 → 36V_AMP →（C34~C39 一堆体电容）→ F4 → U26`。

**问题**：`C34`(1000 µF) 和 `C35~C39` 全挂在 `F4` 的**上游**。
这些电容一旦击穿短路，`F4` 管不着，只有 `F1`(6.3 A) 兜底 ——
而 `Q1` 全导通时 Rds(on) 只有几十 mΩ，**短路电流几百安，Q1 会在 F1 熔断之前先炸**。

**改成**：

```
36V_RAW ──[ F4 T4A ]──→ Q1.3(S)     Q1.2(D) = 36V_AMP ──┬── C34~C39
                                                         └──→ U26
```
软启动浪涌 1.48 A × 83 ms → I²t = **0.18 A²s**，T4A 的熔断 I²t 是它的几十倍 ✅ 毫无压力。

### P-36 🔴 `F2`/`F3`/`F4` 用的是 **1206 贴片保险丝**，必须确认**直流额定电压 ≥63 V**

```
F1206 ! '{Value}' ; F2 F3 F4
```
🔴 **1206 贴片保险丝的直流额定普遍只有 32 V 或 63 V，而且大电流档（≥3 A）往往只标 32 V。**
我们母线最坏 **55.9 V** —— 用 32 V 的管子，熔断瞬间会拉弧、断不干净。

**下单前必须看规格书里的 `Voltage Rating (VDC)` 这一栏。**
选不到 ≥63 VDC 的，就改用 **Nano²（方形贴片，125 VDC 常见）** 或 φ5×20 管座。

**取值（同上一轮）**：

| 位号 | 值 | 负载 | 余量 |
|---|---|---|---|
| `F2` | **T1A / ≥63 VDC** | DDR-30L-12：7.3 W/0.85/32 V = 0.27 A | 2.8× |
| `F3` | **T1A / ≥63 VDC** | DDR-30L-5：≈2.6 W/0.85/32 V = 0.10 A | 大 |
| `F4` | **T4A / ≥63 VDC** | 功放 50 W/0.90/32 V = 1.74 A | 1.71× |

⚠️ 贴片保险丝在 70 °C 环境要降额约 25%，机箱内温度要算进去。

## 三、🟡 建议改

### P-37 🟡 `CC / VA` 上并了**两只** 100 nF

```
'CC / VA' ; C42.1  C44.1  CN1.5  RN1.4  U24.13
```
8 路输入用了 9 只电容（C42~C50）。**`C44` 是多出来的**，删掉一只
（两只并联 = 200 nF，τ 变 2 ms，虽然不致命，但和另外 7 路不一致）。

### P-38 🟡 三只地桥 `R16`/`R20`/`R21` 仍然并联

```
DGND ; ... R16.1 R20.1 R21.1 ...        GND ; ... R16.2 R20.2 R21.2 ...
AGND ; ... R13.2 ...                    DGND ; ... R13.1 ...
```
**① 三只并联要删到一只**（单点星型接地只能有一个连接点；三路电源各自隔离闭环，
桥上几乎没有电流，一只 0805 0Ω 足够）。

**② 更要紧的是位置**：现在 `AGND` 只能经 `R13` → `DGND` → `R16` → `GND`，
**是串成一串，不是星型**。`R13` 和 `R16` 之间那段 `DGND` 上的任何压降，`AGND` 都会跟着漂。
🔴 **`R13` 和保留的那一只 GND 桥必须落在同一个物理点上**（PCB 阶段这两个焊盘要挨着）。

> 🔧 **2026-09-13 补充说明（这句话我写得有歧义，rev12 被理解成"并成一个网络"了）**：
> **同一个物理点 ≠ 同一个网络。** 三个网络（`PGND`/`DGND`/`AGND`）**必须保留**，
> 只是它们的**桥接元件在 PCB 上要挨着放**。合成一个网络之后敷铜就是一整块，
> DRC 再也拦不住功放那 1.74 A 从模拟区底下穿过去。详见审图 #12 的 P-42。

### P-39 🟡 `D5` / `D8` 的耐压配合有两处擦边

**① `D5` = SMCJ48A，击穿电压 53.3 ~ 58.9 V；DRS 过压保护点 48.6 ~ 55.9 V —— 两个区间重叠。**
最坏组合（DRS 到 55.9 V 才切、TVS 53.3 V 就击穿）下，TVS 会在一个**持续**的过压里导通。
SMC 封装稳态只能耗几瓦，长时间导通会烧。
→ 建议改 **SMCJ51A**（击穿 56.7 ~ 62.7 V，完全躲开 55.9 V；DDR-30L 耐 75 V，仍在保护范围内）。

**② `D8` = SS10P6C 只有 60 V 反向耐压，而 `D5` 的钳位电压是 77.4 V @19.4 A。**
浪涌时 TVS 把母线钳到 77 V，**`D8` 会先于 TVS 反向击穿**，变成实际的钳位器件，
而它没有浪涌能量额定。
→ `D8` 是**反接保护**，不在乎正向压降，**不必用肖特基**。
改成 **反向耐压 ≥100 V、I_FSM ≥ 20 A 的整流管**（SMC 或 TO-263 封装）即可。
🟡 **具体型号待选型**（不凭记忆写编号）。

> 这两条上一轮标了 ✅，是我漏算了「TVS 击穿区间 vs DRS OVP 区间」和
> 「TVS 钳位电压 vs 肖特基耐压」的配合，**本轮更正**。

### P-40 🟡 `U8.5` = `CTS#`（输入脚）悬空

CH340X 的 MSOP-10 pin 5 是 **CTS#，是输入**。悬空的 CMOS 输入可能来回翻转、多耗电流。
→ **接 `DGND`**（低有效 = 一直允许发送）。
`U8.4`(DTR#) 是输出，悬空无害 ✅。

### P-41 🟡 `C21`/`C22` = 12 pF，要按 8 MHz 晶振的 `CL` 核一次

```
C_L(实际) = (C1 × C2)/(C1 + C2) + C_stray ≈ 6 pF + 5 pF = 11 pF
```
晶振若标 `CL = 12 pF` → 应取 **C1 = C2 = 14 pF**；标 `CL = 20 pF` → 取 **30 pF**。
差几 pF 只是频偏几十 ppm，UART/USB 都不受影响，但**买之前看一眼规格书的 CL**。

## 五、回答用户的四个问题

### 5.1 风扇不要控制，直接满速 → ✅ 可以，但有三条要注意

**电路简化成一个 2P 端子：**

```
12V_AUX ──[ F5 T1A ]──→ J14.1   风扇 +
GND ──────────────────→ J14.2   风扇 −
J14 两脚之间并： 100 µF 电解(≥25V) + 100 nF        ← 电机启停的尖峰要就地吸收
```

| 注意 | 说明 |
|---|---|
| ① **买四线风扇也不用接 PWM** | Intel 四线规范：**PWM 脚悬空 = 全速**。所以买到四线的也能直接用，PWM/TACH 两根剪掉或留着不接 |
| ② 🔴 **NTC 一定还要画** | 风扇满速只是取消了"调速"，**没有取消"测温"**。过温要能降功率/停机，而且后面第 4 步的 3 路 NTC 是唯一的温度信息来源 |
| ③ `F5` 由 T500mA 改 **T1A** | 电机启动电流是额定的 2~3 倍（0.2 A → 瞬时 0.5 A）。T1A 更稳，而且和 F2/F3 同一个料号 |

**释放出两个脚**：`PB10`(30) 和 `PA11`(45) 回到空闲池。

> 🟡 想留后路的话：`PB10` 那里放一只 **BSS138 + 100 Ω + 10 kΩ 下拉的位（不装元件）**，
> 万一整机噪声太大想加调速，补三个件就行，不用改板。

### 5.2 `C33` 新换的电容 → ✅ **合格，可以下单**

| 参数 | 实物 | 核算 |
|---|---|---|
| 容量 | 3.3 µF ±10% | ✅ 斜坡 75~91 ms、浪涌 1.35~1.63 A，容差影响可忽略 |
| 耐压 | **100 V** | ✅ 实际两端最大 **31.2 V**（= 43.2 − 12），**余量 3.2×** |
| 介质 | 金属化聚酯 MEF/CL21 | ✅ **非极性** —— 这是硬要求（G-D 之间电压会变号，稳态是 −12 V） |
| 温度 | −40 ~ +125 °C | ✅ |
| dV/dt | 需要 435 V/s | ✅ 薄膜电容随便扛，聚酯完全够（不必上聚丙烯） |
| 脚距 | 20 mm | ✅ 和封装一致 |

🟡 **唯一要处理的是封装尺寸**：3.3 µF/100 V 聚酯盒式实物大约 **22 × 18 × 11 mm**，
而封装名写的是 `W5.5`。PCB 阶段按实物量一下，把丝印/禁布区改对。

### 5.3 旋转编码器「固定几个档」的 → ✅ 要的是**带定位（detent）的增量式编码器**

**选型要点：**

| 项 | 要求 | 说明 |
|---|---|---|
| 类型 | **EC11 系列**（立式带按键） | 最常见、最好买、面板孔位标准 |
| 🔴 **脉冲数 = 定位数** | **20 脉冲 / 20 定位**，或 24/24 | 🔴 **千万别买「15 脉冲 / 30 定位」** —— 那种每两档才走完一个正交周期，**一半的定位点停在 A/B 中间态**，手一抖就来回计数 |
| 按键 | **必须带**（5 脚版本） | `Encoder ENTER`（TCA9539 的 `P15`）要用 |
| 引脚 | A / C（公共）/ B + 按键 2 脚 | `A→PC6`、`B→PC7`、`C→DGND`；按键两脚 → `Encoder ENTER` + `DGND` |
| 轴 | D 型半轴或滚花轴，轴长按面板厚度 | 15 mm / 20 mm 常见 |
| 寿命 | 机械 ≥30000 圈 | 面板操作够用 |

**为什么带定位正好：**
带定位的编码器**停在定位点时 A/B 处于同一个稳定状态**（通常都断开 = 都被上拉为高），
所以静止时的接触抖动不会产生计数 ✅ 这是它比无定位编码器可靠的根本原因。

**软件：** `TIM3` 编码器接口 ×4 倍频 → **1 档 = 4 个计数** → 软件右移 2 位。
输入滤波 `TIM3_CCMR1.IC1F = IC2F = 0b0011`。

> 如果你的意思是"只要几个固定档位、不要连续调"（像波段开关那样），
> 那是**绝对式档位开关**，要占更多 IO。但面板上已经有 4 个频率预设按键了，
> **编码器就是用来在预设之间连续微调 2~10 kHz 的**，带定位的增量式编码器正合适。

### 5.4 功放的过温检测和故障检测先不要 → ✅ 可以，但**不能连硬件保护链一起砍**

**取消的是：** `CLIP_OTW`（功放模块自己的削顶/过温告警）。
→ `PB5`(58) 释放；`J_AMP` 从 6P 减成 **4P**：

```
J_AMP 4P：  1 DDS_OUT   2 AGND   3 AMP_ENABLE   4 DGND
```
🟡 建议**排针位仍然按 6P 留**，两个脚标 NC。将来换成带告警引出的模块，补两根线就行，不用改板。

🔴 **但下面两条绝对不能一起砍：**

| 保留什么 | 为什么 |
|---|---|
| **AMC23C12 ×2（OC/OV 硬件保护）** | 那是保护**人和变压器**的，不是保护功放的。输出 250 Vrms / 8 Arms，软件卡死就没保护了 |
| **3 路 NTC + 3 只 thermostat** | 砍掉模块的 OTW 之后，**这就是唯一的温度信息来源了**。thermostat 还要硬串进继电器线圈回路 |

**释放出来的脚合计 3 个**（`PB10`、`PA11`、`PB5`），
加上第 5 步要新占的 3 个（`PB0`/`PA15`/`PB7`），**空闲脚仍然是 10 个**。

### 5.5 接口可以用牛角吗 → ✅ 逻辑口可以，**模拟口和电源口不行**

「牛角」= **带护套+防呆缺口的双排 IDC 简易排针（DC3 系列）**，配灰排线压接。

| 接口 | 能不能用牛角 | 说明 |
|---|---|---|
| **`CN1` 面板 16P** | ✅ **推荐** | DC3-16P，带缺口防呆。现在的地线插花排布正好配排线 |
| **`CN2` → RLY-01 10P** | ✅ **推荐**，但建议把 **2.0 mm 改成 2.54 mm** | 2.0 mm 牛角要配 1.0 mm 间距的排线，工具和料都难买；2.54 是绝对主流 |
| **`J_SNS_D` 数字 8P** | ✅ 可以 | 纯逻辑信号 |
| **`J11` 12 V→RLY 4P** | 🟡 可以 | 394 mA；2.54 牛角单脚额定约 1 A、28 AWG 排线约 1 A ✅ 够，但已经没多少余量 |
| **`J15` NTC 6P** | ✅ 可以 | µA 级 |
| 🔴 **`J_SNS_A` 模拟 8P** | 🔴 **不能用** | ADR-015 要求「两对输出各自绞线 + 总屏蔽」。排线是平行扁线，**绞不起来、屏蔽层也没处接**。<br>→ 用 **XH/PH 单排带扣端子 + 自己做屏蔽绞线束** |
| 🟡 **`J_AMP` 信号 4P** | 🟡 勉强可以 | `DDS_OUT` 是模拟信号，但 2 Vpp 抗扰度高。**用的话信号旁边必须排地** |
| 🔴 **36 V / 12 V / 5 V 电源、功放供电** | 🔴 **不能用** | 1.74 ~ 2 A。必须 **KF301/KF128 螺钉端子**或 VH3.96。排线和牛角脚撑不住 |

**用牛角的三条注意：**

1. 🔴 **选带锁扣的**（DC3 标准型就有卡扣），机箱振动不会松
2. 🔴 **排线地线插花**（信号旁边永远有一根地）—— `CN1` 现在已经做到了 ✅，`CN2` 只有 2 根地（8 路信号），🟡 建议换 **14P** 排到 6 根地
3. 🔴 **单脚电流按 ≤1 A 用**；要过大电流就并几根
