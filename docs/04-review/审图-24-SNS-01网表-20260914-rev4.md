## 1. ✅ 核心闭环：`RS1` 四个脚落在四个网络里，主回路通了

```
'HV+'     ; R2.1 R12.1 U6.2 U30.2        ← 4 个成员全齐 ✅✅
'GND1'    ; ... RS1.4 U30.1              ← 变压器 com（宽脚·电流端）✅
'HV_GND'  ; ... RS1.3 ...                ← 变压器侧取样（窄脚）✅
'I_SNS'   ; R1.1 RS1.2                   ← 输出侧取样（窄脚）✅
'SHUNT +' ; RS1.1 U6.1                   ← 输出 −（宽脚·电流端）✅
```

**脚的配对也对**：`1`+`2` 一端（外宽 + 内窄相邻）、`3`+`4` 另一端 ✅

### 电流走向自检 —— 通了

```
负载： U30.2 → HV+ → U6.2 → 负载 → U6.1 → SHUNT+ → RS1.1
       → 【电阻片】→ RS1.4 → GND1 → U30.1 → 变压器 com          ✅ 全过电阻片
分压： HV+ → 两条分压链 → HV_GND → RS1.3（取样脚，和 RS1.4 同一端）
       → GND1 → 变压器 com                                      ✅ 不过电阻片
```

✅ **待决 #59 满足**：分压链那 0.766 mA 不经过被测元件。
✅ **两条分压链的上臂都在 `HV+` 上了** —— rev3 漏掉的 OV 那条（`R2.1`）补上了 ✅
✅ **输出端子 `U6` 接上了** —— rev3 悬空的问题闭环 ✅

## 2. 🔴🔴 回退 1：`R8.1` 跑到 `HV_GND` 上了 —— AMC3301 的电流测量会恒为 0

```
'HV_GND' ; ... R8.1 R9.1 ...      ← 两个都在这里 ❌
'I_SNS'  ; R1.1 RS1.2             ← 只剩 R1（OC 的输入）
'I_INP'  ; C15.2 R8.2 U4.6        ← AMC3301 INP ← R8 ← HV_GND
'I_INN'  ; C15.1 R9.2 U4.7        ← AMC3301 INN ← R9 ← HV_GND
```

**`INP` 和 `INN` 现在都从 `HV_GND` 取 → 差分输入两端是同一个节点 → 电流读数永远是 0。**

（有意思的是 rev3 正好相反：那时 `R8` 对、`R1` 错。**两个各对了一次。**）

**改法**：`R8.1` 从 `HV_GND` 挪到 **`I_SNS`**，和 `R1.1` 同网。

```
改后：
'I_SNS'  ; R1.1 R8.1 RS1.2        ← OC 的输入 + AMC3301 的 INP，都取输出侧取样脚
'HV_GND' ; ... R9.1 ...           ← AMC3301 的 INN 留在这里 ✅（TI 手册：INN 那侧就是 HGND 侧）
```

复核：改完之后
- AMC3301：`INP`(经 R8 ← RS1.2) − `INN`(经 R9 ← RS1.3) = 电阻片两端 ✅，`HGND`(U4.8) 在 `HV_GND` ✅
- OC 片：`IN`(经 R1 ← RS1.2) 相对 `GND1` 脚(U1.4，在 `HV_GND`) = 电阻片两端 ✅
- **两者取同一对取样脚 → 跳闸门限和测量带同样的误差，不会各漂各的** ✅

## 3. 🔴🔴 回退 2：12 只去耦电容的地脚落在功率网 `GND1` 上

芯片的地脚在 `HV_GND`，它们的去耦电容却回到了 `GND1`：

| 电容端 | 属于谁 | 对应芯片地脚 | 现在在 | 应该在 |
|---|---|---|---|---|
| `C1.2` `C2.2` | `U1` 的 `VDD1` 去耦 | `U1.4` ∈ `HV_GND` | `GND1` | **`HV_GND`** |
| `C7.2` `C8.2` | `U2` 的 `VDD1` 去耦 | `U2.4` ∈ `HV_GND` | `GND1` | **`HV_GND`** |
| `C12.2` `C14.2` | `U3` 的 `VISO` 去耦 | `U3.15` ∈ `HV_GND` | `GND1` | **`HV_GND`** |
| `C20.1` `C27.2` | `U4` 的 `HLDO_OUT` 去耦 | `U4.8` ∈ `HV_GND` | `GND1` | **`HV_GND`** |
| `C19.2` `C28.1` | `U5` 的 `HLDO_OUT` 去耦 | `U5.8` ∈ `HV_GND` | `GND1` | **`HV_GND`** |
| `C23.2` `C24.2` | 两片 `AMC23C12` 的 `REF` 滤波 | `U1.4`/`U2.4` ∈ `HV_GND` | `GND1` | **`HV_GND`** |

**共 12 个电容端要改。**

### 为什么这是必改，不是"反正都是高压地"

`GND1` 和 `HV_GND` **不是同一个点** —— 它们只在 `RS1` 内部、经过「取样点到电流端那一小段电阻片 + 镀镍铜脚」相连。

**去耦回路因此多绕了一段 shunt 引脚**（几 nH 电感）+ PCB 上两块铜之间的距离。
对 100 nF 去耦来说，回路电感多几 nH 就足以让它在几十 MHz 以上失效 ——
而 `AMC23C12` / `AMC3301` / `AMC3330` / `UCC12050` 内部都是**几十~上百 MHz 的隔离载波**，
正是靠这些电容就地闭环的。

手册原文（`AMC23C12` §8.4）：
> "Place all four capacitors (C1, C2, C3, and C4) **as close to the device as possible**."

（`UCC12050` 更具体：`VISO` 的旁路电容要接到 **15 脚**，不是 9/16 脚。）

> 🟢 顺带算一下**耦合噪声**这条，免得夸大：
> `GND1` 和 `HV_GND` 之间的电压 = 取样点到电流端的压降 ≈ 0.15~0.5 mΩ × 7.07 A = **1~3.5 mV**。
> `C12` 10 µF 在 10 kHz 的阻抗 1.59 Ω → 流过 2.2 mA → 在取样脚 0.2 mΩ 上产生 **0.44 µV**
> = 150 mV 信号的 **0.0003%** ✅ 可以忽略。
> **所以这一条的危害是"去耦失效"，不是"噪声窜进测量"。** 但去耦失效本身就够严重了。

### ✅ 已经对的（别动）

`C16`/`C18`（`U4` 的 `DCDC_OUT`）、`C25`/`C26`（`U5` 的 `DCDC_OUT`）、
`C3`（OC 输入滤波）、`C6`（OV 输入滤波）、`C32`（AMC3330 输入滤波）
—— 这 7 只的地脚都已经在 `HV_GND` 上 ✅

## 5. ✅ 端子 17 A / 250 V 核算：**电流没问题，电压余量偏窄**

| 项 | 需求 | 端子 | 余量 |
|---|---|---|---|
| **电流** | 7.07 Arms | 17 A | **2.40×** ✅ 很宽 |
| **工作电压** | 223.6 Vrms | 250 V | **1.12×** 🟡 |
| **硬件 OV 跳闸点** | **288 Vrms** | 250 V | 🔴 **超额定 15%** |
| 冲击耐受 | GDT 钳位 600 V 峰 | 250 V / OVC II → 冲击耐受 2500 V | ✅ |
| 极间爬电 | 223.6 Vrms 功能绝缘 | 5.0 mm 间距 | ✅ |

### 结论：**能用，但我建议换 300 V 档**

理由不是"正常工作时不够" —— 正常最高就是 223.6 Vrms，89% 额定，能用。
理由是**硬件过压保护的门限本身就设在 288 Vrms**：

```
OV 跳闸点 288 Vrms  >  端子额定 250 V
```

也就是说，**在软件跑飞 / 选错抽头、一直到硬件 OV 动作之前的那段窗口里，端子是在超额定运行的**。
那个窗口很短（`AMP_ENABLE` 在 µs 级就被拉低，输出随即塌掉），250 V 的爬电间隙也扛得住
（250 V/OVC II 的冲击耐受是 2500 V），**所以不是"会炸"，是"余量不好看"**。

但还有一条更实际的：**做 IEC 61010-1 认证时，元件额定电压要 ≥ 设备的额定工作电压。**
我们已经把 **223.6 Vrms** 定成基准，250 V 只留 12% —— 评审时容易被挑。

🟢 **KF301 系列同间距（5.0 mm）通常有 300 V 的料号**（常见标法 300 V / 17.5 A），
换个料号的事，🟡 **具体料号待核实**。
**如果就用现在这只 250 V 的，也可以** —— 但请把"OV 门限 288 V 超端子额定"这件事记在案。

> 🔴 **和额定无关但同样重要**：这两只端子的螺钉头在 **223.6 Vrms 带电**，
> 是**可触及危险带电部件** —— 必须在机箱内、受门互锁保护，建议选**带护盖/挡板**的型号。
