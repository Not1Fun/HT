## 🟢 `OC`/`OV` 用 `PD2`+`PB3` —— **比我建议的 `PA15`+`PA11` 更好**

| | 我建议的 | **你实际画的** |
|---|---|---|
| `OC_FAULT#` | `PA15` → **EXTI15** | **`PD2` → EXTI2，独立中断向量** |
| `OV_FAULT#` | `PA11` → **EXTI11** | **`PB3` → EXTI3，独立中断向量** |

STM32 的 `EXTI0`~`EXTI4` **每条线有自己的 NVIC 向量**，而 `EXTI9_5`/`EXTI15_10` 是**共享向量** ——
`PA15`/`PA11` 会和 `PC12`(TCA9539 INT)、`PB11/13/14/15` 挤在同一个 ISR 里，要先判标志位再分支。
**`PD2`/`PB3` 各自独占一个向量，这正是"软件静音 <1 µs"最需要的。** ✅
**`EXTI2` / `EXTI3` 全板没有别的脚占用** ✅（`PB0`=EXTI0、`PC12`/`PB12`=EXTI12、`PB15`=EXTI15）

🟡 **代价一条**：`PB3` 原本记着「留给 SWO trace」（`引脚分配总表` 第 56 行）→ **SWO 单线跟踪没了**。
SWD 调试（`PA13`/`PA14`）不受影响，printf 还有 USART1→CH340X，**实际成本基本为零。**
🔴 **软件一条**：`PB3` 复位后默认是 **AF0 = JTDO**，初始化时必须显式配成普通输入。

# 二、🔴 必改 1：六个安装孔是「金属化孔 + 零环宽」

```
SCREW1~6 : 孔 φ3.200 , 焊盘 3.20 × 3.20  →  环宽 = (3.20 − 3.20)/2 = 0 mm
六个孔全在 Drill_PTH_Through.DRL（金属化）里，NPTH 文件里只有那两个 φ0.7
```

**量出来的实际后果**（沿孔心画同心圆采样）：

| 半径 | 1.5 mm | 1.7 mm | 1.9 mm 及以上 |
|---|---|---|---|
| L1 / L4 铜 | 100% | **0%** | 0% |
| L2 铜 | 100% | 0% | 100%（就是 `GND` 平面） |
| 顶层阻焊开窗 | 100% | 100% | 0% |

→ **焊盘整个落在钻孔里，钻完之后四层一点铜环都不剩**，镀出来的孔壁是个悬空的铜套。
**208 个元件通孔的环宽都 ≥0.25 mm ✅，只有这六个是 0。**

🔴 **绝大多数厂家的最小环宽是 0.13 mm，0 会被 DRC 拦下来或发工程问询。**

### ✅ 改法：**把六个孔改成 NPTH（非金属化孔）**

在立创里把 `M3螺丝` 那个焊盘属性改成**非金属化孔 / 开槽孔**，或直接放"安装孔"对象。
改完之后它们会出现在 `Drill_NPTH_Through.DRL` 里，四层都不生成铜、也不生成阻焊开窗。

🟢 **这一步顺带把审图 #29 的接地问题一起解决了**：
现在 `L2` 的 `GND` 平面离孔壁只有 **0.3 mm**（铜从 r=1.9 开始，孔半径 1.6）。
改 NPTH 之后，螺钉能碰到的金属只剩"没有"——**尼龙柱、金属柱都无所谓，ADR-004 的单点接地不会被破坏。**
🟡 将来若要接机箱 PE，**另外单独加一个接 `GND` 的环形端子焊盘**，别指望安装孔。

# 三、🔴 必改 2：`U27.6` / `U27.7` 仍然悬空

```
U27_1 → OUT_A     U27_5 → AGND   ✅ 这次接上了
U27_2 → OUT_A     U27_6 → NET_43 🔴 单焊盘空网
U27_3 → +IN_A     U27_7 → NET_44 🔴 单焊盘空网
U27_4 → AGND      U27_8 → 3V3_AVDD
```

`HMCP6022` 是 SOP-8 双运放：`5`=`IN_B+`、`6`=`IN_B−`、`7`=`OUT_B`。
现在 B 通道是「**+ 输入接地、− 输入悬空、输出悬空**」= **一个没有反馈的开环放大器**。

**它不会烧，但它会乱动**：CMOS 输入悬空，栅极漏电和板上耦合把 − 输入推来推去，
输出在两条轨之间撞，**而这颗芯片的 A 通道正是测量链的 Sallen-Key 滤波器** ——
两个通道共用一块硅、共用电源脚，B 通道的抽搐会从电源和衬底串进 A 通道。

### ✅ 改法（PCB 上就能做，一分钟）

**`U27.6` 和 `U27.7` 是 SOP-8 上相邻的两个脚，画一小段铜把它们连起来就行**
（构成单位增益跟随器，输出恒等于 `AGND`，绝对稳定）。

🔴🔴 **但有一条你必须知道**：你说「运放没改原理图，直接改的 PCB」——
**下次从原理图重新导入网表，立创会把 `U27.5→AGND` 和 `U27.6↔U27.7` 当成"多余的连接"报出来，
很可能被一键清掉。**
→ 🔴 **这两笔改动最终一定要回到原理图里**（`U27.5`→`AGND`、`U27.6`→`U27.7`），
否则它是个"只要有人重新同步一次就会消失"的修复。
**这次打样可以就这么打；但改原理图这件事别放过，记在 `PCB阶段检查清单.md` §一.1。**

# 四、🟡 必确认：全板最小间距 **0.102 mm（4 mil）**

810 条顶层线段两两算净间距（只比较夹角 <15° 的平行对），结果非常整齐：

```
最小净间距 = 0.102 mm ，出现在很多对上（线宽都是 0.254 mm）
→ 线宽 10 mil / 间距 4 mil / 节距 14 mil
```

**最密集的两处**：
- **`CN3` 那束斜排 8 根**（X 114~134, Y 16~26）—— 去 RLY-01 的继电器控制线
- **MCU 左下那束**（X 111~117, Y 46~59）

其余量出来的制造数据**全部合格**：

| 项 | 量出来的 | 判定 |
|---|---|---|
| 最小线宽 | 外层 **0.254 mm** / 内层 L2 **0.203 mm** | ✅ 远高于 0.127 |
| 最小钻孔 | **0.305 mm** | ✅ |
| 元件孔环宽 | **≥0.25 mm**（208 个全过） | ✅ |
| 铜到板边 | 外层 **0.25 mm**、内层 **≥0.5 mm** | ✅（板框 R3 圆角处目视复核过，是我的栅格误差不是真违规） |
| 板外的孔 | **0 个** | ✅ |

🟡 **0.102 mm 不是设计错误，是工艺档位问题**：很多四层工艺支持 3.5 mil(0.0889)，
但便宜档常常只到 5 mil(0.127)。**🔴 具体到你选的厂家和档位，能力表上的数字待核实** ——
下单前用立创的 DRC 跑一次「按制造商规则」，只看**间距**这一项。
如果那档只给 5 mil，就得把这两束线重新排（加宽间距或改走线），**别赌**。

# 五、🟡 六条建议（都不挡打板）

## 5.1 🟡 **L2 的缝在 MCU 底下整体偏了 3 个脚**

指南要求：缝从 **`7|8` 进、`29|30` 出**，脚 `8~13` + `17~29` 划进 `AGND`。
**逐脚量出来的实际**：

| 脚 | 应在 | 实际 | |
|---|---|---|---|
| `8` `ADC1_IN6` · `9` `ADC1_IN7` · `10` `V_BUS_SENSE` | `AGND` | 🔴 **`DGND`** | 到最近 `AGND` 铜 4.6~5.1 mm |
| `11` `12` `13`（三路 NTC） | `AGND` | 🟡 **正好在缝上** | |
| `17`~`29`（含 `VSSA`/`VREF+`/`VDDA`） | `AGND` | ✅ `AGND` | |
| `30` · `31` `VSS` · `32` `VDD` | `DGND` | 🔴 **`AGND`** | 到最近 `DGND` 铜 **4.72 mm** |

→ **不是走线跨缝，是缝画歪了。** 改法：把 `L2` 上 `AGND` 那块铜的边界沿 MCU **挪 3 个脚 = 1.5 mm**。

**🔧 严重度更正（对审图 #26 R26-02 的就地更正）**：
那一轮我把四路 ADC 跨缝定为 🔴🔴，当时的情况是**走线在 L4 上跨了 37~52 mm、抗混叠 RC 在 59 mm 外**。
**现在物理情况完全不同了** —— `C56`~`C61` 都在 MCU 脚边（2.7~7.6 mm），滤波器就是 ADC 前最后一级。
剩下的只是平面边界差 1.5 mm。算一下：

- **脚 8/9 压在 `DGND` 上** → 电压那对的回流要绕星点，多出的环路约 **1.75 cm²**。
  但它是**紧耦合差分对**（净间距量出来 0.102~0.246 mm），远端参考在 SNS-01 的 AMC 上，
  共模被差分 ADC 抑制；真正进读数的只有**两根线之间那 25 mm² 的差模环路**，小 70 倍。
  → 🟡 **实测影响很小。**
- **脚 31/32（`VSS`/`VDD`）压在 `AGND` 上**，最近的 `DGND` 在 4.72 mm 外
  → 这一对的去耦回路镜像电流落在 `AGND` 上。但那是 **100 MHz 量级**的内容，
  被抗混叠 RC（f_c 75.8 kHz）和相干 DFT 一起吃掉 → 🟡 **也不进 2~10 kHz 的读数。**

→ **两条都建议下一版改，但都不是打板的理由。** 这是"规范上不干净"，不是"会测不准"。

## 5.2 🟡 `R16`（星点 `GND`↔`DGND`）翻到了底层

`R13`/`R16` 都是 SMD 放在 **底面**。两只穿板过孔给星点串进约 **2.6 nH**。
- `R13`（`DGND`↔`AGND`）只过 96 mA 直流 → ✅ **无所谓**
- `R16`（`GND`↔`DGND`）在 DC/DC 共模尖峰的回路里：0.36 A / ~20 ns → **2.6 nH 上抖 47 mV**
  → 🟡 **建议 `R16` 挪回顶层**；落在 `GND`↔`DGND` 之间，影响的是数字裕度不是测量精度（审图 #26 已更正过这条）

## 5.3 🟡 `C33`（22 mm 直插膜电容）装在**底面**

`C33` 是 `CAP-TH_L22.0-W5.5-P20.00`，层 = **B**。焊盘还在顶层（通孔），但**本体伸在板子背面**。
- CLAUDE.md 原写「`C33` 本来就只能在顶层」
- 🔴 **机箱要给背面留 ≥6 mm 净空**，而且底面有直插件 = 板子没法平放、装配顺序要注意
- 🟡 建议翻回顶层（`Q1` 的米勒电容，走线不长）

## 5.4 🟡 `C57` / `C60` 离 MCU 脚 6.8~7.6 mm（目标 ≤5 mm）
`C58`/`C59` 是 2.7~2.9 mm ✅ 很好；`C56` 5.5 mm ✅；**`C57` 7.6 / `C60` 6.8 / `C61` 5.7 mm** 🟡。
比 v1 的 59 mm 好了一个数量级，**够用**；想更好就把这三只再往脚上挪。

## 5.5 🟡 丝印
- 最细丝印线宽 **0.076 mm** → 🟡 **印不出来**（一般要 ≥0.15 mm），厂家会自动丢弃细线
- 丝印压在阻焊开窗上 **10.58 mm²**，9 处，其中 6 处就是六个安装孔的圈（改 NPTH 后自动消失）
→ 都是外观问题，厂家会自动裁掉，**不影响功能**

## 5.6 🟡 `L1`/`L4` 没有铺地铜
L1 铜 **2770 mm²（13.4%）**、L4 **1137 mm²（5.5%）**，而 L2 是 **18117 mm²（87.9%）**。
指南 §3.3 建议「L4 的地铺铜按 L2 分区照抄」。不铺不影响功能（回流全在 L2 整板铜上），
🟡 但铺上对散热和 EMI 都有好处，**而且要铺就必须严格照 L2 分区，绝不能把两个区连起来**。
