## 九、「ULN 自带续流二极管，不用加了吧」—— 分两半答

### ✅ 对 `K1`~`K8` 这八只：**对，不用加，一只都不用**

TBD62083A 手册 p.2 的等效电路里，每一路输出都有一只 **Clamp diode 接到 `COMMON`(10 脚)**，
而 **`U1.10` 已经接在 `12V` 上** ✅ → 续流回路是「线圈 → 内部钳位管 → `COMMON` → `12V`」，
完全在芯片和线圈之间就地闭合，**不经过 `9` 脚**。

手册硬数：`V_F ≤ 2.0 V @ I_F = 350 mA`，而我们单只线圈只有 **44.2 mA**（G5RL）/ **33.3 mA**（G2RL）
→ 余量 **8~10×** ✅。审图 #31 §1.2 已经核过这条，结论不变。

### 🔴 对两只 KSAFE：**不行，ULN 根本不在那条回路里**

KSAFE 移到机箱之后，它们的线圈是被**机箱里的机械触点**通断的 —— 门互锁微动开关 + T-3 温度开关，
**电流一次都不经过 `U1`**。TBD62083A 的钳位二极管只保护它自己那 8 路输出管，管不到别人的线圈。

```
12V ─[端子]─→ 门互锁 NC ─ T-3 NC ─→ 节点A ─→ KSAFE_A 线圈 ─┐
                  ↑                      └→ KSAFE_B 线圈 ─┤
             断开的就是这里                                 └─→ GND
             （机械触点，没有任何钳位）
```

🔴 **两只续流二极管还是要加，而且必须跟着 KSAFE 装在机箱、直接并在线圈两端。**
装在 RLY-01 上没用 —— 续流回路会被拉长到整根线束，门开关触点那一侧照样拉弧。

量级：G7L-2A-BUBJ 线圈 12 V / **158 mA**（🟡 待核实，手册仍未入库），两只 316 mA。
门互锁微动开关的触点通常按阻性负载标额定；158 mA 的感性负载不加钳位，
每次开门都在触点上打一次弧 → 触点氧化、粘连。**而这只开关是安全件，它必须一直可靠。**

🟡 **选型**：普通 `1N4007` 就够；如果在意释放时间（安全切断希望断得快），
