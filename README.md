## 关键工况数（所有计算的基准）

| 参数 | 取值 |
|---|---|
| 36V 母线电压范围 | **32 – 43.2 V** 🔧 下限更正（DRS「切断电池 31.3±0.7V」→ 最坏 32.0V 就断）<br>常态：AC 在时 **36V±1%**；电池模式 32–41.4V；43.2V 只在 boost 末期掉电切换时出现 |
| 36V 母线总功耗 | **≈ 71 W ≈ 1.97 A** |
| DRS-240-36 输出能力 | 36V / 6.6A / 240W（负载占 30%，余 **3.91A @43.2V** 给充电）<br>🔧 原写 4.6A 是按 36V 除的，充电发生在 43.2V。充满约 3.7h |
| 电池续航 | **≈ 4.6 h**（指标 ≥2 h，2.3 倍余量） |
| DRS 交流输入电流 | 1.4 A @230VAC / 2.8 A @115VAC；冷启动浪涌 60 A @230VAC ✅ 官方规格书已核实 |
| DRS 过压保护点 | **48.6 – 55.9 V** —— 母线器件耐压必须按 **≥56V** 校核，不是 43.2V |

## 当前状态

### 已核对通过 ✅

- DDR-30L 后缀选型正确（**L = 18~75VDC，G 才是 9~36VDC**，反直觉，采购勿换）
- DRS-240-36 与 12S LiFePO₄ 电压匹配（43.2/41.4 V ↔ 3.60/3.45 V/cell）
- 功率预算与续航
- PC817C 全部取值（回答了 Visio 上「核对PC817的参数」那条批注）
- 变压器 7 个抽头折算初级阻抗一致（3.97–3.99 Ω）、磁通密度 73.5 mT 余量 5 倍
- **STM32G474RET6 LQFP64 引脚号**：已按官方 Table 12 逐行核实 64/64，**原始需求文档那组引脚号全部正确**
- NRST 串 1kΩ 方案：按 Table 58 最坏上拉 25kΩ 校核，NRST 可拉到 0.127V（V_IL max 0.99V）

### 待用户拍板

见 `docs/00-context/决策记录.md` 末尾的「待决事项」表。当前最急的三项：

1. **这块板到底是「控制板」还是「PWR-01 + 控制板合并」？36V 进板做什么？**
   rev4 网表里 PWR-01 的 4 路 DRS 状态光耦已经画在本板上、J3 板间排线不存在，
   证据指向已合并。这一句话同时决定 `36V ; U20.2` 悬空和 ADR-008 冲突怎么收。
   三种方案见 `docs/04-review/36V与板级归属-说明.md`。
2. **电池包 BMS 要不要带 UART 通信** —— 决定 PWR-01 要不要留串口接口，必须在画板子前定。
   建议要：12S LiFePO₄ 放电平台极平（90%→20% 母线只降 1.8V），靠电压做不了精确 SOC。
3. **DRS 的 `bat−` 与 `输出−` 是否内部共地** —— 万用表一测即知，决定 BMS 串口要不要隔离。
   共地则省掉一片隔离器。

已结案：**#2 分流电阻（定 15mΩ）**、**#12 VREFBUF（定 2.9V 档）** —— 见 `docs/03-analog/`。
