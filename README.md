## 电源部分板界（方案 A）

**220V 强电段全部走机箱件与机箱线，不上 PCB。**

| 位置 | 器件 |
|---|---|
| 机箱件（不上原理图） | AC 插座、开关、保险丝、压敏电阻、EMI 滤波、**电池包 + BMS**、电池熔断器、DC 断路器 |
| DIN 导轨件 | DRS-240-36、DDR-30L-12、DDR-30L-5 |
| **PWR-01 板上** | 36V 母线进线保护与分配、Q1 软启动、体电容、母线分压采样、4×PC817C 状态隔离、各路端子 |

## 关键工况数（所有计算的基准）

| 参数 | 取值 |
|---|---|
| 36V 母线电压范围 | **30 – 43.2 V**（12S LiFePO₄ 放空 30V ↔ DRS Vboost 43.2V） |
| 36V 母线总功耗 | **≈ 71 W ≈ 1.97 A** |
| DRS-240-36 输出能力 | 36V / 6.6A / 240W（负载占 30%，余 4.6A 给充电） |
| 电池续航 | **≈ 4.6 h**（指标 ≥2 h，2.3 倍余量） |
| DRS 交流输入电流 | 1.4 A @230VAC / 2.8 A @115VAC；冷启动浪涌 60 A @230VAC |

## 当前状态

### 已核对通过 ✅

- DDR-30L 后缀选型正确（**L = 18~75VDC，G 才是 9~36VDC**，反直觉，采购勿换）
- DRS-240-36 与 12S LiFePO₄ 电压匹配（43.2/41.4 V ↔ 3.60/3.45 V/cell）
- 功率预算与续航
- PC817C 全部取值（回答了 Visio 上「核对PC817的参数」那条批注）
- 变压器 7 个抽头折算初级阻抗一致（3.97–3.99 Ω）、磁通密度 73.5 mT 余量 5 倍
- **STM32G474RET6 LQFP64 引脚号**：已按官方 Table 12 逐行核实 64/64，**原始需求文档那组引脚号全部正确**
- NRST 串 1kΩ 方案：按 Table 58 最坏上拉 25kΩ 校核，NRST 可拉到 0.127V（V_IL max 0.99V）

### 必须改 ❌

| 项 | 现状 | 改成 |
|---|---|---|
| AC 插座 | RT-C06-A1B-CC（C6 / 2.5A / **PCB 弯插**） | C14 三合一模块（10A / **面板安装** / 带保险丝座 + 双刀开关） |
| AC 熔断器 | 15 A | T3.15A / 250V 陶瓷延时 / 分断 ≥1500A |
| 压敏电阻 | S14K275 裸 MOV | TMOV14 320Vac（带热脱扣） |
| 电池熔断器 | 「15A」无直流额定 | T15A / ≥58VDC，紧贴电池正极 |
| DC 断路器 | BOM「暂定不使用」但 Visio 画了 | 保留，2P / ≥63VDC / 16A |
| DRS 充电曲线 | 未指定 | DIP 拨到 LiFePO₄（出厂默认铅酸） |
| BMS 低温禁充 | 未指定 | 写进电池采购规格 |
| 母线软启动 | 无 | Q1 P-MOS + 栅极 RC（τ≈1s） |
| 光耦反并联二极管 | 无 | 4 × 1N4148（PC817 LED 反压仅 6V） |
| 看门狗接 NRST | TPS3823A 推挽输出直连 | 串 1kΩ（推挽 vs MCU 内部下拉会对冲短路） |
| 继电器驱动器 | ULN2803ADWR（按 5V 逻辑标定） | TBD62083A（引脚兼容，2.5V 输入即导通，压降低 3 倍） |
| 风扇 PWM 驱动 | 未定义 | 必须开漏（2N7002），不可 3.3V 推挽直驱 |
| **分流电阻** | 15mΩ 或已购 20mΩ 未定 | **必须 15mΩ**：20mΩ 在 8Arms 时占 AMC3301 线性区 90.5%，余量不足 |
| **AMC3330 分压下臂** | 1.02 kΩ（比值 351:1，输入 1.009V 超 ±1V 满量程） | **806 Ω 0.1%**（比值 443.9:1，输入 0.7975V 占 79.7%） |
| **ADC 基准** | A3V3 外部 3.3V | **内部 VREFBUF 2.9V**：3.3V 下 AMC 共模 1.44V 不满足 STM32 差分 ADC 的 V_CMIN |

全机范围的 P0/P1/P2（含门互锁、TCA9535 无 RESET、AMC3330 分压零余量等）见
`docs/00-context/设计评审-电源与安全.md`。

### 待用户拍板

见 `docs/00-context/决策记录.md` 末尾的「待决事项」表。当前最急的两项：

1. **电池包 BMS 要不要带 UART 通信** —— 决定 PWR-01 要不要留串口接口，必须在画板子前定。
   建议要：12S LiFePO₄ 放电平台极平（90%→20% 母线只降 1.8V），靠电压做不了精确 SOC。
2. **DRS 的 `bat−` 与 `输出−` 是否内部共地** —— 万用表一测即知，决定 BMS 串口要不要隔离。
   共地则省掉一片隔离器。

已结案：**#2 分流电阻（定 15mΩ）**、**#12 VREFBUF（定 2.9V 档）** —— 见 `docs/03-analog/`。
