# HT · 高压电缆接头检测 —— 音频源硬件

电缆接头查找音频源：2–10 kHz、50 VA 连续、7 档自动/手动阻抗匹配（1/3/10/30/100/300/1000 Ω），
同时测量并显示 V / I / VA / W / |Z| / R / X / 相位。

本仓库当前聚焦**电源部分**。

## 电源部分板界（方案 A）

**220V 强电段全部走机箱件与机箱线，不上 PCB。**

| 位置 | 器件 |
|---|---|
| 机箱件 | AC 插座、开关、保险丝、压敏电阻、EMI 滤波、电池包 + BMS、电池熔断器、DC 断路器 |
| DIN 导轨件 | DRS-240-36、DDR-30L-12、DDR-30L-5 |
| **PWR-01 板上** | 36V 母线进线保护与分配、Q1 软启动、体电容、母线分压采样、4×PC817C 状态隔离、各路端子 |

## 关键工况数（所有计算的基准）

| 参数 | 取值 |
|---|---|
| 36V 母线电压范围 | **30 – 43.2 V**（12S LiFePO₄ 放空 30V ↔ DRS Vboost 43.2V） |
| 36V 母线总功耗 | **≈ 73 W ≈ 2.03 A** |
| DRS-240-36 输出能力 | 36V / 6.6A / 240W（负载占 31%，余 4.6A 给充电） |
| 电池续航 | **≈ 4.5 h**（指标 ≥2 h，2.2 倍余量） |
| DRS 交流输入电流 | 1.4 A @230VAC / 2.8 A @115VAC；冷启动浪涌 60 A @230VAC |

## 当前状态

### 已核对通过 ✅

- DDR-30L 后缀选型正确（**L = 18~75VDC，G 才是 9~36VDC**，反直觉，采购勿换）
- DRS-240-36 与 12S LiFePO₄ 电压匹配（43.2/41.4 V ↔ 3.60/3.45 V/cell）
- 功率预算与续航
- PC817C 全部取值（回答了 Visio 上「核对PC817的参数」那条批注）
- 变压器 7 个抽头折算初级阻抗一致（3.97–3.99 Ω）、磁通密度 73.5 mT 余量 5 倍

### 必须改 ❌

| 项 | 现状 | 改成 |
|---|---|---|
| AC 插座 | RT-C06-A1B-CC（C6 / 2.5A / **PCB 弯插**） | C14 三合一模块（10A / **面板安装** / 带保险丝座 + 双刀开关） |
| AC 熔断器 | 15 A | T3.15A / 250V 陶瓷延时 / 分断 ≥1500A |
| 压敏电阻 | S14K275 裸 MOV | TMOV14 320Vac（带热脱扣） |
| 电池熔断器 | 「15A」无直流额定 | T15A / ≥58VDC，紧贴电池正极 |
| DC 断路器 | BOM「暂定不使用」但 Visio 画了 | 保留，2P / ≥63VDC / 16A |
| DRS 充电曲线 | 未指定 | DIP 拨到 LiFePO₄（出厂默认铅酸） |
| BMS 低温禁充 | 未指定 | 写进电池采购规格 |
| 母线软启动 | 无 | Q1 P-MOS + 栅极 RC（τ≈1s） |
| 光耦反并联二极管 | 无 | 4 × 1N4148（PC817 LED 反压仅 6V） |

全机范围的 P0/P1/P2（含门互锁、TCA9535 无 RESET、AMC3330 分压零余量等）见
`docs/00-context/设计评审-电源与安全.md`。
